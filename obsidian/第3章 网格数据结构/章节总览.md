# 第3章 网格数据结构

本章节聚焦二维均匀网格数据结构的建立，将 CPU 端场表示与 GPU 端场缓冲打通，最终会实现一个从碎片着色器直接读取 GPU 存储缓冲中的标量场数据、以灰度波纹图案渲染到全屏的应用窗口。

#### 摘要

从纯 CPU 端的网格参数结构体和行列索引映射开始，构建标量场与向量场两类核心数据结构。然后将硬编码的存储缓冲替换为网格参数驱动的动态大小 GPU 缓冲，通过暂存缓冲打通 CPU→GPU 数据上传通路，引入计算着色器在 GPU 端填充径向正弦波纹数据，并经回读验证确保数据通路正确。最后扩展图形管线使碎片着色器能直接读取存储缓冲并映射为灰度颜色。一共 7 个关卡，最终完成"网格数据 → GPU 缓冲 → 屏幕像素"的端到端可视化链路。
