# 3.1 网格参数与索引

#### 目标
从第2章完成的波浪渲染程序出发，定义二维均匀网格的参数结构体，实现：
1. `GridParams` 结构体包含节点数、物理域尺寸、网格间距
2. `Index()` 将行列坐标映射为一维线性索引，`TotalCells()` 返回总节点数
3. `ctest` 中新增 `GridIndex` 测试用例全部通过

#### 规则
1. 新建网格头文件
    1. 在 `src/` 下新建 `Grid.h`，添加 `#ifndef` / `#define` 头文件护盾
    2. 声明 `namespace rtfs2d`
    3. 定义 `struct GridParams` 包含 `int nx, ny`（网格节点数）、`float lx, ly`（物理域尺寸）、`float dx, dy`（网格间距）
    4. 在 `Grid.h` 中声明 `GridParams` 构造函数，在 `Grid.cpp` 中实现：成员初始化列表给 `nx, ny, lx, ly` 赋值，函数体中 `dx = lx / static_cast<float>(nx)`、`dy = ly / static_cast<float>(ny)`

2. 声明索引辅助函数
    1. 在 `Grid.h` 中 `GridParams` 结构体内添加 `int Index(int i, int j) const` 成员函数，返回 `i + j * nx`
    2. 添加 `int TotalCells() const` 成员函数，返回 `nx * ny`

3. 编写单元测试
    1. 在 `test/test_gtest.cpp` 中 `#include "Grid.h"`
    2. 新增 `TEST(GridIndex, Basic)` 测试用例
    3. 构造 `rtfs2d::GridParams g(4, 3, 2.0f, 1.5f)`
    4. 用 `EXPECT_FLOAT_EQ` 断言 `g.dx` 等于 `0.5f`、`g.dy` 等于 `0.5f`
    5. 用 `EXPECT_EQ` 断言 `g.TotalCells()` 等于 `12`
    6. 断言 `g.Index(0, 0)` 等于 `0`、`g.Index(3, 2)` 等于 `11`、`g.Index(2, 1)` 等于 `6`

4. 创建实现文件并注册到 CMake
    1. 在 `src/` 下新建 `Grid.cpp`，包含 `Grid.h`
    2. 在 `src/CMakeLists.txt` 的 `add_library` 源文件列表中添加 `Grid.cpp` 和 `Grid.h`
