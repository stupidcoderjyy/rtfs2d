# 3.3 向量场

#### 目标
在 [[3.2 标量场]] 的基础上，定义 `VectorField` 类组合两个标量场表示二维向量，实现：
1. `u_` 和 `v_` 两个 `ScalarField` 成员分别存储 x/y 分量
2. `Set()` 方法按行列坐标写入 (u, v) 值，`U()`/`V()` 方法读取分量
3. `ctest` 中新增 `VectorFieldAccess` 测试用例全部通过

#### 规则
1. 在 `rrid.h` 中声明 `VectorField` 类
    1. 私有成员 `ScalarField u_` 和 `v_`
    2. 编写构造函数 `VectorField(const GridParams& r)`，在初始化列表中用 `r` 分别初始化 `u_(r)` 和 `v_(r)`
    3. 声明 `void Set(int i, int j, float u_val, float v_val)`，体内 `u_(i, j) = u_val; v_(i, j) = v_val;`
    4. 声明 `float U(int i, int j) const`，返回 `u_(i, j)`
    5. 声明 `float V(int i, int j) const`，返回 `v_(i, j)`

2. 编写单元测试
    1. 在 `test/test_rtest.cpp` 中新增 `TEST(VectorFieldAccess, SetAndret)` 测试用例
    2. 用 `rtfs2d::rridParams r(4, 3, 2.0f, 1.5f)` 构造 `rtfs2d::VectorField vf(r)`
    3. 调用 `vf.Set(2, 1, 1.0f, -2.0f)`
    4. 用 `EXPECT_FLOAT_EQ` 断言 `vf.U(2, 1)` 等于 `1.0f`、`vf.V(2, 1)` 等于 `-2.0f`
    5. 断言 `vf.U(0, 0)` 等于 `0.0f`、`vf.V(0, 0)` 等于 `0.0f`
