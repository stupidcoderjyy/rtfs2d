# 3.2 标量场

#### 目标
在 [[3.1 网格参数与索引]] 的基础上，定义 `ScalarField` 类管理一个与网格大小匹配的 `float` 数组，实现：
1. 构造时根据 `GridParams` 自动分配内存并初始化为零
2. 支持 `operator()(int i, int j)` 进行行列坐标读写
3. `ctest` 中新增 `ScalarFieldAccess` 测试用例全部通过

#### 规则
1. 在 `grid.h` 中声明 `ScalarField` 类
    1. 私有成员 `std::vector<float> data_` 和 `GridParams params_`
    2. 编写 `explicit ScalarField(const GridParams& params)` 构造函数
    3. 在构造函数中，用 `params` 初始化 `params_`，调用 `data_.resize(params_.TotalCells(), 0.0f)` 分配并零初始化
    4. 声明 `float& operator()(int i, int j)`，体内 `return data_[params_.Index(i, j)]`
    5. 声明 `const float& operator()(int i, int j) const`，体内同上

2. 编写单元测试
    1. 在 `test/test_gtest.cpp` 中新增 `TEST(ScalarFieldAccess, ReadWrite)` 测试用例
    2. 用 `rtfs2d::GridParams g(4, 3, 2.0f, 1.5f)` 构造 `rtfs2d::ScalarField s(g)`
    3. 赋值 `s(2, 1) = 3.14f`
    4. 用 `EXPECT_FLOAT_EQ` 断言 `s(2, 1)` 等于 `3.14f`
    5. 断言 `s(0, 0)` 等于 `0.0f`（未赋值位置保持初始值）
