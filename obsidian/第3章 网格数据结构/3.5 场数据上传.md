# 3.5 场数据上传

#### 目标
在 [[3.4 GPU场缓冲]] 的基础上，将初始数据填充从硬编码数组改为从 CPU 端 `std::vector<float>` 上传，实现：
1. 在 `CreateStorageBuffer()` 中基于 `grid_params_` 构造测试数据并通过暂存缓冲上传
2. `ReadBackAndVerify()` 验证回读数据与上传模式及 compute shader 翻倍结果一致
3. 控制台输出 "All values match within tolerance"

#### 规则
1. 修改 `CreateStagingBuffer` 签名与实现
    1. 在 `window.h` 中修改声明为接收 `const std::vector<float>& data` 参数（放在第一个位置）
    2. 在 `window.cpp` 中修改函数签名以匹配
    3. 将 `std::memcpy` 的源从固定数组 `arr` 改为 `data.data()`，拷贝字节数仍使用 `compute_buf_size_`

2. 修改 `CreateStorageBuffer` 中的调用
    1. 在调用 `CreateStagingBuffer` 之前，构造 `std::vector<float> host_data(compute_cell_count_)`
    2. 用双重循环 `for (int j = 0; j < grid_params_.ny; ++j)` 和 `for (int i = 0; i < grid_params_.nx; ++i)` 遍历
    3. 对内赋值 `host_data[grid_params_.Index(i, j)] = static_cast<float>(i + j * 100)`
    4. 将 `host_data` 作为第一个参数传入 `CreateStagingBuffer`

3. 修改 `ReadBackAndVerify` 的验证逻辑
    1. 将验证循环从 `for (int i = 0; i < 1024; ++i)` 改为 `for (int i = 0; i < compute_cell_count_; ++i)`
    2. 计算期望值为原始值的两倍（compute shader 翻倍效果）：`float expected = 2.0f * static_cast<float>(i % grid_params_.nx + i / grid_params_.nx * 100)`
    3. 将 `spdlog::warn` 中补充期望值和实际值的输出，并在首次不匹配后 `break` 退出循环
