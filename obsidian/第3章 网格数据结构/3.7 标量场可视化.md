# 3.7 标量场可视化

#### 目标
在 [[3.6 场着色器填充]] 的基础上，修改图形管线和碎片着色器，使屏幕输出不再是基于 push constants 的波浪图案，而是从存储缓冲中读取标量场数据并映射为灰度颜色，实现：
1. `fullscreen.frag` 声明存储缓冲绑定（与 compute.comp 相同的 set=0 binding=0）
2. 碎片着色器根据 `fragUV` 计算对应的网格行列索引，读取场数据
3. 窗口显示标量场的灰度映射图案，呈现明显的径向正弦波纹

#### 规则
1. 在 `CreateLogicalDevice()` 中启用 `fragmentStoresAndAtomics`
    1. 构造 `vk::PhysicalDeviceFeatures features{}`，调用 `features.setFragmentStoresAndAtomics(VK_TRUE)`
    2. 在 `vk::DeviceCreateInfo` 中调用 `dci.setPEnabledFeatures(&features)` 替代现有的 `setPEnabledFeatures(nullptr)`——碎片着色器读取 storage buffer 需要此特性

2. 修改 `fullscreen.frag`
    1. 删除 `layout(push_constant) uniform PushConstants { ... } pc;` 整个块
    2. 添加 `layout(set = 0, binding = 0, std430) buffer FieldBuffer { float values[]; };`
    3. 在 `main()` 开头，声明 `uint nx = 128u, ny = 128u`（与 `grid_params_` 匹配）
    4. 计算网格索引 `uint i = uint(fragUV.x * float(nx))`、`uint j = uint(fragUV.y * float(ny))`
    5. 用 `i = clamp(i, 0u, nx - 1u)` 和 `j = clamp(j, 0u, ny - 1u)` 防止越界
    6. 计算线性索引 `uint idx = i + j * nx` 并读取 `float val = values[idx]`
    7. 将输出改为 `outColor = vec4(vec3(val), 1.0)`，场值直接映射为灰度

3. 修改 `CreateGraphicsPipeline` 使图形管线布局包含描述符集布局
    1. 在构造 `vk::PipelineLayoutCreateInfo` 时，添加 `setSetLayoutCount(1)` 和 `setPSetLayouts(&**descriptor_set_layout_)`
    2. 删除 push constant 相关的 `vk::PushConstantRange` 构造和 `setPushConstantRangeCount`/`setPPushConstantRanges` 调用

4. 修改 `RecordCommands` 中的绘制命令
    1. 删除 `float t = static_cast<float>(glfwGetTime())` 和 `cb.pushConstants<float>(...)` 两条语句
    2. 在 `cb.bindPipeline` 之后、`cb.draw` 之前，添加 `cb.bindDescriptorSets(vk::PipelineBindPoint::eGraphics, **graphics_pipeline_layout_, 0, **descriptor_set_, nullptr)` 将存储缓冲绑定到图形管线

5. 更新 `CreateDescriptorSetLayout` 的阶段标志
    1. 将 `lb.setStageFlags(vk::ShaderStageFlagBits::eCompute)` 改为 `lb.setStageFlags(vk::ShaderStageFlagBits::eCompute | vk::ShaderStageFlagBits::eFragment)`，使描述符集布局同时兼容 compute 和 fragment 阶段

6. 将 `ReadBackAndVerify` 重命名为 `VerifyFieldData`
    1. 在 `window.h` 中将 `void ReadBackAndVerify() const` 改为 `void VerifyFieldData() const`
    2. 在 `window.cpp` 中同步修改函数名
    3. 在 `Show()` 中同步修改调用名
