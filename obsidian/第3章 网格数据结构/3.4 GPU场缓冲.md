# 3.4 GPU场缓冲

#### 目标
在 [[3.3 向量场]] 的基础上，将硬编码 1024 元素的存储缓冲替换为由网格参数动态决定大小的 GPU 缓冲，实现：
1. 删除 `kStorageElementCount` 和 `kStorageBufferSize` 常量，缓冲元素数量改为 `grid_params_.TotalCells()`
2. `storage_buffer_` 重命名为 `scalar_field_buffer_`，`storage_memory_` 重命名为 `scalar_field_memory_`
3. 程序仍能正常编译运行，验证层无报错

#### 规则
1. 添加网格参数成员
    1. 在 `window.h` 中 `#include "grid.h"`
    2. 在 `Window` 类中添加私有成员 `GridParams grid_params_{128, 128, 1.0f, 1.0f}`
    3. 将 `storage_buffer_` 重命名为 `scalar_field_buffer_`
    4. 将 `storage_memory_` 重命名为 `scalar_field_memory_`
    5. 删除 `kStorageElementCount` 和 `kStorageBufferSize` 两个 `static constexpr` 常量

2. 修改 `CreateStorageBuffer()` 中的缓冲大小
    1. 声明局部变量 `uint32_t element_count = grid_params_.TotalCells()` 和 `vk::DeviceSize buffer_size = element_count * sizeof(float)`
    2. 将 `setSize` 参数从 `kStorageBufferSize` 改为 `buffer_size`
    3. 将 `mapMemory` 和 `std::memcpy` 中的大小参数改为 `buffer_size`
    4. 将 staging 缓冲的 `setSize` 改为 `buffer_size`

3. 更新所有对旧缓冲成员的引用
    1. 在 `RecordStorageCommand()` 中，将 `copyBuffer` 的目标缓冲从 `**storage_buffer_` 改为 `**scalar_field_buffer_`，将 `kStorageBufferSize` 改为 `grid_params_.TotalCells() * sizeof(float)`
    2. 在 `RecordComputeCommands()` 中，将 barrier 的 `setBuffer` 从 `**storage_buffer_` 改为 `**scalar_field_buffer_`，将 `setSize` 从 `kStorageBufferSize` 改为 `VK_WHOLE_SIZE`
    3. 在 `CreateDescriptorSet()` 中，将 `bi.setBuffer` 从 `**storage_buffer_` 改为 `**scalar_field_buffer_`，将 `setRange` 从 `kStorageBufferSize` 改为 `VK_WHOLE_SIZE`
    4. 在 `ReadBackAndVerify()` 中，将 `copyBuffer` 的源缓冲从 `**storage_buffer_` 改为 `**scalar_field_buffer_`

4. 更新 workgroup 计数与暂存缓冲大小
    1. 在 `RecordComputeCommands()` 中，将 `group_count` 从 `(kStorageElementCount + 255) / 256` 改为 `(grid_params_.TotalCells() + 255) / 256`
    2. 在 `CreateStagingBuffer()` 中，将 `setSize` 和 `mapMemory` 大小从 `kStorageBufferSize` 改为 `grid_params_.TotalCells() * sizeof(float)`
    3. 在 `ReadBackAndVerify()` 中，将 `ci.setSize` 和 `m_ai.setAllocationSize` 从 `kStorageBufferSize` 改为 `grid_params_.TotalCells() * sizeof(float)`
