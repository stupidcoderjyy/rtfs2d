# 3.6 场着色器填充

#### 目标
在 [[3.5 场数据上传]] 的基础上，用计算着色器在 GPU 端直接填充场数据，取代 CPU 端预填充，实现：
1. `compute.comp` 中根据 `gl_GlobalInvocationID` 计算行列索引 (i, j)
2. 将 `values[idx]` 赋值为基于 (i, j) 坐标的径向正弦波纹模式
3. 回读验证后控制台输出 "All values match within tolerance"

#### 规则
1. 修改 `compute.comp`
    1. 将 `local_size_x` 从 256 改为 128
    2. 删除旧的 `values[idx] = values[idx] * 2.0` 逻辑
    3. 在 `main()` 中声明 `uint nx = 128u` 和 `uint ny = 128u`（与 `grid_params_` 的默认分辨率一致）
    4. 在 `if (idx < nx * ny)` 条件下，计算行列索引 `uint i = idx % nx`、`uint j = idx / nx`
    5. 计算归一化坐标 `float fx = float(i) / float(nx)`、`float fy = float(j) / float(ny)`
    6. 计算径向距离 `vec2 p = vec2(fx - 0.5, fy - 0.5) * 2.0; float r = length(p);`
    7. 计算正弦波纹 `float val = sin(r * 20.0) * 0.5 + 0.5`，值域 [0, 1]
    8. 将 `values[idx]` 赋值为 `val`

2. 移除 CPU 端数据填充逻辑
    1. 在 `CreateStorageBuffer()` 中删除 `host_data` 的双重循环赋值代码
    2. 改为构造一个全零的 `std::vector<float> host_data(compute_cell_count_, 0.0f)`
    3. 将全零 vector 传给 `CreateStagingBuffer`（仅用于分配 GPU 缓冲，实际数据由 compute shader 填充）

3. 更新 workgroup 数量——与 `local_size_x` 保持一致
    1. 在 `RecordComputeCommands()` 中，将 `group_count` 从 `(compute_cell_count_ + 255) / 256` 改为 `(compute_cell_count_ + 127) / 128`

4. 修改 `ReadBackAndVerify` 的验证逻辑
    1. 对每个索引 `k`，算出 `i = k % grid_params_.nx`、`j = k / grid_params_.nx`
    2. 计算 `fx = float(i) / float(grid_params_.nx)`、`fy = float(j) / float(grid_params_.ny)`
    3. 计算 `r = std::sqrt((fx - 0.5f) * (fx - 0.5f) + (fy - 0.5f) * (fy - 0.5f)) * 2.0f`
    4. 期望值 `expected = std::sin(r * 20.0f) * 0.5f + 0.5f`
    5. 断言 `std::abs(p_res[k] - expected) < 1e-5f`
