# 6.6 可视化更新

#### 目标
在[[6.5 网格参数简化]]的基础上，更新 `fullscreen.frag` 和图形管线以支持非 128×128 网格的正确渲染，实现：
1. `fullscreen.frag` 使用 specialization constants 获得实际 NX/NY
2. `CreateGraphicsPipeline` 传入 specialization info

#### 规则
1. 修改 `shaders/fullscreen.frag`
    1. 使用 `layout(constant_id = 0) const uint NX = 128u;` 和 `constant_id = 1` 的 NY
    2. `main()` 中用 `uint(fragUV.x * float(NX))` 和 `uint(fragUV.y * float(NY))` 反算索引
    3. 用 `i + j * NX` 计算一维索引
    4. 输出灰度速度幅值：`float intensity = clamp(length(vec2(u, v)), 0.0, 1.0); outColor = vec4(intensity, intensity, intensity, 1.0);`

2. 修改 `src/vk_graphics.cpp` 的 `CreateGraphicsPipeline`
    1. 片段着色器阶段设置 `vk::SpecializationMapEntry` 数组——constant_id 0 offset=0 size=4, constant_id 1 offset=4 size=4
    2. 从 `cc_->grid_params()` 获取 nx/ny 构造 data vector
    3. `VkSpecializationInfo` 填入 map entries 和 data，设置到 `fragmentStage.pSpecializationInfo`

3. 确认效果
    1. 任意 NX×NY 网格均能正确渲染——fragment shader 不再硬编码 128
    2. 图形管线需在 swapchain 重建时重新创建（或已处理 NX/NY 不变的场景）
