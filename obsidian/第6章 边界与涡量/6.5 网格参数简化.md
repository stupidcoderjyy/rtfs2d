# 6.5 网格参数简化

#### 目标
在[[6.4 压力出口回流抑制]]的基础上，简化 `GridParams` 结构体，删除 `lx`/`ly` 参数，将 `dx`/`dy` 变为直接由 `nx`/`ny` 计算的常量，实现：
1. `dx = 1.0f / nx, dy = 1.0f / ny`（单位域 [0,1]×[0,1]）
2. 构造时只需传入 `(nx, ny)` 两个参数

#### 规则
1. 修改 `src/grid.h`
    1. 删除 `float lx, ly;` 成员
    2. 将 `float dx, dy;` 改为带默认初始化：`float dx = 1.0f / static_cast<float>(nx); float dy = 1.0f / static_cast<float>(ny);`
    3. 构造函数签名改为 `GridParams(int nx, int ny);`
    4. 删除 `InteriorCells()` 方法（如有）

2. 修改 `src/grid.cpp`
    1. 构造函数改为 `GridParams::GridParams(int nx, int ny): nx(nx), ny(ny) {}`——dx/dy 由默认初始化自动完成

3. 修改 `src/window.cpp`
    1. 构造调用改为 `GridParams params{128, 128};`（或其他目标分辨率）

4. 确认一致性
    1. 所有着色器已使用 `dx = 1.0 / NX`，与新的 C++ 端 `dx` 定义一致
    2. `vk_compute.cpp` 中 `alpha` 和 `alpha_p` 的计算仍用 `grid_params_.dx`，结果不变
