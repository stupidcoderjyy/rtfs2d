# 6.4 压力出口回流抑制

#### 目标
在[[6.3 边界缓冲映射修复]]的基础上，修改四个速度着色器的 `border_velocity` 函数，为压力出口（Pressure=3）添加回流检测与抑制，实现：
1. 检测面法向速度是否指向域内（回流）
2. 回流时将 ghost 法向速度置零，削弱流体倒灌

#### 规则
1. 理解回流的物理含义
    1. 压力出口应允许流体自由流出（Neumann 零梯度），但不希望外界流体倒灌
    2. 原 code 的 Pressure 分支无条件返回 `vi`，入流和出流完全对称——实际就是没做回流抑制
    3. 回流抑制的核心：检测法向速度方向，若指向域内则将 ghost 速度置零

2. 修改四个着色器的 `border_velocity` 的 case 3 分支
    1. 判断当前分量是否为法向分量：`bool is_normal = ((edge <= 1) == is_u);`——左右边的 u 分量、上下边的 v 分量为法向
    2. 切向分量保持 Neumann（`return vi`）
    3. 法向分量检测入流方向：左(edge=0)时 vi>0 为入流、右(edge=1)时 vi<0 为入流、底(edge=2)时 vi>0 为入流、顶(edge=3)时 vi<0 为入流
    4. 入流时 `return 0.0`——ghost 速度为零，面速度被压到 vi/2，大幅削弱回流
    5. 出流时 `return vi`——保持 Neumann，自由流出

3. 影响的着色器
    1. `advection.comp`——追踪越界时自然抑制回流
    2. `diffusion.comp`——扩散邻居查询时抑制回流
    3. `diverge.comp`——散度计算时使用正确的边界速度
    4. `vorticity.comp`——涡量计算时使用正确的边界速度
