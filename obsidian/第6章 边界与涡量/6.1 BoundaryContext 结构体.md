# 6.1 BoundaryContext 结构体

#### 目标
在[[第5章 流体求解器/章节总览|第5章]]基础上，创建 `BoundaryContext` 结构体，支持以归一化坐标段式设置四条边的边界条件，实现：
1. 每条边持有独立的 GPU 缓冲，每个单元格存储 `(type:uint32, u:float, v:float)` 三元组
2. `BeginSetBoundary()` / `SetBoundary()` / `EndSetBoundary()` 三段式 API
3. `EndSetBoundary()` 解析段式叠加覆盖规则后一次性上传四条边的缓冲

#### 规则
1. 创建 `src/vk_boundary.h`
    1. 声明 `enum class BoundaryDirection : uint32_t { kLeft = 0, kRight = 1, kBottom = 2, kTop = 3 };`
    2. 声明 `enum class BoundaryType : int8_t { kNoSlipWall = 0, kSlipWall = 1, kVelocity = 2, kPressure = 3 };`
    3. 声明 `struct BoundarySegment { float begin; float end; BoundaryType type; float u; float v; };`
    4. 声明构造函数 `BoundaryContext(DeviceManager& dm, const GridParams& gp);`
    5. 声明三个公有方法：`void BeginSetBoundary()`、`void SetBoundary(dir, type, begin, end, u, v)`、`void EndSetBoundary()`
    6. 声明公有 getter：`const vk::raii::Buffer& BufferAt(BoundaryDirection d) const;` 和 `uint32_t BufferSize(BoundaryDirection d) const;`
    7. 私有成员：`dm_`、`grid_params_`、`h_cell_count_`（水平边格数 = nx-2）、`v_cell_count_`（垂直边格数 = ny-2）、`h_buf_size_`、`v_buf_size_`、`std::array<std::vector<BoundarySegment>,4> segments_`、4 个 `unique_ptr<Buffer>` 和对应 `DeviceMemory`、4 个 buffer size

2. 创建 `src/vk_boundary.cpp`
    1. 构造函数中计算 cell count 和 buf size，为四条边各分配 device-local 缓冲（`kBufferUnitSize = sizeof(uint32_t)+2*sizeof(float)`），上传零初始值
    2. `BeginSetBoundary()`——清空四个方向的 segments vector
    3. `SetBoundary()`——push 一个 BoundarySegment 到对应方向的 vector
    4. `EndSetBoundary()`——对每条边：分配 `std::vector<uint8_t>` 填入默认全零（NoSlipWall），反向遍历该边的 segments 以确定每个单元格的最终类型和速度值（后调用的覆盖先调用），用 `memcpy` 逐格写入 `(type, u, v)` 三元组，最后 `UploadBufferData`

3. 在 `src/CMakeLists.txt` 中追加 `vk_boundary.h` 和 `vk_boundary.cpp`

4. 在 `ComputeContext` 构造函数中集成
    1. 创建 `boundary_ctx_` 成员（`std::make_unique<BoundaryContext>(dm, params)`）
    2. 调用 `BeginSetBoundary()`，四条边分别 `SetBoundary(kXxx, kNoSlipWall, 0, 1, 0, 0)`，调用 `EndSetBoundary()`
