# 6.1 BoundaryContext 结构体

#### 目标
在[[第5章 流体求解器/章节总览|第5章]]基础上，新建独立的 `BoundaryContext` 结构体，支持以归一化坐标段式设置任意边界的任意单元格类型和附带速度值，实现：
1. 持有 3 个拼接 GPU 缓冲：`bc_type_`（四条边的 int32_t 类型标记串联）、`bc_vel_u_` 和 `bc_vel_v_`（四条边的 float 速度分量串联）
2. `SetBoundary(direction, type, begin, end, u, v)` 支持叠加调用——每个段同时指定类型和速度，后调用的覆盖先调用的重合范围
3. `Upload()` 遍历四条边逐单元格解析最终覆盖段，同时写入类型和速度值
4. 所有单元格默认为 `kBoundaryNone`，速度默认为 `(0, 0)`

#### 规则
1. 创建 `src/vk_boundary.h`，声明 `BoundaryContext` 结构体和相关枚举及偏移常量
    1. 添加 `#ifndef RTFS2D_VK_BOUNDARY_H` / `#define` 守卫，包含 `<vulkan/vulkan_raii.hpp>`、`<cstdint>`、`<vector>`、`<array>`，前置声明 `class DeviceManager` 和 `struct GridParams`
    2. 声明 `enum class BoundaryDirection { kTop = 0, kBottom, kLeft, kRight };`
    3. 声明 `enum class BoundaryType : int32_t { kNone = 0, kNoSlipWall, kVelocityInlet, kVelocityOutlet, kPressureInlet, kPressureOutlet, kMovingWall };`
    4. 声明 `struct BoundarySegment { float begin; float end; BoundaryType type; float u; float v; };`
    5. 声明构造函数 `BoundaryContext(DeviceManager& dm, const GridParams& gp);`
    6. 声明公有方法 `void SetBoundary(BoundaryDirection dir, BoundaryType type, float begin = 0.0f, float end = 1.0f, float u = 0.0f, float v = 0.0f);`——向 `std::array<std::vector<BoundarySegment>, 4> segments_` 的对应边追加一条段记录，后调用的覆盖先调用的重合范围
    7. 声明公有方法 `void Upload();`——将 `segments_` 解析为 per-cell 的类型和速度，一次性上传三条拼接缓冲
    8. 声明公有 getter：`const vk::raii::Buffer& bc_type_buffer() const;`、`bc_vel_u_buffer()`、`bc_vel_v_buffer()`——三条拼接缓冲各一个引用
    9. 声明公有常量偏移接口——`uint32_t bc_offset(BoundaryDirection dir) const;` 返回对应边在 `bc_type_` 等缓冲中的起始偏移（上一节点数之和）以及该边单元数 `uint32_t bc_count(BoundaryDirection dir) const;`
    10. 私有成员：`DeviceManager* dm_`、`const GridParams& grid_params_`、`uint32_t top_count_`、`bottom_count_`、`left_count_`、`right_count_`、`uint32_t bc_total_count_`、`std::array<std::vector<BoundarySegment>, 4> segments_`、`std::unique_ptr<vk::raii::Buffer> bc_type_`、`bc_vel_u_`、`bc_vel_v_`、对应的 `bc_type_memory_`、`bc_vel_u_memory_`、`bc_vel_v_memory_`

2. 创建 `src/vk_boundary.cpp`，实现构造函数和 `Upload`
    1. 实现构造函数——`top_count_ = grid_params_.nx`、`bottom_count_ = nx`、`left_count_ = grid_params_.ny`、`right_count_ = ny`，`bc_total_count_ = 2 * (nx + ny)`
    2. `bc_type_`、`bc_vel_u_`、`bc_vel_v_` 各调用 `AllocateBuffer(device, physical_device, bc_total_count_ * sizeof(int32_t) 或 sizeof(float), eStorageBuffer, eDeviceLocal)` 创建
    3. 用全零 `std::vector<int32_t>` 和全零 `std::vector<float>` 初始化三个缓冲
    4. 实现 `Upload`——构造三个 `std::vector`（类型、u、v），长度各为 `bc_total_count_`。对四个方向依次填充：对每个单元格 `i`，计算归一化坐标 `t`，反向遍历 `segments_[dir]` 找到覆盖该位置的段，写入 `type`、`u`、`v`。未匹配的保持 `kNone` 和 `0.0`。最后 `UploadBufferData` 上传三个 vector

3. 在 `src/CMakeLists.txt` 中追加 `vk_boundary.h` 和 `vk_boundary.cpp`
