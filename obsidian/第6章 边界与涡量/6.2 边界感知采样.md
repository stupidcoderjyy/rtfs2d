# 6.2 边界感知采样

#### 目标
在[[6.1 BoundaryContext 结构体]]的基础上，将六个着色器的越界采样逻辑统一改为通过 BC 缓冲查询的 `border_velocity`/`border_pressure` 内联函数，实现：
1. 越界时不再简单 clamp 或返回 0，而是查询边界类型和速度/压力值
2. 四个速度着色器共享相同的 `border_velocity` 实现，两个压力着色器共享相同的 `border_pressure` 实现

#### 规则
1. 四个速度着色器（advection、diffusion、diverge、vorticity）统一添加 `border_velocity`
    1. 声明 binding 5=left、6=right、7=bottom、8=top 的 BC 缓冲（`uint` 数组，通过 `uintBitsToFloat` 转换 float）
    2. `border_velocity(float vi, bool is_u, int edge, uint local)` 函数——`bi = local*3`，按 edge 分支从对应缓冲读取 type/bc_u/bc_v
    3. 四种类型的返回值：NoSlipWall(0)→0, SlipWall(1)→法向0切向vi, Velocity(2)→预设 bc 值, Pressure(3)→vi
    4. `getU/getV` 辅助函数——正常坐标直接取缓冲值，越界时调用 `border_velocity`

2. 两个压力着色器（poisson、project）统一添加 `border_pressure`
    1. `border_pressure(float pi, int edge, int ci, int cj)` 函数——从 BC 缓冲读取类型
    2. NoSlipWall/SlipWall/Velocity→返回 pi（Neumann dp/dn=0），Pressure→返回 -pi（Dirichlet p=0）
    3. `getNeighborP/getPressure` 辅助函数——越界时调用 `border_pressure`

3. 描述符集注册中统一写入 BC 缓冲
    1. 在 `CreateDescriptorSets` 的 `sets_registry` 遍历中，所有 8 个集统一写入 binding 5→kLeft、6→kRight、7→kBottom、8→kTop
