# 6.2 边界感知采样

#### 目标
在[[6.1 BoundaryContext 结构体]]的基础上，修改 `advection.comp`、`jacobi.comp`、`diverge.comp`、`project.comp` 四个着色器中的越界邻居采样逻辑，将固定的"越界返回 0.0 或自身值"替换为通过三条拼接边界缓冲查询边界类型和附带速度值，实现：
1. 四个着色器各自新增 binding 5（拼接类型）、binding 6（拼接 u 速度）、binding 7（拼接 v 速度）
2. 每条边的起始偏移硬编码为着色器常量（`top_start=0, bottom_start=NX, left_start=2*NX, right_start=2*NX+NY`）
3. 越界时读取 `bc_type.data[edge_start + j]` 判断类型，需要速度时从 bc_vel_u/v 的相同偏移读取

#### 规则
1. 四个着色器统一添加拼接缓冲声明和偏移常量
    1. 追加 `layout(std430, binding = 5) buffer BCType { int data[]; } bc_type;`
    2. 追加 `layout(std430, binding = 6) buffer BCVelU { float data[]; } bc_vel_u;`
    3. 追加 `layout(std430, binding = 7) buffer BCVelV { float data[]; } bc_vel_v;`
    4. 声明偏移常量：`const uint TOP_START = 0u, BOTTOM_START = NX, LEFT_START = 2u * NX, RIGHT_START = 2u * NX + NY;`

2. 在 `advection.comp` 中修改反向追踪越界处理
    1. 当 `bx < 0.5f` 时计算 `int t = bc_type.data[LEFT_START + j];`：若 `t` 为 0 或 1→clamp 到 `0.5f`；若 `t` 为 2 或 3→读取 `bc_vel_u.data[LEFT_START + j]` 作为采样结果替代双线性插值；若 `t` 为 6→读取 bc_vel_u 作为结果
    2. `bx > NX-0.5f` 和 y 方向同理

3. 在 `jacobi.comp` 中修改 `getNeighbor`
    1. 越界时查询 `bc_type.data[edge_start + local_index]`：
        - 1（NoSlipWall）：`-cur.data[idx_self]`
        - 4 或 5（压力边界）：`0.0`
        - 其余：`cur.data[idx_self]`

4. 在 `diverge.comp` 中修改 `getU` 和 `getV`
    1. 越界时查询 `bc_type`：
        - 1（NoSlipWall）：`0.0`
        - 2（VelocityInlet）：读取 `bc_vel_u` 或 `bc_vel_v` 在对应偏移的值
        - 3（VelocityOutlet）：返回内部值
        - 其余：`0.0`

5. 在 `project.comp` 中修改 `getPressure`
    1. 越界时查询 `bc_type`：
        - 1（NoSlipWall）：返回 `p.data[idx_self]`（Neumann）
        - 4 或 5（压力边界）：`0.0`（Dirichlet）
        - 其余：`0.0`
