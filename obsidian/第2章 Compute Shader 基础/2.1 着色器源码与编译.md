# 2.1 着色器源码与编译

#### 目标
在第1章完成的渲染管线基础上，编写 GLSL 计算着色器并通过 CMake 编译为 SPIR-V，实现：
1. `shaders/compute.comp` 在每次构建时被 `glslc` 编译为 `compute.comp.spv`
2. 若编译失败（GLSL 语法错误），CMake 构建失败并报错

#### 规则
1. 创建 `shaders/` 子目录并编写计算着色器
    1. 在项目根目录创建 `shaders/` 文件夹
    2. 新建 `shaders/compute.comp`，第一行声明 `#version 450`
    3. 声明 workgroup 大小为 256×1×1：`layout(local_size_x = 256, local_size_y = 1, local_size_z = 1) in;`
    4. 声明一个 storage buffer 绑定点为 `set = 0, binding = 0`，使用 `std430` 布局，内含 `float values[]` 数组
    5. `main()` 中获取 `gl_GlobalInvocationID.x` 作为索引，将 `values[idx]` 赋值为 `values[idx] * 2.0`

2. 配置 CMake SPIR-V 编译规则
    1. 新建 `shaders/CMakeLists.txt`，调用 `find_program(GLSLC glslc ...)` 定位 glslc 编译器
    2. 调用 `add_custom_command` 为 `compute.comp` 生成编译规则：`OUTPUT` 为 `${CMAKE_CURRENT_BINARY_DIR}/compute.comp.spv`，`COMMAND` 为 `${GLSLC} -o <output> <input>`，`DEPENDS` 为 `compute.comp`
    3. 调用 `add_custom_target` 定义一个依赖该 `.spv` 的伪目标，并通过 `add_dependencies` 让 `rtfs2d` 依赖此目标

3. 集成到顶层构建
    1. 在顶层 `CMakeLists.txt` 中追加 `add_subdirectory(shaders)`
