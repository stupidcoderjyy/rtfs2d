# 2.1 着色器模块

#### 目标
在第1章完成的渲染管线基础上，添加 Compute Shader 的 GLSL 源码、CMake 编译规则和运行时加载机制，实现：
1. `shaders/compute.comp` 被编译为 `compute.comp.spv`，并随构建复制到可执行文件旁
2. 程序启动时从文件加载 SPIR-V 二进制，创建 `vk::raii::ShaderModule` 并存入成员变量（暂不参与渲染）

#### 规则
1. 编写 GLSL 计算着色器
    1. 在项目根目录创建 `shaders/` 文件夹
    2. 新建 `shaders/compute.comp`，第一行声明 `#version 450`
    3. 声明 workgroup 大小为 256×1×1：`layout(local_size_x = 256, local_size_y = 1, local_size_z = 1) in;`
    4. 声明一个 storage buffer 绑定点为 `set = 0, binding = 0`，使用 `std430` 布局，内含 `float values[]` 数组
    5. `main()` 中获取 `gl_GlobalInvocationID.x` 作为索引，将 `values[idx]` 赋值为 `values[idx] * 2.0`

2. 配置 CMake SPIR-V 编译
    1. 在顶层 `CMakeLists.txt` 中调用 `find_program(GLSLC glslc HINTS "$ENV{VULKAN_SDK}/Bin")` 定位 glslc 编译器
    2. 调用 `add_custom_command` 为 `compute.comp` 生成编译规则：OUTPUT 为 `${CMAKE_CURRENT_BINARY_DIR}/shaders/compute.comp.spv`，COMMAND 为 `${GLSLC} -o <output> <input>`，DEPENDS 为 `shaders/compute.comp`
    3. 调用 `add_custom_target` 定义一个依赖该 `.spv` 的伪目标（如 `CompileShaders`），并通过 `add_dependencies` 让 `${PROJECT_NAME}` 依赖此目标

3. 在 Window 类中加载着色器模块
    1. 在 `Window.h` 中添加 `std::unique_ptr<vk::raii::ShaderModule> compute_shader_module_` 成员
    2. 在 `Window.h` 中声明 `void CreateShaderModule()` 私有方法
    3. 在 `Window.cpp` 中实现 `CreateShaderModule()`：使用 `std::ifstream` 以二进制模式打开 `shaders/compute.comp.spv`，通过 `std::vector<uint32_t>` 存储全部字节（将 `char` buffer 按 4 字节对齐拷贝至 `uint32_t` vector）
    4. 构造 `vk::ShaderModuleCreateInfo`，调用 `setCodeSize(spv_bytes)` 和 `setPCode(spv.data())`
    5. 调用 `device_->createShaderModule(ci)` 返回 `vk::raii::ShaderModule`，以 `std::make_unique` 包装后赋值给 `compute_shader_module_`

4. 集成到初始化流程
    1. 在 `Show()` 中，`CreateImageViews()` 调用之后、`CreateRenderPass()` 之前插入 `CreateShaderModule()`
