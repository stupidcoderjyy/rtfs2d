# 2.4 调度与回读

#### 目标
在 [[2.3 描述符集与计算管线]] 的基础上调度 compute shader 执行并将结果回读到 CPU 端验证，实现：
1. 在渲染循环的每帧中，先 dispatch compute shader 将 storage buffer 中的值翻倍，再执行图形清屏
2. 程序启动后第一帧之后，将 storage buffer 通过 staging buffer 回读至 CPU，验证 `values[i] == float(i) * 2.0f`，并将验证结果打印到控制台

#### 规则
1. 创建 compute 专用命令池
    1. 在 `Window.h` 中添加 `std::unique_ptr<vk::raii::CommandPool> compute_command_pool_` 成员
    2. 在 `Window.h` 中声明 `void CreateComputeCommandPool()` 私有方法
    3. 在 `Window.cpp` 中实现：构造 `vk::CommandPoolCreateInfo`，设置 `setQueueFamilyIndex(graphics_queue_family_index_)`、`setFlags(vk::CommandPoolCreateFlagBits::eResetCommandBuffer)`
    4. 调用 `device_->createCommandPool(ci)` 返回 `vk::raii::CommandPool`，以 `std::make_unique` 包装存入 `compute_command_pool_`

2. 录制 compute 命令缓冲
    1. 在 `Window.h` 中添加 `std::unique_ptr<vk::raii::CommandBuffer> compute_command_buffer_` 成员
    2. 在 `Window.h` 中声明 `void RecordComputeCommands()` 私有方法
    3. 在 `Window.cpp` 中实现：构造 `vk::CommandBufferAllocateInfo`，设置 `setCommandPool(*compute_command_pool_)`、`setCommandBufferCount(1)`、`setLevel(ePrimary)`
    4. 调用 `device_->allocateCommandBuffers(ai)` 返回 `vector`，取 `[0]` 以 `std::make_unique` 包装存入 `compute_command_buffer_`
    5. 调用 `cb.begin({vk::CommandBufferUsageFlagBits::eSimultaneousUse})`
    6. 调用 `cb.bindPipeline(vk::PipelineBindPoint::eCompute, **compute_pipeline_)`
    7. 调用 `cb.bindDescriptorSets(vk::PipelineBindPoint::eCompute, **pipeline_layout_, 0, **descriptor_set_, nullptr)`
    8. 计算 workgroup 数量为 `(kStorageElementCount + 255) / 256`，调用 `cb.dispatch(group_count, 1, 1)`
    9. 在 dispatch 之后添加内存屏障，确保 compute 写入对后续 host 读取可见：构造 `vk::BufferMemoryBarrier`，设置 `setSrcAccessMask(vk::AccessFlagBits::eShaderWrite)`、`setDstAccessMask(vk::AccessFlagBits::eHostRead)`、`setBuffer(**storage_buffer_)`、`setSize(kStorageBufferSize)`、`setSrcQueueFamilyIndex(VK_QUEUE_FAMILY_IGNORED)`、`setDstQueueFamilyIndex(VK_QUEUE_FAMILY_IGNORED)`
    10. 调用 `cb.pipelineBarrier(vk::PipelineStageFlagBits::eComputeShader, vk::PipelineStageFlagBits::eHost, {}, nullptr, nullptr, barrier)`
    11. 调用 `cb.end()`

3. 在渲染循环中调度 compute
    1. 在 `Show()` 的主循环中，`device_->resetFences(**fence)` 之后、`acquireNextImage` 之前插入 compute 提交
    2. 构造 `vk::SubmitInfo`：设置 `setCommandBuffers(*compute_command_buffer_)`
    3. 调用 `graphics_queue_->submit(si)` 提交 compute 工作（不设 fence，直接 `waitIdle` 同步）
    4. 调用 `graphics_queue_->waitIdle()` 等待 compute 完成

4. 回读 storage buffer 到 CPU
    1. 在 `Window.h` 中声明 `void ReadBackAndVerify()` 私有方法
    2. 在 `Window.cpp` 中实现：构造 `vk::BufferCreateInfo` 创建读回用 staging buffer，设置 `setSize(kStorageBufferSize)`、`setUsage(vk::BufferUsageFlagBits::eTransferDst)`、`setSharingMode(eExclusive)`
    3. 通过 `FindMemoryType` 选择 `eHostVisible | eHostCoherent` 类型并 `allocateMemory`、`bindMemory`
    4. 分配一个临时 command buffer，录制 `cb.copyBuffer(**storage_buffer_, *staging_buffer, copy_region)`，提交到 `graphics_queue_` 后 `waitIdle()`
    5. 调用 `staging_memory.mapMemory(0, kStorageBufferSize)` 获取 `void*` 指针，转为 `const float*`
    6. 遍历 `0` 到 `1023`，检查 `values[i]` 是否等于 `static_cast<float>(i) * 2.0f`（可容忍微小浮点误差），用 `spdlog::info` 打印前 8 个值和验证结果
    7. 调用 `staging_memory.unmapMemory()`
    8. 注意：此方法只在第一帧之后调用一次，可用 `static bool verified = false` 控制

5. 集成到初始化与渲染流程
    1. 在 `Show()` 中，`CreateDescriptorSet()` 之后插入 `CreateComputeCommandPool()`、`RecordComputeCommands()`
    2. 在 compute `submit` + `waitIdle` 之后、`acquireNextImage` 之前，检查是否首次验证（可用成员变量 `bool compute_verified_ = false`），若否则调用 `ReadBackAndVerify()` 并置 `compute_verified_ = true`
