# 2.8 调度执行

#### 目标
在 [[2.7 描述符集]] 的基础上，在渲染循环中调度 compute shader 执行，实现：
1. 每帧在图形渲染之前，先 dispatch compute shader 将 storage buffer 中的值翻倍
2. 利用管线屏障确保 compute 写入对主机可见

#### 规则
1. 添加成员与声明
    1. 在 `Window.h` 中添加 `std::unique_ptr<vk::raii::CommandPool> compute_command_pool_` 成员
    2. 在 `Window.h` 中添加 `std::unique_ptr<vk::raii::CommandBuffer> compute_command_buffer_` 成员
    3. 在 `Window.h` 中声明 `void CreateComputeCommandPool()` 和 `void RecordComputeCommands()` 私有方法

2. 实现 `CreateComputeCommandPool()`
    1. 构造 `vk::CommandPoolCreateInfo` 变量 `cp_ci`，设置 `cp_ci.setQueueFamilyIndex(graphics_queue_family_index_)`、`cp_ci.setFlags(vk::CommandPoolCreateFlagBits::eResetCommandBuffer)`
    2. 调用 `device_->createCommandPool(cp_ci)` 获得 `vk::raii::CommandPool`，以 `std::make_unique` 包装存入 `compute_command_pool_`

3. 实现 `RecordComputeCommands()`
    1. 构造 `vk::CommandBufferAllocateInfo`，设置 `setCommandPool(*compute_command_pool_)`、`setCommandBufferCount(1)`、`setLevel(ePrimary)`
    2. 调用 `device_->allocateCommandBuffers(ai)` 获得 vector，取 `cbs[0]` 以 `std::move` 转移并 `std::make_unique` 包装存入 `compute_command_buffer_`
    3. 调用 `cb.begin({vk::CommandBufferUsageFlagBits::eSimultaneousUse})`
    4. 调用 `cb.bindPipeline(vk::PipelineBindPoint::eCompute, **compute_pipeline_)`
    5. 调用 `cb.bindDescriptorSets(vk::PipelineBindPoint::eCompute, **pipeline_layout_, 0, **descriptor_set_, nullptr)`
    6. 计算 workgroup 数量 `int group_count = (kStorageElementCount + 255) / 256`，调用 `cb.dispatch(group_count, 1, 1)`
    7. 构造 `vk::BufferMemoryBarrier` 变量 `barrier`，设置 `setSrcAccessMask(vk::AccessFlagBits::eShaderWrite)`、`setDstAccessMask(vk::AccessFlagBits::eHostRead)`、`setBuffer(**storage_buffer_)`、`setSize(kStorageBufferSize)`、`setOffset(0)`、`setSrcQueueFamilyIndex(VK_QUEUE_FAMILY_IGNORED)`、`setDstQueueFamilyIndex(VK_QUEUE_FAMILY_IGNORED)`
    8. 调用 `cb.pipelineBarrier(vk::PipelineStageFlagBits::eComputeShader, vk::PipelineStageFlagBits::eHost, {}, nullptr, barrier, nullptr)`
    9. 调用 `cb.end()`

4. 在渲染循环中提交 compute 工作
    1. 在 `Show()` 主循环中，`device_->resetFences(**fence)` 之后插入 compute 提交
    2. 构造 `vk::SubmitInfo` 变量 `c_si`，设置 `c_si.setCommandBuffers(**compute_command_buffer_)`
    3. 调用 `graphics_queue_->submit(c_si)` 提交 compute 工作
    4. 调用 `graphics_queue_->waitIdle()` 等待 compute 完成
    5. 此后继续原有的 `acquireNextImage` 和图形提交流程不变

5. 集成到初始化流程
    1. 在 `Show()` 中，`CreateDescriptorSet()` 之后插入 `CreateComputeCommandPool()`、`RecordComputeCommands()`
