# 第2章 Compute Shader 基础

**目标**：在第1章完成的图形渲染管线基础上，引入 Compute Shader 与 Storage Buffer，打通 GPU 通用计算能力。

每个谜题的产物是当前阶段可以编译运行的程序。从 2.1 到 2.5 渐进构建，最终得到一个能通过 Compute Shader 在 GPU 上执行并行计算、并用图形管线将结果可视化渲染的 Vulkan 应用。

---

## 摘要

本章从 GLSL 计算着色器的编写与编译开始，逐步引入 Vulkan 通用计算的核心组件：SPIR-V 着色器模块、存储缓冲（Storage Buffer）、描述符集布局与管线布局、计算管线。最后将所有组件串联，通过命令缓冲调度计算着色器执行，利用管线屏障进行同步，并将结果从 GPU 映射回 CPU 端验证。作为收尾，引入全屏三角形图形管线，用片段着色器实现逐像素彩色渲染，为后续的流场可视化奠定基础。

Compute Shader 与图形管线独立运行，但在同一 vk::raii::Device 上共享队列资源。本章用单独的命令池存放 compute 指令，并用独立的管线屏障处理计算到图形的同步。
