# 2.9 回读验证

#### 目标
在 [[2.8 调度执行]] 的基础上，将 storage buffer 回读到 CPU 并验证 compute shader 执行结果，实现：
1. 程序启动后第一帧执行完毕时，`values[i] == float(i) * 2.0f` 验证通过
2. 验证结果打印到控制台

#### 规则
1. 添加成员与声明
    1. 在 `window.h` 中添加 `bool compute_verified_ = false` 成员，用于控制只验证一次
    2. 在 `window.h` 中声明 `void ReadBackAndVerify() const` 私有方法

2. 实现 `ReadBackAndVerify()`
    1. 构造 `vk::BufferCreateInfo`，设置 `setSize(kStorageBufferSize)`、`setUsage(vk::BufferUsageFlagBits::eTransferDst)`、`setSharingMode(eExclusive)`
    2. 调用 `device_->createBuffer(ci)` 获得临时 `staging_buf`（`vk::raii::Buffer`，非指针包装）
    3. 调用 `staging_buf.getMemoryRequirements()` 直接获得 `mr`
    4. 调用 `FindMemoryType(mr.memoryTypeBits, vk::MemoryPropertyFlagBits::eHostVisible | eHostCoherent)` 获得内存类型索引 `mti`
    5. 构造 `vk::MemoryAllocateInfo`，设置 `setAllocationSize(mr.size)`、`setMemoryTypeIndex(mti)`
    6. 调用 `device_->allocateMemory(m_ai)` 获得临时 `staging_mem`（`vk::raii::DeviceMemory`）
    7. 调用 `staging_buf.bindMemory(*staging_mem, 0)` 绑定
    8. 从 `compute_command_pool_` 分配临时 command buffer：构造 `vk::CommandBufferAllocateInfo`，设置 `setCommandPool(*compute_command_pool_)`、`setCommandBufferCount(1)`、`setLevel(ePrimary)`；调用 `device_->allocateCommandBuffers(ai)` 获得 vector，取 `front()` 引用；`cb.begin({eOneTimeSubmit})`；构造 `vk::BufferCopy`（`setSrcOffset(0)`、`setSize(kStorageBufferSize)`，dstOffset 默认为 0）；调用 `cb.copyBuffer(**storage_buffer_, *staging_buf, copy)`；`cb.end()`；构造 `vk::SubmitInfo` 设置 `setCommandBuffers(*cb)`；调用 `graphics_queue_->submit(si)` 后 `graphics_queue_->waitIdle()`
    9. 调用 `staging_mem.mapMemory(0, kStorageBufferSize)` 获得 `void*`，`static_cast<float*>` 转为 `float*`
    10. 遍历 `i` 从 `0` 到 `1023`，若 `std::abs(p_res[i] - static_cast<float>(i) * 2.0f) > 1e-5f`，则调用 `spdlog::warn` 打印索引和 delta，并将 `pass` 置为 `false`
    11. 若 `pass` 为 `true`，调用 `spdlog::info` 打印 `"All values match within tolerance"`
    12. 调用 `staging_mem.unmapMemory()`

3. 集成到渲染循环
    1. 在 `Show()` 的 compute `submit` + `waitIdle` 之后、`acquireNextImage` 之前，检查 `!compute_verified_`，若为真则调用 `ReadBackAndVerify()` 并置 `compute_verified_ = true`
