# 2.9 回读验证

#### 目标
在 [[2.8 调度执行]] 的基础上，将 storage buffer 回读到 CPU 并验证 compute shader 执行结果，实现：
1. 程序启动后第一帧执行完毕时，`values[i] == float(i) * 2.0f` 验证通过
2. 验证结果打印到控制台（前 8 个值和 overall pass/fail）

#### 规则
1. 添加声明
    1. 在 `Window.h` 中声明 `void ReadBackAndVerify()` 私有方法
    2. 在 `Window.h` 中添加 `bool compute_verified_ = false` 成员用于控制只验证一次

2. 实现 `ReadBackAndVerify()`
    1. 构造 `vk::BufferCreateInfo`，设置 `setSize(kStorageBufferSize)`、`setUsage(vk::BufferUsageFlagBits::eTransferDst)`、`setSharingMode(eExclusive)`
    2. 调用 `device_->createBuffer(ci)` 创建临时 `staging_buffer`
    3. 通过 `FindMemoryType` 选择 `eHostVisible | eHostCoherent` 类型并分配、绑定 memory
    4. 分配临时 command buffer，录制 `cb.copyBuffer(**storage_buffer_, *staging_buffer, copy_region)`，`begin`、`end`、`submit`、`waitIdle`
    5. 调用 `staging_memory.mapMemory(0, kStorageBufferSize)` 获取 `void*`，转为 `const float*`
    6. 遍历 `0` 到 `1023`，检查 `values[i]` 是否等于 `static_cast<float>(i) * 2.0f`（容忍 `1e-5` 的浮点误差）
    7. 用 `spdlog::info` 打印前 8 个值和验证结论（全部通过则打印 `Compute verification passed`，否则打印首个失败索引和期望值/实际值）
    8. 调用 `staging_memory.unmapMemory()`

3. 集成到渲染循环
    1. 在 `Show()` 的 compute `submit` + `waitIdle` 之后、`acquireNextImage` 之前，检查 `!compute_verified_`，若为真则调用 `ReadBackAndVerify()` 并置 `compute_verified_ = true`
