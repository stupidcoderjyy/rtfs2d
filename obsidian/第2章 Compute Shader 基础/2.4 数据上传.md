# 2.4 数据上传

#### 目标
在 [[2.3 存储缓冲]] 的基础上，通过 staging buffer 将初始数据上传至 GPU 端存储缓冲，实现：
1. 将 `static_cast<float>(i)`（`i` 从 `0` 到 `1023`）写入 GPU 端 storage buffer
2. 上传完成后 staging buffer 自动销毁（RAII），不残留临时资源

#### 规则
1. 实现 `CreateStagingBuffer()`
    1. 填充 [[2.3 存储缓冲]] 中声明的 `CreateStagingBuffer` 方法体：参数为两个 `std::unique_ptr` 的引用，用于输出创建的 buffer 和 memory
    2. 构造 `vk::BufferCreateInfo`，设置 `setSize(kStorageBufferSize)`、`setUsage(vk::BufferUsageFlagBits::eTransferSrc)`、`setSharingMode(eExclusive)`
    3. 调用 `device_->createBuffer(ci)` 获得 `vk::raii::Buffer`，以 `std::make_unique` 赋给 `staging_buffer` 输出参数
    4. 构造 `vk::DeviceBufferMemoryRequirements`，调用 `setPCreateInfo(&ci)`；调用 `device_->getBufferMemoryRequirements(bmr).memoryRequirements` 获得 `mr`
    5. 调用 `FindMemoryType(mr.memoryTypeBits, vk::MemoryPropertyFlagBits::eHostVisible | eHostCoherent)` 获得内存类型索引
    6. 构造 `vk::MemoryAllocateInfo`，设置 `setAllocationSize(mr.size)`、`setMemoryTypeIndex(返回的索引)`；调用 `device_->allocateMemory(ai)` 获得 `vk::raii::DeviceMemory`，以 `std::make_unique` 赋给 `staging_memory` 输出参数
    7. 调用 `staging_buffer->bindMemory(**staging_memory, 0)` 绑定
    8. 调用 `staging_memory->mapMemory(0, kStorageBufferSize)` 获得 `void*` 指针
    9. 创建 `float arr[1024]` 栈数组，循环 `i` 从 `0` 到 `1023`，赋值 `arr[i] = static_cast<float>(i)`
    10. 调用 `std::memcpy(mp, arr, kStorageBufferSize)` 写入数据后 `staging_memory->unmapMemory()`

2. 实现 `RecordStorageCommand()`
    1. 填充 [[2.3 存储缓冲]] 中声明的 `RecordStorageCommand` 方法体：参数为 staging buffer 的 `unique_ptr` 引用
    2. 构造 `vk::CommandBufferAllocateInfo`，设置 `setCommandPool(**command_pool_)`、`setCommandBufferCount(1)`、`setLevel(ePrimary)`
    3. 调用 `device_->allocateCommandBuffers(ai)` 获得 `std::vector<vk::raii::CommandBuffer>`，取 `front()` 引用
    4. 调用 `cb.begin({vk::CommandBufferUsageFlagBits::eOneTimeSubmit})`
    5. 构造 `vk::BufferCopy`，设置 `setSrcOffset(0)`、`setDstOffset(0)`、`setSize(kStorageBufferSize)`
    6. 调用 `cb.copyBuffer(**staging_buffer, **storage_buffer_, copy_region)`
    7. 调用 `cb.end()`
    8. 构造 `vk::SubmitInfo`，设置 `setCommandBuffers(*cb)`
    9. 调用 `graphics_queue_->submit(si)` 提交拷贝命令，再调用 `graphics_queue_->waitIdle()` 等待完成

3. 无需额外集成——两个方法已在 `CreateStorageBuffer()` 末尾被调用
