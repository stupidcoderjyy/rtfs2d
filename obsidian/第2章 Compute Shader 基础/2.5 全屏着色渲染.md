# 2.5 全屏着色渲染

#### 目标
在 [[2.4 调度与回读]] 的基础上，用全屏三角形 + 图形管线替代纯清屏渲染，实现：
1. 每帧执行 compute shader 翻倍 storage buffer 后，通过 fragment shader 将屏幕坐标映射为随时间横向波浪位移的彩色图案
2. 窗口显示周期性左右摇摆的彩色波纹，呈现循环保持 60FPS V-Sync

#### 规则
1. 编写全屏三角形顶点着色器
    1. 新建 `shaders/fullscreen.vert`，声明 `#version 450`
    2. 声明硬编码的三角形顶点数组 `vec2 positions[3]`，三个顶点分别为 `(-1,-1)`、`(3,-1)`、`(-1,3)`，覆盖整个 NDC 空间
    3. 声明 `layout(location = 0) out vec2 fragUV`，将 `positions[gl_VertexIndex] * 0.5 + 0.5` 写入 `fragUV`
    4. 将 `gl_Position` 设为 `vec4(positions[gl_VertexIndex], 0.0, 1.0)`

2. 编写全屏片段着色器（含波浪位移）
    1. 新建 `shaders/fullscreen.frag`，声明 `#version 450`
    2. 声明 `layout(location = 0) in vec2 fragUV` 和 `layout(location = 0) out vec4 outColor`
    3. 声明 push constant 块：`layout(push_constant) uniform PushConstants { float time; } pc;`
    4. `main()` 中先计算横向波浪位移：`float wave = sin(fragUV.y * 12.0 + pc.time * 2.5) * 0.06`，得到位移后的坐标 `vec2 uv = fragUV + vec2(wave, 0.0)`
    5. 将 `uv` 映射为彩色图案：`vec3 color = 0.5 + 0.5 * cos(uv.x * 20.0 + uv.y * 15.0 + vec3(0.0, 2.09439, 4.18879))`，输出 `outColor = vec4(color, 1.0)`

3. 扩展 CMake 编译规则
    1. 在 `add_custom_command` 中增加 `fullscreen.vert` 和 `fullscreen.frag` 的 `OUTPUT` 和 `COMMAND`（每对 `.vert`/`.frag` 单独调用 `glslc`），`DEPENDS` 包含对应源文件
    2. 确保 `CompileShaders` 目标一并依赖新增的 `.spv` 文件

4. 创建图形管线所需的 Vulkan 对象
    1. 在 `Window.h` 中添加 `std::unique_ptr<vk::raii::ShaderModule> vert_shader_module_` 和 `frag_shader_module_` 成员
    2. 在 `Window.h` 中添加 `std::unique_ptr<vk::raii::PipelineLayout> graphics_pipeline_layout_` 和 `std::unique_ptr<vk::raii::Pipeline> graphics_pipeline_` 成员
    3. 声明 `CreateGraphicsPipeline()` 私有方法

5. 实现 `CreateGraphicsPipeline()`
    1. 读取 `fullscreen.vert.spv` 和 `fullscreen.frag.spv`，分别创建 `vk::raii::ShaderModule` 存入 `vert_shader_module_` 和 `frag_shader_module_`
    2. 构造两个 `vk::PipelineShaderStageCreateInfo`：分别 `setStage(eVertex)`/`setStage(eFragment)`、`setModule(**vert_shader_module_)`/`setModule(**frag_shader_module_)`、`setPName("main")`
    3. 构造 `vk::PipelineVertexInputStateCreateInfo`：不设顶点绑定和属性（全屏三角形用硬编码顶点），`setVertexBindingDescriptionCount(0)`、`setVertexAttributeDescriptionCount(0)`
    4. 构造 `vk::PipelineInputAssemblyStateCreateInfo`：`setTopology(vk::PrimitiveTopology::eTriangleList)`、`setPrimitiveRestartEnable(VK_FALSE)`
    5. 构造 `vk::PipelineViewportStateCreateInfo`：`setViewportCount(1)`、`setScissorCount(1)`，使用动态 viewport 和 scissor（`vk::DynamicState::eViewport`、`eScissor`）
    6. 构造 `vk::PipelineRasterizationStateCreateInfo`：`setPolygonMode(eFill)`、`setCullMode(eNone)`、`setFrontFace(eClockwise)`、`setLineWidth(1.0f)`
    7. 构造 `vk::PipelineMultisampleStateCreateInfo`：`setRasterizationSamples(e1)`
    8. 构造 `vk::PipelineColorBlendAttachmentState`：`setBlendEnable(VK_FALSE)`、`setColorWriteMask(R | G | B | A)`
    9. 构造 `vk::PipelineColorBlendStateCreateInfo`：`setAttachmentCount(1)`、`setPAttachments(&blend_attachment)`
    10. 构造 `vk::PipelineDynamicStateCreateInfo`：`setDynamicStates({eViewport, eScissor})`
    11. 构造 `vk::PushConstantRange`，设置 `setStageFlags(vk::ShaderStageFlagBits::eFragment)`、`setOffset(0)`、`setSize(sizeof(float))`
    12. 构造 `vk::PipelineLayoutCreateInfo`，设置 `setPushConstantRangeCount(1)`、`setPPushConstantRanges(&push_constant_range)`，以 `std::make_unique` 包装存入 `graphics_pipeline_layout_`
    13. 构造 `vk::GraphicsPipelineCreateInfo`，设置上述所有结构体字段，`setRenderPass(**render_pass_)`、`setSubpass(0)`
    14. 调用 `device_->createGraphicsPipeline(nullptr, ci)` 返回 `vk::raii::Pipeline`，以 `std::make_unique` 包装存入 `graphics_pipeline_`

6. 修改 `RecordCommands` 使用图形管线并传入时间
    1. 在 `cb.beginRenderPass` 之前增加 viewport 和 scissor 的设置：
       构造 `vk::Viewport`，设置 `x=0`、`y=0`、`width=swapchain_extent_.width`、`height=swapchain_extent_.height`、`minDepth=0`、`maxDepth=1`，调用 `cb.setViewport(0, viewport)`
       构造 `vk::Rect2D scissor`，设置 `offset={0,0}`、`extent=swapchain_extent_`，调用 `cb.setScissor(0, scissor)`
    2. 调用 `cb.bindPipeline(vk::PipelineBindPoint::eGraphics, **graphics_pipeline_)`
    3. 获取当前时间 `float t = static_cast<float>(glfwGetTime())`，调用 `cb.pushConstants<float>(**graphics_pipeline_layout_, vk::ShaderStageFlagBits::eFragment, 0, t)` 将时间推入 fragment shader 的 push constant
    4. 调用 `cb.draw(3, 1, 0, 0)` 绘制全屏三角形
    5. 删除原有的 `clear_value` 逻辑（`vk::ClearValue` 仍需要但颜色不随时间变化，设为黑色即可）

7. 集成到初始化流程
    1. 在 `Show()` 中 `CreateComputePipeline()` 之后插入 `CreateGraphicsPipeline()`
    2. 更新 `RecordCommands` 签名无需改动，内部改为 bind `graphics_pipeline_`、push time、draw
