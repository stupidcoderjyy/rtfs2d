# 2.2 存储缓冲

#### 目标
在 [[2.1 着色器模块]] 的基础上创建 Storage Buffer 并通过 staging buffer 上传初始数据，实现：
1. GPU 端分配一块 `1024 * sizeof(float)` 的设备本地内存，用于 compute shader 读写
2. 通过 staging buffer 将 `0` 到 `1023` 的浮点值上传至该缓冲区
3. 验证层无报错，缓冲区创建成功

#### 规则
1. 添加内存类型查询辅助
    1. 在 `Window.h` 中声明私有静态方法 `static uint32_t FindMemoryType(vk::PhysicalDevice pd, uint32_t typeFilter, vk::MemoryPropertyFlags properties)`
    2. 在 `Window.cpp` 中实现：调用 `pd.getMemoryProperties()` 获取 `memoryProperties`，遍历 `memoryTypes` 查找同时满足 `(typeFilter & (1 << i))` 和 `(properties == memoryProperties.memoryTypes[i].propertyFlags)` 的索引，找到则返回，否则抛出 `std::runtime_error`

2. 创建存储缓冲
    1. 在 `Window.h` 中添加 `std::unique_ptr<vk::raii::Buffer> storage_buffer_` 和 `std::unique_ptr<vk::raii::DeviceMemory> storage_memory_` 成员
    2. 在 `Window.h` 中添加 `static constexpr uint32_t kStorageElementCount = 1024` 和 `static constexpr vk::DeviceSize kStorageBufferSize = kStorageElementCount * sizeof(float)` 常量
    3. 在 `Window.h` 中声明 `void CreateStorageBuffer()` 私有方法
    4. 在 `Window.cpp` 中实现 `CreateStorageBuffer()`：构造 `vk::BufferCreateInfo`，设置 `setSize(kStorageBufferSize)`、`setUsage(vk::BufferUsageFlagBits::eStorageBuffer | vk::BufferUsageFlagBits::eTransferDst | vk::BufferUsageFlagBits::eTransferSrc)`、`setSharingMode(vk::SharingMode::eExclusive)`
    5. 调用 `device_->createBuffer(ci)` 返回 `vk::raii::Buffer`，以 `std::make_unique` 包装存入 `storage_buffer_`
    6. 调用 `device_->getBufferMemoryRequirements(*storage_buffer_)` 获取 `mem_req`
    7. 构造 `vk::MemoryAllocateInfo`：设置 `setAllocationSize(mem_req.size)`、`setMemoryTypeIndex(FindMemoryType(physical_device_, mem_req.memoryTypeBits, vk::MemoryPropertyFlagBits::eDeviceLocal))`
    8. 调用 `device_->allocateMemory(ai)` 返回 `vk::raii::DeviceMemory`，以 `std::make_unique` 包装存入 `storage_memory_`
    9. 调用 `storage_buffer_->bindMemory(**storage_memory_, 0)` 绑定缓冲与内存

3. 创建 staging buffer 并上传数据
    1. 在 `CreateStorageBuffer()` 中继续：构造第二个 `vk::BufferCreateInfo`，设置 `setSize(kStorageBufferSize)`、`setUsage(vk::BufferUsageFlagBits::eTransferSrc)`、`setSharingMode(eExclusive)`
    2. 调用 `device_->createBuffer(ci)` 创建临时 staging buffer
    3. 调用 `device_->getBufferMemoryRequirements(staging_buffer)` 后，通过 `FindMemoryType` 选择 `eHostVisible | eHostCoherent` 类型并 `allocateMemory`
    4. 调用 `staging_buffer.bindMemory(*staging_memory, 0)`
    5. 调用 `staging_memory.mapMemory(0, kStorageBufferSize)` 获取 `void*` 指针，用 `std::memcpy` 将 `0` 到 `1023` 的 `float` 值写入后 `unmapMemory`

4. 录制一次性拷贝命令
    1. 构造 `vk::CommandBufferAllocateInfo`：`setCommandPool(*command_pool_)`、`setCommandBufferCount(1)`、`setLevel(ePrimary)`
    2. 调用 `device_->allocateCommandBuffers(ai)` 获取一个临时 command buffer
    3. 调用 `cb.begin({vk::CommandBufferUsageFlagBits::eOneTimeSubmit})`
    4. 构造 `vk::BufferCopy`，设置 `setSize(kStorageBufferSize)`、`setSrcOffset(0)`、`setDstOffset(0)`
    5. 调用 `cb.copyBuffer(*staging_buffer, **storage_buffer_, copy_region)`
    6. 调用 `cb.end()`
    7. 构造 `vk::SubmitInfo`，设置 `setCommandBuffers(*cb)`
    8. 调用 `graphics_queue_->submit(si)` 提交（此处不设 fence 和 semaphore，同步用 queue waitIdle）
    9. 调用 `graphics_queue_->waitIdle()` 等待拷贝完成
    10. `staging_buffer` 和其 memory 在作用域结束时自动销毁（RAII）

5. 集成到初始化流程
    1. 在 `Show()` 中，`CreateShaderModule()` 之后、`CreateRenderPass()` 之前插入 `CreateStorageBuffer()`
