# 2.10 全屏着色渲染

#### 目标
在 [[2.9 回读验证]] 的基础上，用全屏三角形 + 图形管线 + push constants 替代纯色清屏，实现：
1. 每帧先执行 compute shader，再通过 fragment shader 渲染横向波浪位移的彩色图案
2. 窗口显示周期性左右摇摆的彩色波纹，呈现循环保持 60FPS V-Sync

#### 规则
1. 编写全屏三角形顶点着色器
    1. 新建 `shaders/fullscreen.vert`，声明 `#version 450`
    2. 声明硬编码的三角形顶点数组 `vec2 positions[3]`，三个顶点分别为 `(-1,-1)`、`(3,-1)`、`(-1,3)`，覆盖整个 NDC 空间
    3. 声明 `layout(location = 0) out vec2 fragUV`，将 `positions[gl_VertexIndex] * 0.5 + 0.5` 写入 `fragUV`
    4. 将 `gl_Position` 设为 `vec4(positions[gl_VertexIndex], 0.0, 1.0)`

2. 编写全屏片段着色器（含波浪位移）
    1. 新建 `shaders/fullscreen.frag`，声明 `#version 450`
    2. 声明 `layout(location = 0) in vec2 fragUV` 和 `layout(location = 0) out vec4 outColor`
    3. 声明 push constant 块：`layout(push_constant) uniform PushConstants { float time; } pc;`
    4. `main()` 中先计算横向波浪位移：`float wave = sin(fragUV.y * 12.0 + pc.time * 2.5) * 0.06`，得到 `vec2 uv = fragUV + vec2(wave, 0.0)`
    5. 将 `uv` 映射为彩色图案：`vec3 color = 0.5 + 0.5 * cos(uv.x * 20.0 + uv.y * 15.0 + vec3(0.0, 2.09439, 4.18879))`，输出 `outColor = vec4(color, 1.0)`

3. 更新 CMake 编译规则
    1. 在 `shaders/CMakeLists.txt` 的 `SHADER_SOURCES` 列表中追加 `fullscreen.vert` 和 `fullscreen.frag`（由现有的 foreach 循环自动处理编译）

4. 添加成员与声明
    1. 在 `Window.h` 中添加 `std::unique_ptr<vk::raii::ShaderModule> vert_shader_module_` 和 `frag_shader_module_` 成员
    2. 在 `Window.h` 中添加 `std::unique_ptr<vk::raii::PipelineLayout> graphics_pipeline_layout_` 和 `std::unique_ptr<vk::raii::Pipeline> graphics_pipeline_` 成员
    3. 在 `Window.h` 中声明 `void CreateGraphicsPipeline()` 私有方法

5. 实现 `CreateGraphicsPipeline()`
    1. 分别读取 `fullscreen.vert.spv` 和 `fullscreen.frag.spv`，创建 `vk::raii::ShaderModule` 存入对应成员
    2. 构造两个 `vk::PipelineShaderStageCreateInfo`：分别 `setStage(eVertex)`/`setStage(eFragment)`、`setModule(...)`、`setPName("main")`
    3. 构造 `vk::PipelineVertexInputStateCreateInfo`：`setVertexBindingDescriptionCount(0)`、`setVertexAttributeDescriptionCount(0)`
    4. 构造 `vk::PipelineInputAssemblyStateCreateInfo`：`setTopology(eTriangleList)`、`setPrimitiveRestartEnable(VK_FALSE)`
    5. 构造 `vk::PipelineViewportStateCreateInfo`：`setViewportCount(1)`、`setScissorCount(1)`
    6. 构造 `vk::PipelineRasterizationStateCreateInfo`：`setPolygonMode(eFill)`、`setCullMode(eNone)`、`setFrontFace(eClockwise)`、`setLineWidth(1.0f)`
    7. 构造 `vk::PipelineMultisampleStateCreateInfo`：`setRasterizationSamples(e1)`
    8. 构造 `vk::PipelineColorBlendAttachmentState`：`setBlendEnable(VK_FALSE)`、`setColorWriteMask(R | G | B | A)`
    9. 构造 `vk::PipelineColorBlendStateCreateInfo`：`setAttachmentCount(1)`、`setPAttachments(&blend_attachment)`
    10. 构造 `vk::PipelineDynamicStateCreateInfo`：`setDynamicStates({eViewport, eScissor})`
    11. 构造 `vk::PushConstantRange`：`setStageFlags(eFragment)`、`setOffset(0)`、`setSize(sizeof(float))`
    12. 构造 `vk::PipelineLayoutCreateInfo`：`setPushConstantRangeCount(1)`、`setPPushConstantRanges(&push_constant_range)`，以 `std::make_unique` 包装存入 `graphics_pipeline_layout_`
    13. 构造 `vk::GraphicsPipelineCreateInfo`，遍历设置上述所有结构体的对应字段，`setRenderPass(**render_pass_)`、`setSubpass(0)`
    14. 调用 `device_->createGraphicsPipeline(nullptr, ci)`，取 second 以 `std::make_unique` 包装存入 `graphics_pipeline_`

6. 修改 `RecordCommands` 使用图形管线
    1. 构造 `vk::Viewport` 和 `vk::Rect2D scissor`，调用 `cb.setViewport(0, viewport)` 和 `cb.setScissor(0, scissor)`
    2. 调用 `cb.bindPipeline(vk::PipelineBindPoint::eGraphics, **graphics_pipeline_)`
    3. 获取 `float t = static_cast<float>(glfwGetTime())`，调用 `cb.pushConstants<float>(**graphics_pipeline_layout_, vk::ShaderStageFlagBits::eFragment, 0, t)`
    4. 调用 `cb.draw(3, 1, 0, 0)` 绘制全屏三角形
    5. 删除原有的 `clear_value` 逻辑（`vk::ClearValue` 仍需要，设为黑色 `{0,0,0,1}` 即可）

7. 集成到初始化流程
    1. 在 `Show()` 中 `CreateComputePipeline()` 之后插入 `CreateGraphicsPipeline()`
