# 1.1 项目骨架

**初始状态**：一个空目录。

**目标状态**：`cmake --build build` 成功编译出可执行文件，运行后在控制台打印 "rtfs2d ready"。

**规则**：
- 使用 CMake 作为构建系统，`CMakeLists.txt` 在项目根目录
- `find_package(Vulkan REQUIRED)` 查找 Vulkan SDK
- `find_package(glfw3 REQUIRED)` 查找 GLFW
- 创建静态库 `rtfs2d_core`，通过别名 `rtfs2d::core` 暴露
- `main.cpp` 由可执行目标编译，链接 `rtfs2d::core`
