# 1.15 交换链重建

**初始状态**：谜题 1.14 的渲染循环程序。

**目标状态**：拖动窗口边缘改变大小时，画面不闪烁、不崩溃。全屏切换也能正常工作。

**规则**：
- 在 `vkAcquireNextImageKHR` 返回 `VK_ERROR_OUT_OF_DATE_KHR` 或 `vkQueuePresentKHR` 返回 `VK_SUBOPTIMAL_KHR` / `VK_ERROR_OUT_OF_DATE_KHR` 时触发重建
- 窗口最小化时（framebuffer 尺寸为 0）不渲染，`glfwWaitEvents()` 等待恢复
- 重建流程：
  1. `vkDeviceWaitIdle`
  2. 销毁所有 framebuffer、image view、swapchain（保留 render pass，因为重建后格式不变）
  3. 重新执行 1.8 → 1.9 → 1.11
  4. 重新录制命令缓冲（1.12 的录制部分）
- 窗口尺寸变化通过 GLFW 的 framebuffer resize callback 感知：`glfwSetFramebufferSizeCallback`
