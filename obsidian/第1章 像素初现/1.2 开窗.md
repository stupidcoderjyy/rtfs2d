# 1.2 开窗

#### 目标
在谜题 1.1 的项目骨架基础上，引入 GLFW 创建窗口，实现：
1. 运行程序后出现一个 800x600 的空白窗口，标题为 "rtfs2d"
2. 点击关闭按钮可正常退出，无内存泄漏

#### 规则
- `glfwInit()` — 初始化 GLFW 库，必须在任何 GLFW 函数之前调用；`glfwTerminate()` 在程序退出前调用以释放资源
- `glfwWindowHint(GLFW_CLIENT_API, GLFW_NO_API)` — 告知 GLFW 不使用 OpenGL / OpenGL ES 上下文，为后续 Vulkan 渲染做准备
- `glfwCreateWindow(width, height, title, nullptr, nullptr)` — 创建窗口及其关联的 context。后两个参数为 monitor（全屏用）和 share（资源共享用），此处均不需要
- 主循环 `while (!glfwWindowShouldClose(window)) { glfwPollEvents(); }` — `glfwWindowShouldClose` 检测用户是否点击关闭按钮；`glfwPollEvents` 处理所有待处理的事件（输入、窗口、回调等），不调用则窗口无响应
- `glfwDestroyWindow(window)` — 销毁窗口及其关联的 context，在 `glfwTerminate` 之前调用
