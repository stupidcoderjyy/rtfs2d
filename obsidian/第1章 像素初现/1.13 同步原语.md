# 1.13 同步原语

**初始状态**：谜题 1.12 的命令缓冲程序。

**目标状态**：创建 semaphore 和 fence 数组，用于每帧的 acquire-submit-present 同步。程序退出前全部销毁。

**规则**：
- 两个 semaphore 数组（`image_available` 和 `render_finished`），各 `kMaxFramesInFlight` 个
- 一个 fence 数组（`in_flight_fences`），`kMaxFramesInFlight` 个，创建时置为 signaled 状态
- `kMaxFramesInFlight = 2`
- 所有 semaphore 和 fence 的 `Vk*CreateInfo` flags 均设为 0
