# 1.4 调试信使

**初始状态**：谜题 1.3 的 Vulkan 实例程序。

**目标状态**：验证层的所有消息（Info / Warning / Error）都打印到控制台，带有 `[Vulkan]` 前缀。程序退出时正确销毁 `VkDebugUtilsMessengerEXT`。

**规则**：
- 仅在 `VK_LAYER_KHRONOS_validation` 可用时创建 debug messenger
- 使用 `vkCreateDebugUtilsMessengerEXT`（扩展函数，需 `vkGetInstanceProcAddr` 动态加载）
- 回调函数签名为 `PFN_vkDebugUtilsMessengerCallbackEXT`
- `messageSeverity` 和 `messageType` 的组合决定是否打印，至少打印 Warning 和 Error
- 必须填充 `VkDebugUtilsMessengerCreateInfoEXT` 的 `pNext` 到 `VkInstanceCreateInfo::pNext`，确保 instance 创建和销毁阶段的消息也被捕获
