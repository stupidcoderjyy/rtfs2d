# 8.4 图形管线传参与模式切换

#### 目标
在[[8.3 渐变色映射]]的基础上，为图形管线添加 push constant，将梯度类型从 specialization constant 改为运行时 push constant 传递，同时在 `ComputeContext` 中新增 `SetVisualizationMode` 接口，实现：
1. 图形管线通过 push constant 在每帧切换渐变色类型
2. `ComputeContext` 提供 API 设置可视化模式（compute 模式 + gradient 类型）

#### 规则
1. 修改 `shaders/fullscreen.frag`
    1. 删除 `layout(constant_id = 2) const uint GRADIENT = 0u;` 声明
    2. 新增 `layout(push_constant) uniform VisParams { uint gradientType; uint visMode; } vis;`
    3. 将 `main()` 中 `if (GRADIENT == 0u)` 改为 `if (vis.gradientType == 0u)`（后续同理）
    4. 暂不处理 `visMode` 分支（为 8.6 预留）

2. 在 `src/vk_graphics.h` 中
    1. 将 `RecordCommands` 签名改为 `void RecordCommands(const vk::raii::CommandBuffer& cb, uint32_t img_idx, uint32_t gradient_type, uint32_t vis_mode) const;`

3. 在 `src/vk_graphics.cpp` 的 `CreateGraphicsPipeline` 中
    1. `SpecializationMapEntry` 数组恢复为 2 个条目（仅 NX/NY），`bytes` 恢复为 `2*sizeof(uint32_t)`
    2. 在 `graphics_pipeline_layout_` 创建前追加 push constant range：声明 `vk::PushConstantRange pcr{};` → `pcr.setStageFlags(vk::ShaderStageFlagBits::eFragment).setOffset(0).setSize(2 * sizeof(uint32_t));` → `pipelineLayoutInfo.setPushConstantRanges(pcr);`

4. 在 `src/vk_graphics.cpp` 的 `RecordCommands` 中
    1. 追加参数 `uint32_t gradient_type, uint32_t vis_mode`
    2. 在 `cb.bindDescriptorSets` 之后、`cb.draw` 之前追加 `cb.pushConstants<uint32_t>(**graphics_pipeline_layout_, vk::ShaderStageFlagBits::eFragment, 0, {gradient_type, vis_mode});`

5. 在 `src/vk_compute.h` 中
    1. 新增 `enum class VisField { kSpeed = 0, kPressure = 1, kVorticity = 2 };`
    2. 新增 `enum class VisGradient { kGray = 0, kJet = 1, kCoolWarm = 2 };`
    3. 新增公有方法 `void SetVisualizationField(VisField field);` 和 `void SetVisualizationGradient(VisGradient gradient);`
    4. 新增公有 getter `VisField vis_field() const { return vis_field_; }` 和 `VisGradient vis_gradient() const { return vis_gradient_; }`
    5. 新增私有成员 `VisField vis_field_ = VisField::kSpeed;` 和 `VisGradient vis_gradient_ = VisGradient::kGray;`

6. 在 `src/vk_compute.cpp` 中
    1. 实现 `SetVisualizationField`：`vis_field_ = field;`
    2. 实现 `SetVisualizationGradient`：`vis_gradient_ = gradient;`
    3. 修改 `RecordFluidStepCommands` 中 `SolveComputeScalar` 调用：`fluid_solvers_->SolveComputeScalar(cb, DescriptorSetAt(kSetComputeScalar), static_cast<uint32_t>(vis_field_));`

7. 在调用 `GraphicsContext::RecordCommands` 的地方（`window.cpp` 的渲染循环中）
    1. 传入 `static_cast<uint32_t>(cc_->vis_gradient())` 和 `0u`（vis_mode 暂为 0，场可视化模式）
