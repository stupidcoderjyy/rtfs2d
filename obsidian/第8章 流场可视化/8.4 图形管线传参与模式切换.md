# 8.4 图形管线传参与模式切换

#### 目标
在[[8.3 渐变色映射]]的基础上，在 `ComputeContext` 中定义 `VisField`、`VisGradient`、`VisMode` 三个枚举和对应的 setter/getter，将 `RecordFluidStepCommands` 中的硬编码模式替换为动态读取成员变量，同时根据模式选择不同的后处理管线。实现：
1. `ComputeContext` 提供 `set_vis_field` / `set_vis_gradient` / `set_vis_mode` 三个接口
2. 场模式下根据 `vis_field_` 选择速度/压力/涡量，涡量模式额外调用 `SmoothVelocity` 再计算
3. 染料模式下跳过标量计算分支，改为执行染料平流和源项注入（8.5/8.6 实现）

#### 规则
1. 在 `src/vk_compute.h` 中
    1. 新增 `enum class VisField { kSpeed = 0, kPressure = 1, kVorticity = 2 };`
    2. 新增 `enum class VisGradient { kGray = 0, kJet = 1, kCoolWarm = 2 };`
    3. 新增 `enum class VisMode { kField = 0, kDye = 1 };`
    4. 新增私有成员 `VisField vis_field_` / `VisGradient vis_gradient_` / `VisMode vis_mode_` 及对应的 getter/setter

2. 在 `src/vk_compute.cpp` 的 `RecordFluidStepCommands` 中
    1. 将标量计算分支包裹进 `if (vis_mode_ == VisMode::kDye)` / `else` 结构
    2. else 分支中：若 `vis_field_ == kVorticity`，先 `SmoothVelocity` → barrier → `ComputeScalar(kSetComputeScalarVI, 2u)`；否则 `ComputeScalar(kSetComputeScalarOthers, static_cast<uint32_t>(vis_field_))`
    3. barrier 确保 V2（场模式）或 dye_dst（染料模式）写入对 fragment shader 可见

3. 在调用 `ComputeScalar` 处改为 `static_cast<uint32_t>(vis_field_)` 替代硬编码 `0u`
