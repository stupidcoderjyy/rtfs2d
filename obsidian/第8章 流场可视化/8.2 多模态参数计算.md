# 8.2 多模态参数计算

#### 目标
在[[8.1 速度幅值计算着色器]]的基础上，为 `compute_scalar.comp` 引入 push constant 控制计算模式（速度幅值 / 压力直通 / 涡量强度），并在 `FluidSolvers` 中创建带 push constant 的独立管线布局，实现：
1. 通过 `SolveComputeScalar(cb, ds, mode)` 在三种物理量之间切换
2. 压力模式将 V4 已有的压力值直通输出
3. 涡量模式用中心差分计算旋度幅值写入 V4

#### 规则
1. 修改 `shaders/compute_scalar.comp`
    1. 在 binding 声明之后追加 `layout(push_constant) uniform Params { uint mode; } pc;`
    2. 在 `main()` 中将原来的速度幅值计算包裹进 `if (pc.mode == 0u)` 分支（速度模式，不变）
    3. 追加 `else if (pc.mode == 1u)` 分支——压力直通：`scalar.data[idx] = scalar.data[idx];`（从 binding 2 自身读回再写入，保持 V4 中的压力值不变）
    4. 追加 `else` 分支——涡量模式：取 `uint i = idx % NX; uint j = idx / NX;`，边界格（`i==0` 或`i>=NX-1` 或 `j==0` 或` j>=NY-1`）写 `scalar.data[idx] = 0.0;` 并 return；内部格计算 `float inv2dx = 0.5 * float(NX);`，取 `vl = v.data[idx-1], vr = v.data[idx+1], ub = u.data[idx-NX], ut = u.data[idx+NX]`，计算 `float omega = (vr - vl - ut + ub) * inv2dx;`，写入 `scalar.data[idx] = abs(omega);`

2. 在 `src/fluid_solvers.h` 中
    1. 追加声明 `std::unique_ptr<vk::raii::PipelineLayout> pipeline_layout_compute_scalar_;`
    2. 将 `SolveComputeScalar` 签名改为 `void SolveComputeScalar(const vk::raii::CommandBuffer& cb, const vk::raii::DescriptorSet& ds, uint32_t mode) const;`

3. 在 `src/fluid_solvers.cpp` 中
    1. 构造函数中删除 `pipeline_compute_scalar_ = CreateSolverPipeline(...)` 的初始化
    2. 在构造函数体内新增管线布局创建：声明 `vk::PushConstantRange pcr{};` → `pcr.setStageFlags(vk::ShaderStageFlagBits::eCompute).setOffset(0).setSize(sizeof(uint32_t));` → 声明 `vk::PipelineLayoutCreateInfo ci{};` → `ci.setSetLayoutCount(1).setPSetLayouts(&*cc_->descriptor_set_layout()).setPushConstantRanges(pcr);` → `pipeline_layout_compute_scalar_ = std::make_unique<vk::raii::PipelineLayout>(dm_->device().createPipelineLayout(ci));` → `pipeline_compute_scalar_ = dm_->CreateComputePipelineFromFile(*pipeline_layout_compute_scalar_, "shaders/compute_scalar.comp.spv");`
    3. 修改 `SolveComputeScalar` 实现：在 `bindDescriptorSets` 后追加 `cb.pushConstants<uint32_t>(*pipeline_layout_compute_scalar_, vk::ShaderStageFlagBits::eCompute, 0, {mode});`

4. 在 `src/vk_compute.cpp` 的 `RecordFluidStepCommands` 中，将 `SolveComputeScalar` 调用改为传入模式参数
    1. `fluid_solvers_->SolveComputeScalar(cb, DescriptorSetAt(kSetComputeScalar), 0u);`——0 为速度模式，保持当前行为
