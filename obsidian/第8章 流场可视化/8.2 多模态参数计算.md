# 8.2 多模态参数计算

#### 目标
在[[8.1 速度幅值计算着色器]]的基础上，为 `compute_scalar.comp` 引入 push constant 控制计算模式，支持速度幅值、压力直通、涡量强度三种路径。在 `FluidSolvers` 中创建带 push constant 的独立管线布局。实现：
1. `ComputeScalar(cb, ds, mode)` 在三种物理量之间切换
2. 压力模式从 V4 读取压力值写入 V2
3. 涡量模式使用 5x5 块平均平滑后计算旋度幅值

#### 规则
1. 修改 `shaders/compute_scalar.comp`
    1. 追加 `layout(std430, binding=3) buffer PressureBuffer { float data[]; } p;`
    2. 追加 `layout(push_constant) uniform Params { uint mode; } pc;`
    3. `main()` 中 mode=0 计算速度幅值（不变），mode=1 写入 `scalar.data[idx]=p.data[idx]`，mode=2 调用 `computeVorticity` 写入 `abs(...)*0.07`

2. 在 `src/fluid_solvers.h` 中
    1. 追加 `std::unique_ptr<vk::raii::PipelineLayout> layout_compute_scalar_;`
    2. 将 `ComputeScalar` 签名改为 `void ComputeScalar(const vk::raii::CommandBuffer& cb, const vk::raii::DescriptorSet& ds, uint32_t mode) const;`

3. 在 `src/fluid_solvers.cpp` 中
    1. 新增 `CreateComputeScalarPipeline` 方法：`PushConstantRange` 设置 `offset=0, size=sizeof(uint32_t)`，创建管线布局 `layout_compute_scalar_`，再创建管线 `pipeline_compute_scalar_`
    2. 构造函数中取消原有 pipeline 直接初始化，改为调用 `CreateComputeScalarPipeline()`
    3. 修改 `ComputeScalar`：`bindPipeline` → `bindDescriptorSets(*layout_compute_scalar_)` → `pushConstants<uint32_t>(*layout_compute_scalar_, eCompute, 0, {mode})` → `dispatch`

4. 在 `src/vk_compute.cpp` 的 `RecordFluidStepCommands` 中，将 `ComputeScalar` 调用改为 `fluid_solvers_->ComputeScalar(cb, DescriptorSetAt(kSetComputeScalarOthers), 0u);`
