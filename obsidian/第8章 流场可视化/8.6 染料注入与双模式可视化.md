# 8.6 染料注入与双模式可视化

#### 目标
在[[8.5 染料缓冲与平流]]的基础上，编写 `dye_source.comp` 通过 push constant 控制注入位置与开关向染料场注入源项，扩展 `fullscreen.frag` 增加染料渲染分支，最终由 `ComputeContext::SetVisualizationMode` 统一控制场/染料切换，实现：
1. 每帧根据 push constant 的坐标和开关注入染料源项
2. 片段着色器根据 `visMode` 切换场可视化与染料可视化
3. `ComputeContext` 提供 `SetVisualizationMode(mode)` 统一切换

#### 规则
1. 创建 `shaders/dye_source.comp`
    1. `#version 450`，`layout(local_size_x = 128, local_size_y = 1, local_size_z = 1) in;`
    2. 声明 `layout(constant_id = 0) const uint NX = 128u;` 和 `constant_id = 1` 的 NY
    3. 声明 `layout(std430, binding = 13) buffer DyeBuffer { float data[]; } dye;`
    4. 声明 `layout(push_constant) uniform Params { float srcX; float srcY; uint enabled; } pc;`
    5. `main()` 中 `if (pc.enabled == 0u) return;`——开关关闭则整帧跳过
    6. 取 `idx = gl_GlobalInvocationID.x`，越界返回；计算归一化坐标 `float x = float(idx % NX) / float(NX); float y = float(idx / NX) / float(NY);`
    7. 计算到源点的距离 `float dist = length(vec2(x - pc.srcX, y - pc.srcY));`
    8. 若 `dist < 0.02` 则 `dye.data[idx] = 1.0;`

2. 在 `shaders/CMakeLists.txt` 的 `SHADER_SOURCES` 中追加 `dye_source.comp`

3. 在 `src/vk_compute.h` 的 `DescriptorSetIndex` 枚举末尾追加 `kSetDyeSource`
    1. 新增公有方法 `void SetVisualizationMode(uint32_t mode);`——mode=0 为场可视化，mode=1 为染料可视化

4. 在 `src/vk_compute.cpp` 的 `CreateDescriptorSets` 中
    1. `field_reg` 末尾追加 `{kSetDyeSource, 13, buffers::kBufDye0}`
    2. 实现 `SetVisualizationMode`：设置 `vis_mode_` 成员

5. 在 `src/fluid_solvers.h` 中
    1. 声明 `std::unique_ptr<vk::raii::Pipeline> pipeline_dye_source_;` 和 `std::unique_ptr<vk::raii::PipelineLayout> layout_dye_source_;`
    2. 声明 `void SolveDyeSource(const vk::raii::CommandBuffer& cb, const vk::raii::DescriptorSet& ds, float srcX, float srcY, uint32_t enabled) const;`

6. 在 `src/fluid_solvers.cpp` 中
    1. 新增 `CreateDyeSourcePipeline` 方法：`PushConstantRange` 设置 `offset=0, size=2*sizeof(float)+sizeof(uint32_t)`，创建带 push constant 的管线布局 → `layout_dye_source_`，再创建管线 `pipeline_dye_source_`
    2. 构造函数中调用 `CreateDyeSourcePipeline();`
    3. 实现 `SolveDyeSource`：`bindPipeline` → `bindDescriptorSets` → 分两次 `pushConstants` 推送 float 坐标和 uint32_t 开关 → `dispatch`

7. 在 `src/vk_compute.cpp` 的 `RecordFluidStepCommands` 中，染料平流之后插入源项注入
    1. `EnsureBufferReady`（eComputeShader→eComputeShader，对 `kBufDye0`）
    2. `fluid_solvers_->SolveDyeSource(cb, DescriptorSetAt(kSetDyeSource), 0.5f, 0.5f, 1u);`——默认在中心持续注入

8. 修改 `shaders/fullscreen.frag`
    1. 新增 `layout(std430, binding = 13) buffer DyeBuffer { float data[]; } dye;`
    2. 在 `main()` 中将现有渐变色输出包裹进 `if (vis.visMode == 0u)` 分支
    3. 追加 `else` 分支：`float dye_val = clamp(dye.data[midx], 0.0, 1.0);` → `vec3 dye_color = mix(vec3(0.02, 0.02, 0.05), mix(vec3(0.8, 0.3, 0.05), vec3(1.0, 0.95, 0.3), dye_val), dye_val);` → `outColor = vec4(dye_color, 1.0);`

9. 在 `src/vk_compute.h` 中新增私有成员 `uint32_t vis_mode_ = 0u;` 和公有 getter `uint32_t vis_mode() const { return vis_mode_; }`

10. 在调用 `GraphicsContext::RecordCommands` 的地方，第三参数改为 `cc_->vis_mode()`
