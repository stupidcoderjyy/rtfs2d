# 8.6 染料平流与源项注入

#### 目标
在[[8.5 涡量抗锯齿与平滑速度场]]的基础上，扩展缓冲系统至 V6，创建染料双缓冲（V5/V6）及 `dye_advection.comp`、`dye_source.comp`，在 `RecordFluidStepCommands` 染料模式下实现 ping-pong 平流与源项注入。实现：
1. 染料双缓冲 V5/V6 做 ping-pong 平流
2. `dye_advection.comp` 障碍感知的半拉格朗日平流
3. `dye_source.comp` 障碍感知的径向渐变注入

#### 规则
1. 修改 `src/buffers.h`
    1. 追加 `constexpr int kBufV5 = 0x05;` 和 `constexpr int kBufV6 = 0x06;`

2. 修改 `src/vk_compute.cpp` 的 `CreateBuffers`
    1. 循环上界从 `kBufV4` 改为 `kBufV6`，确保 V5/V6 创建

3. 在 `src/vk_compute.h` 的 `DescriptorSetIndex` 中追加
    1. `kSetDyeAdvection1`、`kSetDyeAdvection2`（ping-pong src/dst 翻转）
    2. `kSetDyeSource1`、`kSetDyeSource2`（对应 dst 缓冲）
    3. `kSetVis1`、`kSetVis2`（对应不同 dye_dst）

4. 在 `src/vk_compute.cpp` 的 `CreateDescriptorSets` 中注册上述描述符集
    1. `kSetDyeAdvection1`：0→V2, 1→V3, 12→mask, 13→V5(dye_src), 14→V6(dye_dst), 5-8→BC
    2. `kSetDyeAdvection2`：13↔14 翻转（V6→src, V5→dst）
    3. `kSetDyeSource1`：12→mask, 13→V6
    4. `kSetDyeSource2`：12→mask, 13→V5
    5. `kSetVis1`：2→V2, 12→mask, 13→V6
    6. `kSetVis2`：2→V2, 12→mask, 13→V5

5. 创建 `shaders/dye_advection.comp`
    1. 复用 `advection.comp` 的 `border_velocity`/`getU`/`getV` 进行速度查询
    2. binding 12=mask、13=dye_src、14=dye_dst
    3. `isObstacle` 判断障碍格，`main()` 中障碍格写 `dye_dst=0`
    4. `sampleBilinearDye`：越界返回 0.0；四角点任一为障碍格则返回 0.0；否则双线性插值
    5. 反向追踪坐标计算同 `advection.comp`

6. 创建 `shaders/dye_source.comp`
    1. binding 12=mask、13=dye
    2. `layout(push_constant) uniform Params { float srcX; float srcY; } pc;`
    3. `isObstacle` 跳过障碍格
    4. 计算 `dist = length(vec2(x-pc.srcX, y-pc.srcY)); ink = max(0.0, 1.0-dist/0.03);`
    5. 写入 `dye.data[idx] = max(dye.data[idx], ink);`

7. 在 `src/fluid_solvers.h` 中
    1. 声明 `pipeline_dye_advection_`、`pipeline_dye_source_`、`layout_dye_source_`
    2. 声明 `SolveDyeAdvection(cb, ds)` 和 `AddDyeSource(cb, ds, x, y)`

8. 在 `src/fluid_solvers.cpp` 中
    1. 实现 `SolveDyeAdvection`：`bindPipeline` → `bindDescriptorSets` → `dispatch`
    2. 新增 `CreateDyeSourcePipeline`：`PushConstantRange size=sizeof(float)*2`，创建带 push constant 的 layout 和 pipeline
    3. 实现 `AddDyeSource`：`bindPipeline` → `bindDescriptorSets` → `pushConstants<float>(x, y)` → `dispatch`

9. 在 `src/vk_compute.cpp` 的 `RecordFluidStepCommands` 中，染料模式分支内
    1. `auto set_dye_adv = dye_use_set1_ ? kSetDyeAdvection1 : kSetDyeAdvection2;`
    2. `auto set_dye_src = dye_use_set1_ ? kSetDyeSource1 : kSetDyeSource2;`
    3. `dye_use_set1_ = !dye_use_set1_;`
    4. barrier → `SolveDyeAdvection(cb, set_dye_adv)` → barrier → `AddDyeSource(cb, set_dye_src, dye_x_, dye_y_)`
    5. 末尾 barrier dye_dst 到 fragment shader：`EnsureBufferReady(eComputeShader, eFragmentShader, cb, buf_dye_dst)`

10. 在 `shaders/CMakeLists.txt` 中追加 `dye_advection.comp` 和 `dye_source.comp`
