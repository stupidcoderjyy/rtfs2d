# 8.5 染料缓冲与平流

#### 目标
在[[8.4 图形管线传参与模式切换]]的基础上，扩展缓冲系统至 15 个 binding，创建染料双缓冲并通过半拉格朗日平流将染料作为被动标量跟随速度场输运，实现：
1. `buffers.h` 新增 `kBufDye0=13`、`kBufDye1=14`
2. `dye_advection.comp` 读取速度场对染料标量做反向追踪双线性插值
3. `FluidSolvers` 支持每帧染料平流调度

#### 规则
1. 修改 `src/buffers.h`
    1. 追加 `constexpr int kBufDye0 = 13;` 和 `constexpr int kBufDye1 = 14;`

2. 修改 `src/vk_compute.h`
    1. 将 `kBindingsSize` 从 13 改为 15
    2. 在 `DescriptorSetIndex` 枚举末尾追加 `kSetDyeAdvection`

3. 修改 `src/vk_compute.cpp` 的 `CreateBuffers`
    1. 追加 `dm_->CreateBuffer(buffers::kBufDye0, compute_buf_size_, usage, mem_flags);` 和 `dm_->InitBuffer(buffers::kBufDye0, host_data);`
    2. 追加 `dm_->CreateBuffer(buffers::kBufDye1, compute_buf_size_, usage, mem_flags);` 和 `dm_->InitBuffer(buffers::kBufDye1, host_data);`

4. 修改 `src/vk_compute.cpp` 的 `CreateDescriptorSets`
    1. binding 13 和 14 的 stage flag 设为 `vk::ShaderStageFlagBits::eCompute | vk::ShaderStageFlagBits::eFragment`（需要被片段着色器读取）
    2. `field_reg` 末尾追加 `{kSetDyeAdvection, 0, buffers::kBufV0, 1, buffers::kBufV1, 13, buffers::kBufDye0, 14, buffers::kBufDye1, 5, buffers::kBufBc0, 6, buffers::kBufBc1, 7, buffers::kBufBc2, 8, buffers::kBufBc3}`
    3. 同步更新 `kSetVisualization`：追加 `13, buffers::kBufDye0` 绑定（使片段着色器能读取染料缓冲）

5. 创建 `shaders/dye_advection.comp`
    1. `#version 450`，`layout(local_size_x = 128, local_size_y = 1, local_size_z = 1) in;`
    2. 声明 `layout(constant_id = 0) const uint NX = 128u;` 和 `constant_id = 1` 的 NY，`const float DT = 0.016;`
    3. 声明 binding 0=u(V0)、1=v(V1)、13=dye_src、14=dye_dst，binding 5-8 为四边 BC 缓冲
    4. 复用 `advection.comp` 中的 `border_velocity`、`getU`、`getV`、`sampleBilinear` 四个函数（直接复制其完整实现）
    5. `main()` 中取 `idx = gl_GlobalInvocationID.x`，越界返回；`i = idx % NX; j = idx / NX;`
    6. 读当前速度 `float vel_u = u.data[idx]; float vel_v = v.data[idx];`
    7. 反向追踪 `float bx = float(i) + 0.5 - vel_u * DT * float(NX); float by = float(j) + 0.5 - vel_v * DT * float(NY);`
    8. 双线性采样 `float dye = sampleBilinearDye(bx, by);`——新建 `sampleBilinearDye` 函数，内部逻辑同 `sampleBilinear` 但读取 `dye_src.data` 而非速度
    9. 写入 `dye_dst.data[idx] = dye;`

6. 在 `shaders/CMakeLists.txt` 的 `SHADER_SOURCES` 中追加 `dye_advection.comp`

7. 在 `src/fluid_solvers.h` 中
    1. 声明 `std::unique_ptr<vk::raii::Pipeline> pipeline_dye_advection_;`
    2. 声明 `void SolveDyeAdvection(const vk::raii::CommandBuffer& cb, const vk::raii::DescriptorSet& ds) const;`

8. 在 `src/fluid_solvers.cpp` 中
    1. 构造函数初始化列表追加 `pipeline_dye_advection_(CreateSolverPipeline("shaders/dye_advection.comp.spv"))`
    2. 实现 `SolveDyeAdvection`：`cb.bindPipeline(vk::PipelineBindPoint::eCompute, **pipeline_dye_advection_);` → `cb.bindDescriptorSets(...)` → `cb.dispatch(group_count, 1, 1);`

9. 在 `src/vk_compute.cpp` 的 `RecordFluidStepCommands` 中，速度平流（`SolveAdvection`）之后、涡量约束之前插入染料平流
    1. `AddBufferMemoryWriteReadBarrier(cb, buffers::kBufV0);`
    2. `AddBufferMemoryWriteReadBarrier(cb, buffers::kBufV1);`
    3. `AddBufferMemoryWriteReadBarrier(cb, buffers::kBufDye0);`
    4. `fluid_solvers_->SolveDyeAdvection(cb, DescriptorSetAt(kSetDyeAdvection));`
