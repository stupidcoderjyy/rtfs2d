# 8.3 渐变色映射

#### 目标
在[[8.2 多模态参数计算]]的基础上，修改 `fullscreen.frag` 实现三套渐变色映射函数，通过 specialization constant 选择渐变类型，实现灰度、jet 彩虹、冷暖发散三种渐变。

#### 规则
1. 修改 `shaders/fullscreen.frag`
    1. 在 NX/NY specialization constant 之后追加 `layout(constant_id = 2) const uint GRADIENT = 0u;`
    2. 新增 `vec3 GrayScale(float t)`：`return vec3(clamp(t, 0.0, 1.0));`
    3. 新增 `vec3 Jet(float t)`：`t=clamp(t,0,1);` 五段分段 mix：0~0.125 蓝到青，0.125~0.375 青到绿，0.375~0.625 绿到黄，0.625~0.875 黄到红，0.875~1.0 红到暗红
    4. 新增 `vec3 CoolWarm(float t)`：`t=clamp(t,0,1); blue=pow(1-t, 3); red=pow(t, 3); white=6*t*(1-t);` 返回 `vec3(red+white, white, blue+white);`
    5. 将 `outColor=vec4(scalar,scalar,scalar,1.0)` 替换为 `if(GRADIENT==0u) color=GrayScale(scalar); else if(GRADIENT==1u) color=Jet(scalar); else color=CoolWarm(scalar); outColor=vec4(color,1.0);`

2. 在 `src/vk_graphics.cpp` 的 `CreateGraphicsPipeline` 中
    1. `SpecializationMapEntry` 数组追加 `{2, 2*sizeof(uint32_t), sizeof(uint32_t)}`（constant_id=2 映射到 GRADIENT）
    2. `bytes` 扩展为 `3*sizeof(uint32_t)`，第三个位置写入 `uint32_t gradient_type = 0u;`
