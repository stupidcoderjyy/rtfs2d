# 8.3 渐变色映射

#### 目标
在[[8.2 多模态参数计算]]的基础上，修改 `fullscreen.frag` 实现三套渐变色映射函数（灰度、Jet 彩虹、CoolWarm 冷暖发散），通过片段着色器的 push constant 选择渐变类型。实现：
1. 灰度渐变：标量值直接映射为明度
2. Jet 渐变：五段分段 mix（蓝→青→绿→黄→红→暗红）
3. CoolWarm 渐变：三次幂蓝→白→红发散渐变

#### 规则
1. 修改 `shaders/fullscreen.frag`
    1. 确保 `layout(push_constant) uniform VisParams { uint gradientType; uint visMode; } vis;` 存在（visMode 暂未使用，为后续预留）
    2. 新增 `vec3 GrayScale(float t)`：`return vec3(clamp(t, 0.0, 1.0));`
    3. 新增 `vec3 Jet(float t)`：五段 mix——t<0.125 蓝到青，t<0.375 青到绿，t<0.625 绿到黄，t<0.875 黄到红，else 红到暗红
    4. 新增 `vec3 CoolWarm(float t)`：`blue=pow(1-t,3); red=pow(t,3); white=6*t*(1-t);` 返回 `vec3(red+white, white, blue+white);`
    5. 将 `outColor=vec4(scalar,...)` 替换为 `if (vis.gradientType==0u) GrayScale; else if (vis.gradientType==1u) Jet; else CoolWarm;`

2. 在 `src/vk_graphics.cpp` 的 `CreateGraphicsPipeline` 中
    1. 添加 `vk::PushConstantRange pcr{};` → `pcr.setStageFlags(eFragment).setOffset(0).setSize(2*sizeof(uint32_t));`
    2. `pipelineLayoutInfo.setPushConstantRanges(pcr);`

3. 在 `src/vk_graphics.cpp` 的 `RecordCommands` 中
    1. 追加参数 `uint32_t gradient_type, uint32_t vis_mode`
    2. 在 `bindDescriptorSets` 之后、`draw` 之前追加 `cb.pushConstants<uint32_t>(..., {gradient_type, vis_mode});`

4. 在调用 `RecordCommands` 处（`window.cpp`）传入 `static_cast<uint32_t>(compute_ctx_->vis_gradient())` 和 `static_cast<uint32_t>(compute_ctx_->vis_mode())`
