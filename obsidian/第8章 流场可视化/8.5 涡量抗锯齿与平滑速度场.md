# 8.5 涡量抗锯齿与平滑速度场

#### 目标
在[[8.4 图形管线传参与模式切换]]的基础上，编写 `smooth_velocity.comp` 对速度场做障碍感知的 7x7 块平均平滑，同时扩展 `compute_scalar.comp` 的涡量模式为基于平滑速度场的 5x5 块平均差分。实现：
1. `smooth_velocity.comp` 读取 V0/V1 + mask，7x7 邻域平均后写入 V3(u_sm) / V5(v_sm)
2. 涡量模式的 `sampleSmooth` 对平滑速度场做 5x5 块平均后再取中心差分
3. 消除障碍物前端因离散差分产生的锯齿

#### 规则
1. 创建 `shaders/smooth_velocity.comp`
    1. `#version 450`，`layout(local_size_x = 128, local_size_y = 1, local_size_z = 1) in;`
    2. 声明 NX/NY specialization constants
    3. binding 0=u_src(V0)、1=v_src(V1)、3=u_sm(V3)、4=v_sm(V5)、12=mask
    4. `isObstacle(ci, cj)` 判断障碍格
    5. `main()` 中障碍格输出 0.0；正常格对 7x7 邻域（`w=3`）做均匀平均（跳过越界和障碍），写入 `u_sm` 和 `v_sm`

2. 修改 `shaders/compute_scalar.comp`
    1. 追加 `layout(std430, binding=12) buffer MaskBuf { float data[]; } mask;`
    2. 追加 `isObstacle` 函数
    3. 涡量模式改为调用 `computeVorticity`：`isObstacle` 跳过障碍格；边界格返回 0.0；内部格调用 `dvdxSmooth` 和 `dudySmooth`
    4. `sampleSmooth(ci, cj, isU)`：以 `w=2` 的 5x5 邻域对目标格做均匀平均（跳过越界和障碍格），等权重
    5. `dvdxSmooth` / `dudySmooth`：对左右/上下两点各做 `sampleSmooth` 后取中心差分
    6. 涡量结果乘 `0.07` 缩放适配可视化范围

3. 在 `shaders/CMakeLists.txt` 的 `SHADER_SOURCES` 中追加 `smooth_velocity.comp`

4. 在 `src/fluid_solvers.h` 中
    1. 声明 `std::unique_ptr<vk::raii::Pipeline> pipeline_smooth_velocity_;`
    2. 声明 `void SmoothVelocity(const vk::raii::CommandBuffer& cb, const vk::raii::DescriptorSet& ds) const;`

5. 在 `src/fluid_solvers.cpp` 中
    1. 构造函数中创建 `pipeline_smooth_velocity_`
    2. 实现 `SmoothVelocity`：`bindPipeline` → `bindDescriptorSets` → `dispatch`

6. 在 `src/vk_compute.h` 的 `DescriptorSetIndex` 中追加 `kSetSmoothVelocity` 和 `kSetComputeScalarVI`

7. 在 `src/vk_compute.cpp` 的 `CreateDescriptorSets` 中
    1. `{kSetSmoothVelocity, 0, kBufV0, 1, kBufV1, 3, kBufV3, 4, kBufV5, 12, kBufIbmMask}`
    2. `{kSetComputeScalarVI, 0, kBufV3, 1, kBufV5, 2, kBufV2, 12, kBufIbmMask}`——从平滑后的 V3/V5 读取速度、V2 输出标量
