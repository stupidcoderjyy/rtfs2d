# 8.7 鼠标交互染料注入与双模式可视化

#### 目标
在[[8.6 染料平流与源项注入]]的基础上，在 `ComputeContext` 中添加染料源坐标和注入开关，在 `window.cpp` 中注册 GLFW 鼠标回调，实现按住鼠标左键时在指针位置注入染料、松开停止。同时修改 `fullscreen.frag` 增加染料可视化分支，完成场/染料双模式渲染。实现：
1. 按住鼠标左键时在指针位置持续注入径向渐变染料
2. 松开鼠标立即停止
3. 片段着色器根据 `visMode` 在场可视化与染料可视化之间切换

#### 规则
1. 在 `src/vk_compute.h` 中
    1. 新增公有方法 `void SetDyeInjectPos(float x, float y);`
    2. 新增公有方法 `void SetDyeInjecting(bool injecting);`
    3. 新增私有成员 `float dye_x_{}, dye_y_{};` 和 `bool dye_injecting_ = false;`
    4. 新增公有方法 `DescriptorSetIndex GetVisDescriptorSetIndex()` 返回 `dye_use_set1_ ? kSetVis1 : kSetVis2;`
    5. 新增私有成员 `bool dye_use_set1_ = false;`

2. 在 `src/vk_compute.cpp` 中
    1. 实现 `SetDyeInjectPos` / `SetDyeInjecting` 对应赋值
    2. 修改 `RecordFluidStepCommands` 中染料源项注入加条件 `if (dye_injecting_)` 包裹

3. 在 `src/window.h` 中
    1. 声明 `static void MouseButtonCallback(GLFWwindow*, int button, int action, int mods);`
    2. 声明 `static void CursorPosCallback(GLFWwindow*, double xpos, double ypos);`

4. 在 `src/window.cpp` 中
    1. `Show()` 的 `glfwSetWindowUserPointer` 之后注册 `glfwSetMouseButtonCallback(window_, MouseButtonCallback);` 和 `glfwSetCursorPosCallback(window_, CursorPosCallback);`
    2. 实现 `MouseButtonCallback`：左键按下→`SetDyeInjecting(true)`，松开→`SetDyeInjecting(false)`
    3. 实现 `CursorPosCallback`：`nx=xpos/width_`，`ny=ypos/height_`，调用 `SetDyeInjectPos(nx, ny)`

5. 修改 `shaders/fullscreen.frag`
    1. 新增 `layout(set=0, binding=13, std430) buffer DyeBuffer { float d[]; };`
    2. `main()` 中当前渐变色输出包裹进 `if (vis.visMode == 0u)` 分支
    3. `else` 分支：`float dye_val = clamp(d.data[midx], 0.0, 1.0);` → 三层 mix 黑蓝色调，输出 `outColor`

6. 在调用 `GraphicsContext::RecordCommands` 处传入 `cc_->GetVisDescriptorSetIndex()` 对应描述符集
