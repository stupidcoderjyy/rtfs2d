# 8.1 速度幅值计算着色器

#### 目标
在[[第7章 障碍物与流场遮罩/7.7 管线集成与障碍导入|7.7]]的基础上，创建 `compute_scalar.comp`，在投影步后调度，把 V0/V1 速度矢量合成为速度幅值写入 V2，同时修改 `fullscreen.frag` 从 V2 读取标量值。实现：
1. 速度幅值预计算为标量场存入 V2 缓冲
2. 片段着色器不再内联计算 `length(u,v)`，改为直接读取标量缓冲

#### 规则
1. 创建 `shaders/compute_scalar.comp`
    1. `#version 450`，`layout(local_size_x = 128, local_size_y = 1, local_size_z = 1) in;`
    2. 声明 `layout(constant_id = 0) const uint NX = 128u;` 和 `constant_id = 1` 的 NY
    3. binding 0=u(V0)、1=v(V1)、2=scalar(V2)
    4. `main()` 中取 `idx=gl_GlobalInvocationID.x`，越界返回；计算 `speed=sqrt(u.data[idx]*u.data[idx]+v.data[idx]*v.data[idx])`；写入 `scalar.data[idx]=speed`

2. 在 `shaders/CMakeLists.txt` 的 `SHADER_SOURCES` 中追加 `compute_scalar.comp`

3. 在 `src/vk_compute.h` 的 `DescriptorSetIndex` 枚举中追加 `kSetComputeScalarOthers`

4. 在 `src/vk_compute.cpp` 的 `CreateDescriptorSets` 中
    1. `field_reg` 末尾追加 `{kSetComputeScalarOthers, 0, buffers::kBufV0, 1, buffers::kBufV1, 2, buffers::kBufV2}`

5. 在 `src/fluid_solvers.h` 中
    1. 声明 `std::unique_ptr<vk::raii::Pipeline> pipeline_compute_scalar_;`
    2. 声明 `void ComputeScalar(const vk::raii::CommandBuffer& cb, const vk::raii::DescriptorSet& ds) const;`

6. 在 `src/fluid_solvers.cpp` 中
    1. 构造函数初始化列表追加 `pipeline_compute_scalar_ = CreateSolverPipeline("shaders/compute_scalar.comp.spv")`
    2. 实现 `ComputeScalar`：`bindPipeline` → `bindDescriptorSets` → `dispatch(group_count, 1, 1)`

7. 在 `src/vk_compute.cpp` 的 `RecordFluidStepCommands` 中，投影 `SolveProjection` 之后插入
    1. `EnsureBufferReadyForCompute(cb, buffers::kBufV0); EnsureBufferReadyForCompute(cb, buffers::kBufV1);`
    2. `fluid_solvers_->ComputeScalar(cb, DescriptorSetAt(kSetComputeScalarOthers));`
    3. `EnsureBufferReady(eComputeShader, eFragmentShader, cb, buffers::kBufV2);`

8. 修改 `shaders/fullscreen.frag`
    1. 删除 binding 0/1 的速度缓冲声明
    2. 将 binding 2 改为 `buffer ScalarBuffer { float s[]; };`
    3. 删除 `main()` 中的速度采样和 `length(vec2(u,v))` 计算
    4. 改为 `float scalar = clamp(s[midx], 0.0, 1.0); outColor = vec4(scalar, scalar, scalar, 1.0);`

9. 同步更新 `src/vk_compute.cpp` 中 `kSetVis1` 和 `kSetVis2` 的 field_reg，binding 2 映射到 `buffers::kBufV2`
