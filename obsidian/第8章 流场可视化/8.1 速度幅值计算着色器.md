# 8.1 速度幅值计算着色器

#### 目标
在[[第7章 障碍物与流场遮罩/7.7 管线集成与障碍导入|7.7]]的基础上，创建 `compute_scalar.comp` 计算着色器，在 `RecordFluidStepCommands` 投影步之后调度，把 V0/V1 中的速度矢量合成为速度幅值写入 V4，同时修改 `fullscreen.frag` 改为从 V4 读取标量值，实现：
1. 速度幅值预计算为标量场存入 V4 缓冲
2. 片段着色器不再内联计算 `length(u,v)`，改为直接读取标量缓冲

#### 规则
1. 创建 `shaders/compute_scalar.comp`
    1. `#version 450`，`layout(local_size_x = 128, local_size_y = 1, local_size_z = 1) in;`
    2. 声明 `layout(constant_id = 0) const uint NX = 128u;` 和 `layout(constant_id = 1) const uint NY = 128u;`
    3. 声明 `layout(std430, binding = 0) buffer UBuffer { float data[]; } u;`——读取 V0（u 分量速度）
    4. 声明 `layout(std430, binding = 1) buffer VBuffer { float data[]; } v;`——读取 V1（v 分量速度）
    5. 声明 `layout(std430, binding = 2) buffer ScalarBuffer { float data[]; } scalar;`——写入 V4（标量结果）
    6. `main()` 中取 `uint idx = gl_GlobalInvocationID.x;`，`if (idx >= NX * NY) return;`
    7. 计算 `float speed = sqrt(u.data[idx] * u.data[idx] + v.data[idx] * v.data[idx]);`
    8. 写入 `scalar.data[idx] = speed;`

2. 在 `shaders/CMakeLists.txt` 的 `SHADER_SOURCES` 列表中追加 `compute_scalar.comp`

3. 在 `src/vk_compute.h` 的 `DescriptorSetIndex` 枚举末尾追加 `kSetComputeScalar`

4. 在 `src/vk_compute.cpp` 的 `CreateDescriptorSets` 方法中
    1. 在 `field_reg` 末尾追加新条目 `{kSetComputeScalar, 0, buffers::kBufV0, 1, buffers::kBufV1, 2, buffers::kBufV4}`

5. 在 `src/fluid_solvers.h` 中
    1. 声明 `std::unique_ptr<vk::raii::Pipeline> pipeline_compute_scalar_;`
    2. 声明 `void SolveComputeScalar(const vk::raii::CommandBuffer& cb, const vk::raii::DescriptorSet& ds) const;`

6. 在 `src/fluid_solvers.cpp` 中
    1. 构造函数初始化列表追加 `pipeline_compute_scalar_(CreateSolverPipeline("shaders/compute_scalar.comp.spv"))`
    2. 实现 `SolveComputeScalar`：`cb.bindPipeline(vk::PipelineBindPoint::eCompute, **pipeline_compute_scalar_);` → `cb.bindDescriptorSets(vk::PipelineBindPoint::eCompute, *cc_->pipeline_layout(), 0, *ds, nullptr);` → `uint32_t group_count = (cc_->cell_count() + kWorkGroupSize - 1) / kWorkGroupSize;` → `cb.dispatch(group_count, 1, 1);`

7. 在 `src/vk_compute.cpp` 的 `RecordFluidStepCommands` 方法中，投影步 `SolveProjection` 调用之后、`cb.end()` 之前插入
    1. `AddBufferMemoryWriteReadBarrier(cb, buffers::kBufV4);`
    2. `fluid_solvers_->SolveComputeScalar(cb, DescriptorSetAt(kSetComputeScalar));`

8. 修改 `shaders/fullscreen.frag`
    1. 删除 `layout(set = 0, binding = 0, std430) buffer VelocityUBuffer { float vel_u[]; };` 声明
    2. 删除 `layout(set = 0, binding = 1, std430) buffer VelocityVBuffer { float vel_v[]; };` 声明
    3. 将 `layout(set = 0, binding = 2, std430) buffer PressureBuffer { float p[]; };` 改为 `layout(set = 0, binding = 2, std430) buffer ScalarBuffer { float s[]; };`
    4. `main()` 中删除 `uint i = mi; uint j = mj; uint idx = i + j * NX;` 及其下所有速度采样与幅值计算（`float u = vel_u[idx];` 到 `outColor = vec4(intensity, intensity, intensity, 1.0);` 共 5 行）
    5. 在障碍边缘检测 `if (edge < 0.002)` 分支之后、输出之前，改为 `float scalar = s[midx]; outColor = vec4(scalar, scalar, scalar, 1.0);`
