# 8.7 鼠标交互染料注入

#### 目标
在[[8.6 染料注入与双模式可视化]]的基础上，在 `ComputeContext` 中添加染料源坐标和注入开关的读写接口，在 `window.cpp` 中注册 GLFW 鼠标回调，将 `RecordFluidStepCommands` 中硬编码的中心注入替换为动态坐标，实现：
1. 按住鼠标左键时在指针位置持续注入染料
2. 松开鼠标立即停止注入
3. 注入位置随指针实时移动

#### 规则
1. 在 `src/vk_compute.h` 中
    1. 新增公有方法 `void SetDyeSourcePosition(float nx, float ny);`
    2. 新增公有方法 `void SetDyeInjecting(bool injecting);`
    3. 新增私有成员 `float dye_src_x_ = 0.5f;`、`float dye_src_y_ = 0.5f;`、`bool dye_injecting_ = false;`

2. 在 `src/vk_compute.cpp` 中
    1. 实现 `SetDyeSourcePosition`：`dye_src_x_ = nx; dye_src_y_ = ny;`
    2. 实现 `SetDyeInjecting`：`dye_injecting_ = injecting;`
    3. 修改 `RecordFluidStepCommands` 中 `SolveDyeSource` 调用为 `fluid_solvers_->SolveDyeSource(cb, DescriptorSetAt(kSetDyeSource), dye_src_x_, dye_src_y_, dye_injecting_ ? 1u : 0u);`

3. 在 `src/window.h` 中
    1. 新增静态回调声明 `static void MouseButtonCallback(GLFWwindow* window, int button, int action, int mods);`
    2. 新增静态回调声明 `static void CursorPosCallback(GLFWwindow* window, double xpos, double ypos);`

4. 在 `src/window.cpp` 的 `Show()` 方法中 `glfwSetWindowUserPointer` 之后注册回调
    1. `glfwSetMouseButtonCallback(window_, MouseButtonCallback);`
    2. `glfwSetCursorPosCallback(window_, CursorPosCallback);`
    3. 实现 `MouseButtonCallback`：`auto* w = static_cast<Window*>(glfwGetWindowUserPointer(win));` → 若 `button == GLFW_MOUSE_BUTTON_LEFT && action == GLFW_PRESS` 则 `w->compute_ctx_->SetDyeInjecting(true);` → 若 `action == GLFW_RELEASE` 则 `w->compute_ctx_->SetDyeInjecting(false);`
    4. 实现 `CursorPosCallback`：`auto* w = static_cast<Window*>(glfwGetWindowUserPointer(win));` → `float nx = float(xpos) / float(w->width_);` `float ny = 1.0f - float(ypos) / float(w->height_);`（Y 轴翻转，GLFW 原点在左上）→ `w->compute_ctx_->SetDyeSourcePosition(nx, ny);`
