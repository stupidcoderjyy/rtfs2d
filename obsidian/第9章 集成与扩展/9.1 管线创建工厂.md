# 9.1 管线创建工厂

#### 目标
在[[第8章 流场可视化/章节总览|第8章]]的基础上，创建 `ComputeShaderTask`（封装 `bindPipeline → bindDescriptorSets → pushConstants → dispatch` 的四步链式接口）和 `ComputeShaderTaskFactory`（通过 Builder 模式统一创建计算管线），将 `FluidSolvers` 从直接持有管线/布局改为持有 `ComputeShaderTask` 的 `unique_ptr`。实现：
1. `FluidSolvers` 不再持有任何 `pipeline_*` / `layout_*` 成员，改为持有 14 个 `std::unique_ptr<ComputeShaderTask>`
2. 所有 dispatch 统一到 `ComputeShaderTask::Begin(descriptor_set).PushConstant(values).End(cell_count)` 链式接口

#### 规则
1. 创建 `src/compute_pipeline_factory.h`
    1. 声明 `class ComputeShaderTask`——封装单个计算任务的一次调度
    2. `Begin(const vk::CommandBuffer& cb, const vk::raii::DescriptorSet& ds)` 返回 `*this`：内部调用 `cb.bindPipeline(eCompute, **pipeline_);` 和 `cb.bindDescriptorSets(eCompute, *layout_, 0, *ds, nullptr);`，保存 `cb` 的指针到 `cb_`
    3. 模板方法 `PushConstant<T>(values, offset=0)` 返回 `*this`：调用 `cb_->pushConstants<T>(**layout_, eCompute, offset, values);`
    4. `End(uint32_t unit_size)`：调用 `cb_->dispatch((unit_size+127)/128, 1, 1);` 并置 `cb_ = nullptr`
    5. 私有成员：`std::unique_ptr<vk::raii::Pipeline> pipeline_`、`std::shared_ptr<vk::raii::PipelineLayout> layout_`、`const vk::CommandBuffer* cb_`
    6. 声明 `namespace internal { class ComputeShaderTaskBuilder { ... }; }`
    7. `ComputeShaderTaskBuilder` 模板方法 `AppendSpecializationConst<T>(initializer_list)`：遍历每个值，用 `AppendDataToBytesVec<T>` 追加 specialization constant 字节，同时构造 `SpecializationMapEntry` 数组（自动递增 constant_id）
    8. `SetPipelineLayout(shared_ptr<PipelineLayout>)`：设置管线布局；`SetPushConstSize(uint32_t)`：设置 push constant 大小
    9. `Build()` 方法：`dm_->LoadShader` 获取着色器模块 → 构造 `PipelineShaderStageCreateInfo`（若 spec_const 非空则设置 specialization info）→ 若 `push_const_size_` 非 0 则 `CreatePipelineLayout()` 创建带 push constant 的独立布局 → `dm_->device().createComputePipeline(nullptr, cp_ci)` → 返回 `unique_ptr<ComputeShaderTask>`
    10. `CreatePipelineLayout()`：构造 `PushConstantRange` → `PipelineLayoutCreateInfo`（setLayoutCount=1, pSetLayouts 指向 `ds_->descriptor_set_layout()`）→ `layout_ = make_shared<PipelineLayout>(...)`
    11. 声明 `class ComputeShaderTaskFactory`：构造函数接收 `DeviceManager& dm, ComputeContext& cc, DescriptorSets& ds`
    12. `Create(const string& shader_path) const` 按值返回 `ComputeShaderTaskBuilder`：栈上构造 builder → `builder.SetPipelineLayout(cc_->pipeline_layout())` → `return builder`

2. 创建 `src/compute_pipeline_factory.cpp`
    1. 实现 `ComputeShaderTask` 构造函数：移动 `pipeline_`，共享 `layout_`
    2. 实现 `ComputeShaderTaskBuilder` 构造函数：保存 `dm_`、`cc_`、`ds_`、`shader_path_`
    3. 实现 `SetPipelineLayout`、`SetPushConstSize`、`Build`、`CreatePipelineLayout`
    4. 实现 `ComputeShaderTaskFactory` 构造函数和 `Create`

3. 修改 `src/fluid_solvers.h`
    1. 删除所有 `pipeline_*` 和 `layout_*` 成员
    2. 删除所有 `Solve*` / `ComputeScalar` / `SmoothVelocity` / `AddDyeSource` 方法声明
    3. 删除所有 `Create*Pipeline` 私有方法
    4. 删除 `dm_`、`cc_`、`kWorkGroupSize` 私有成员
    5. 新增 `ComputeShaderTaskFactory factory_;` 和 14 个 `std::unique_ptr<ComputeShaderTask> task_*;` 成员
    6. 新增 14 个 getter：`ComputeShaderTask& task_advection() const` 等

4. 修改 `src/fluid_solvers.cpp`
    1. 删除所有 `Solve*` 和 `Create*Pipeline` 实现体
    2. 构造函数改为接收 `DeviceManager& dm, ComputeContext& cc, const CaseData& case_data, DescriptorSets& ds`
    3. 构造函数体内逐一创建 14 个 task，通过 `factory_.Create("shaders/xxx.comp.spv").AppendSpecializationConst<uint32_t>({nx,ny})` 链式调用，需要物理尺寸的 task 追加 `AppendSpecializationConst<float>({inv_dx, inv_dy})`，需要 push constant 的 task 追加 `SetPushConstSize(...)`，最后 `.Build()`
