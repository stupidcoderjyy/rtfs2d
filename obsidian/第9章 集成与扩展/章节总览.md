# 第9章 集成与扩展

本章节聚焦于代码架构重构与外部配置集成：将管线创建与调度解耦为 `ComputeShaderTask`（流式链式接口），将描述符集构建提取到独立模块 `DescriptorSets`，集中管理缓冲初始化，扩展网格物理尺寸并通过 specialization constant 传入着色器，引入编译器生成器实现障碍物表达式解析，创建 `CaseData` 统一从 JSON 加载流场参数、边界条件、障碍几何和可视化设置，最终合并计算与图形录制到单一 CommandBuffer 并通过 `main` 命令行参数驱动。一共 9 个关卡。

#### 摘要

创建 `ComputeShaderTask`（`Begin → PushConstant → End` 链式接口）和 `ComputeShaderTaskFactory`（Builder 模式），将 `FluidSolvers` 缩减为 14 个 task 的 `unique_ptr` 容器。创建 `DescriptorSets` 模块，通过注册表式 `GetDescriptorRegistry` 统一声明 21 个描述符集的绑定映射，由 `DescriptorSetBuilder` 完成布局、池、集的创建与缓冲区写入。将分散在 `ComputeContext::CreateBuffers` 和 `BoundaryContext` 中的缓冲创建收敛到 `buffers::InitBuffers` 自由函数。为所有涉及 `dx` 的着色器追加 `INV_DX`/`INV_DY` specialization constants。引入 `obstacle_exp_parser` 编译器和 `compile/*`、`util/*` 辅助模块实现障碍物表达式解析。创建 `CaseData` 配置类，统一从 JSON 加载 `mesh_resolution`、`mesh_density`、`boundary_conditions`、`geometry`、`visual` 等字段。合并 compute 和 graphics 到同一 CommandBuffer，`main` 通过 `argv[1]` 传入 JSON 路径。
