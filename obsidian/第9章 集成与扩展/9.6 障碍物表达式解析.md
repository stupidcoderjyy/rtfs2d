# 9.6 障碍物表达式解析

#### 目标
在[[9.5 网格物理尺寸]]的基础上，引入 `obstacle_exp_parser` 编译器（`compile/*`、`util/*` 为从其他项目复用的编译器生成器框架），实现从 JSON 的 `geometry` 字符串数组中解析障碍物描述并构建 `ObstacleGeometry`。实现：
1. 几何描述字符串（如 `"C 0.5 0.5 R 8"`）经词法/语法分析后生成多边形顶点
2. `ObstacleGeometry` 支持物理坐标的顶点存储、AABB 计算、拉格朗日标记生成、SSBO 序列化

#### 规则
1. 复用 `compile/*` 和 `util/*` 模块
    1. `compile/compiler.h` 提供编译器基类框架
    2. `compile/compiler_input.h` 提供 `CompilerInput` 包装
    3. `compile/compile_error.h` 提供编译错误格式化
    4. `util/` 提供 `AbstractInput`、`StringInput`、`ByteReader` 等字符流抽象

2. 创建 `src/obstacle_exp_parser.h` 和 `src/obstacle_exp_parser.cpp`
    1. 基于编译器生成器实现障碍物表达式解析：从 `compile/compiler.h` 继承，实现 lexer 和 parser
    2. 支持的语法：`C <x> <y> R <n>` 表示圆心 `(x,y)` 半径 `n` 格的多边形近似；矩形 `R <x> <y> <w> <h>`
    3. 解析结果通过 `ObstacleGeometry::AddObstacle(vertices)` 添加

3. 修改 `src/obstacle_geometry.h`
    1. 定义 `Obstacle` 结构体：`vert_count`、`aabb[4]`（std430 vec2 对齐）、`poly_verts[64]`
    2. 定义 `PolygonSSBO`（`count + obstacles[16]`）和 `MarkerSSBO`（`count + markers[2048]`）
    3. 声明 `AddObstacle(points)`——追加障碍多边形并计算 AABB
    4. 声明 `GenerateIBMMarkers(float h)`——以物理间距 `h` 在障碍物内部均匀取样生成拉格朗日标记点
    5. 声明 `SerializePolygonSSBO()` 和 `SerializeMarkerSSBO()`——返回 `vector<uint8_t>` 供 GPU 上传
    6. 声明常量 `kPolygonBufferSize` / `kMarkBufferSize`

4. 修改 `src/obstacle_geometry.cpp`
    1. 实现 `AddObstacle`：将顶点拷贝到 `polygon_ssbo_.obstacles[count]`，设置 `vert_count`，调用 `ComputeAABB()`
    2. 实现 `ComputeAABB`：遍历顶点取 min/max，外扩 `1e-5` 防止射线投射精度问题
    3. 实现 `GenerateIBMMarkers`：在 AABB 范围内以间距 h 均匀布点，对每个点用射线法（`pointInPolygon`）检测是否在多边形内部，内部点加入 `marker_ssbo_`
    4. 实现 `SerializePolygonSSBO` 和 `SerializeMarkerSSBO`：将结构体 `memcpy` 到 `vector<uint8_t>`

5. 在 `src/case_data.cpp` 的 `ParseGeometry` 中
    1. 遍历 `geometry` 数组，对每个字符串创建 `CompilerInput` → `ObstacleExpLexer` → `ObstacleExpParser` 运行解析
    2. 解析出错时通过 `spdlog::error(err.FormatErrorMessage())` 输出
