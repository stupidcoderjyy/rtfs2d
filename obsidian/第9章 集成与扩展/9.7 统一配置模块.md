# 9.7 统一配置模块

#### 目标
在[[9.6 障碍物表达式解析]]的基础上，创建 `CaseData` 配置类，从 JSON 文件一次性加载网格参数、边界条件、障碍几何和可视化设置，将原先分散在 `ComputeContext` 构造、`BoundaryContext` 配置、`AddDebugGeometry` 中的硬编码全部替换为 JSON 驱动。实现：
1. `CaseData` 持有 `GridParams`（`nx/ny/dx/dy/width/height`）、`BoundaryContext`、`ObstacleGeometry`
2. `ParseJson` 统一调度四个子解析器

#### 规则
1. 创建 `src/case_data.h`
    1. 声明 `class CaseData`，构造函数接收 `std::string name`
    2. `ParseJson(const nlohmann::json& json)`——顶级入口
    3. getter：`width()/height()/nx()/ny()/dx()/dy()/total_cells()/name()`、`geometry()/boundary()`
    4. 私有字段：`width_/height_/nx_/ny_/dx_/dy_/total_cells_/name_`、`unique_ptr<ObstacleGeometry> geometry_`、`unique_ptr<BoundaryContext> boundary_ctx_`
    5. 四个私有解析方法：`ParseGridParams`、`ParseGeometry`、`ParseBoundary`、`ParseVisual`

2. 创建 `src/case_data.cpp`
    1. `ParseJson`：验证 JSON 为 object → 查找 `"case"` 子对象 → 依次调用 `ParseGridParams`、`ParseGeometry`、`ParseBoundary` → 可选解析 `"visual"`
    2. `ParseGridParams`：从 `mesh_resolution: [nx, ny]` 读取网格分辨率；从 `mesh_density` 读取网格密度（物理尺寸 = 密度 × 分辨率）；强制 `dx = dy = density`；计算 `total_cells_ = nx * ny`
    3. 构造函数中创建 `boundary_ctx_` 和 `geometry_`

3. 修改 `src/vk_boundary.h`
    1. `BoundaryContext` 构造函数改为接收 `CaseData& cd`
    2. 新增 `Reset()` 方法清空 `segments_` 数组
    3. `UploadData` 签名改为 `void UploadData(const CaseData& case_data, DeviceManager& dm) const;`

4. 修改 `src/vk_boundary.cpp`
    1. 构造函数从 `case_data` 读取 `nx/ny` 计算 `h_cell_count_/v_cell_count_`
    2. `UploadData` 从 `case_data` 读取尺寸和密度，物理坐标展开为网格索引

5. 修改 `src/window.cpp`
    1. 删除所有硬编码的 `GridParams` 和 `AddDebugGeometry`
    2. 窗口标题改为 `"rtfs2d - " + case_data_->name()`
    3. 窗口尺寸从 `case_data_->nx()/ny()` 读取
