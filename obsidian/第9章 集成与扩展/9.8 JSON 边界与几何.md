# 9.8 JSON 边界与几何

#### 目标
在[[9.7 统一配置模块]]的基础上，实现 `ParseBoundarySide` 和 `ParseBoundary` 从 JSON 的 `boundary_conditions` 对象中解析四边边界条件，以及从 `geometry` 字符串数组解析障碍物几何。实现：
1. 支持 `left`/`right`/`bottom`/`top` 四个方向的多段边界条件
2. 每段边界包含 `from`/`to`（归一化 [0,1] 范围）、`type`（字符串）、可选 `u`/`v` 速度分量

#### 规则
1. 在 `src/case_data.cpp` 中新增两个静态辅助函数
    1. `static BoundaryDirection ParseDirection(const std::string& s)`——将 `"left"/"right"/"bottom"/"top"` 映射为 `BoundaryDirection` 枚举值
    2. `static BoundaryType ParseType(const std::string& s)`——将 `"no_slip_wall"/"slip_wall"/"velocity"/"pressure"` 映射为 `BoundaryType` 枚举值

2. 实现 `ParseBoundarySide(BoundaryDirection dir, const nlohmann::json& side_array)`
    1. 验证 `side_array` 为数组类型
    2. 遍历每个 `cond` 对象：读取 `from`（`double`，缺省抛异常）、`to`（`double`，缺省抛异常）→ 验证 `from <= to`
    3. 读取 `type` 字符串 → 调用 `ParseType` 转换为枚举
    4. 读取可选 `u`（`float`，缺省 0.0）和 `v`（`float`，缺省 0.0）
    5. 调用 `boundary_ctx_->SetBoundary(dir, bc_type, from, to, u, v)`

3. 实现 `ParseBoundary(const nlohmann::json& json)`
    1. 查找 `"boundary_conditions"` 子对象，若不存在则返回（无边界条件视为合理）
    2. 声明静态数组 `sides[] = {{"left", kLeft}, {"right", kRight}, {"bottom", kBottom}, {"top", kTop}}`
    3. 遍历 `sides`，对每个方向在 `bc_obj` 中查找对应键名，找到则调用 `ParseBoundarySide(dir, *it_side)`

4. 实现 `ParseGeometry(const nlohmann::json& json) const`
    1. 查找 `"geometry"` 数组，若不存在或非数组则返回
    2. 遍历每个字符串元素：创建 `CompilerInput::FromString(desc)` → `ObstacleExpLexer` → `ObstacleExpParser(*geometry_)` 运行解析 → 捕获 `CompileError` 输出错误日志

5. 在 `test.json` 中定义示例格式
    1. `"boundary_conditions": {"left": [{"from": 0.0, "to": 1.0, "type": "velocity", "u": 0.5}], "right": [{"from": 0.0, "to": 1.0, "type": "pressure"}]}`
    2. `"geometry": ["C 0.5 0.5 R 8"]`——圆心 (0.5, 0.5) 半径 8 格的多边形
