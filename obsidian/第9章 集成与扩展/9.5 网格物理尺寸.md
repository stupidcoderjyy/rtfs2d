# 9.5 网格物理尺寸

#### 目标
在[[9.4 模块化描述符集]]的基础上，将着色器中硬编码的 `1.0/NX`（单位域假设）替换为 specialization constant `INV_DX`/`INV_DY`，使差分算子适配任意物理尺寸。同时根据 `dx` 动态缩放泊松方程的雅可比迭代次数。实现：
1. 6 个着色器（`advection`、`diverge`、`project`、`vorticity`、`compute_scalar`、`dye_advection`）追加 `constant_id=2` 和 `constant_id=3` 的 `INV_DX`/`INV_DY`
2. 泊松迭代次数按 `n = 50*(h₀/h)²` 动态计算

#### 规则
1. 着色器统一追加 specialization constant
    1. 在 `layout(constant_id = 1) const uint NY = ...;` 之后追加两行：`layout(constant_id = 2) const float INV_DX = 128.0;` 和 `layout(constant_id = 3) const float INV_DY = 128.0;`（默认值对应 NX=128 的单位域）

2. `advection.comp` 和 `dye_advection.comp`
    1. 删除 `float dx = 1.0 / float(NX);`
    2. 反向追踪改为 `bx = float(i) + 0.5 - u * DT * INV_DX;` 和 `by = float(j) + 0.5 - v * DT * INV_DY;`

3. `diverge.comp`
    1. `inv_2dx = 0.5 * float(NX)` → `float inv_2dx = 0.5 * INV_DX; float inv_2dy = 0.5 * INV_DY;`
    2. 散度公式拆分为 `(u_right - u_left) * inv_2dx + (v_top - v_bottom) * inv_2dy`

4. `project.comp`
    1. `inv_2dx` 同上拆分
    2. `u.data[idx] -= (p_right-p_left)*inv_2dx;` `v.data[idx] -= (p_top-p_bottom)*inv_2dy;`
    3. `border_pressure` 中 `dx = 1.0/float(NX)` → `dx = 1.0/INV_DX`

5. `vorticity.comp`
    1. `dx = 1.0/INV_DX;` `inv_2dx = 0.5*INV_DX; inv_2dy = 0.5*INV_DY;`
    2. `omega` 拆分为 `(v_right-v_left)*inv_2dx - (u_up-u_down)*inv_2dy`
    3. 四个 `w` 梯度中涉及 u 部分用 `inv_2dy`、v 部分用 `inv_2dx`
    4. `grad_x = (wr-wl)*inv_2dx;` `grad_y = (wu-wd)*inv_2dy;`
    5. `f_max = 2.0*INV_DX;`

6. `compute_scalar.comp`
    1. `computeVorticity` 中 `dx_inv=float(NX)` → `dx_inv=INV_DX; dy_inv=INV_DY;` 分别传入 `dvdxSmooth` 和 `dudySmooth`

7. `ibm_mask.comp`、`ibm_interpolate.comp`、`ibm_spread_markers.comp`
    1. 追加 INV_DX/INV_DY 声明
    2. IBM mask：网格中心坐标从 `(i+0.5)/NX` 改为 `(i+0.5)/INV_DX`，`cell_w/cell_h` 改为 `1.0/INV_DX`、`1.0/INV_DY`
    3. IBM interpolate/spread：`gx = mp.x*float(NX)` → `mp.x*INV_DX`，`gy` 同理

8. `src/fluid_solvers.cpp` 构造中追加
    1. `float inv_dx = 1.0f / case_data.dx(); float inv_dy = 1.0f / case_data.dy();`
    2. 需要物理尺寸的 task 追加 `.AppendSpecializationConst<float>({inv_dx, inv_dy})`

9. `src/vk_compute.cpp` 构造中
    1. `poisson_iter_n = clamp(ceil(50*(0.00195/case_data.dx())*(0.00195/case_data.dx())), 1u, 100u)`
    2. 在 `RecordCommands` 的泊松循环中将 `50` 替换为 `poisson_iter_n`
