# 9.4 模块化描述符集

#### 目标
在[[9.3 集中缓冲初始化]]的基础上，创建 `DescriptorSets` 模块，将描述符集从 `ComputeContext` 中分离为独立类，通过注册表式 `GetDescriptorRegistry()` 统一声明 21 个描述符集的绑定映射，由内部 `DescriptorSetBuilder` 完成布局、池、集的创建与缓冲区写入。实现：
1. `DescriptorSets` 提供 `SetAt(DescriptorSetIndex)` 访问具体描述符集
2. 描述符集枚举 `DescriptorSetIndex` 从 `vk_compute.h` 移入 `descriptor_sets.h`

#### 规则
1. 创建 `src/descriptor_sets.h`
    1. 声明枚举 `DescriptorSetIndex`：`kSetAdvection` 到 `kSetVis2`（共 21 项），从 `vk_compute.h` 中完整移出
    2. 声明 `class DescriptorSets`：构造函数接收 `DeviceManager& dm`
    3. getter `SetAt(DescriptorSetIndex idx)` 返回 `const vk::raii::DescriptorSet&`
    4. getter `descriptor_set_layout()` 和 `descriptor_pool()`
    5. 私有方法 `CreateDescriptorSets(DescriptorSetBuilder& dsb)`——创建 21 个描述符集，前 18 个为 compute-only 或 compute+fragment，后 3 个为 fragment-only
    6. 私有静态方法 `GetDescriptorRegistry()`——返回 `vector<vector<uint32_t>>`，每项格式为 `{set_index, binding, buffer_idx, binding, buffer_idx, ...}`

2. 创建 `src/descriptor_sets.cpp`
    1. 实现 `DescriptorSets` 构造函数：构造 `DescriptorSetBuilder`（传入 `dm` 和 `GetDescriptorRegistry()`）→ 调用 `CreateDescriptorSets` → `dsb.Build()` 获取 layout、pool、sets → 移入成员
    2. 实现 `CreateDescriptorSets`：`dsb.CreateDescriptorSet(kSetAdvection, eCompute)` 等 21 次调用（`kSetDiffusionEven` 和 `kSetSmoothVelocity` 等涉及 fragment shader 的 set 用 `eCompute|eFragment`）
    3. 实现 `GetDescriptorRegistry`：返回 21 个 vector，每个声明各 set 的 binding→buffer 映射（如 `{kSetAdvection, 0, kBufV0, 1, kBufV1, 2, kBufV2, 3, kBufV3, 5, kBufBc0, 6, kBufBc1, 7, kBufBc2, 8, kBufBc3}`）

3. 创建内部类 `DescriptorSetBuilder`（`namespace internal`）
    1. `Constructor(dm, sets_registry)`：保存引用
    2. `CreateDescriptorSet(uint32_t binding, ShaderStageFlags)`：向 `bindings_` 追加一个 `VkDescriptorSetLayoutBinding`
    3. `BuildResult` 结构体包含 `layout`、`pool`、`sets`
    4. `Build()`：验证 `sets_registry_.size() == bindings_.size()` → 计算 `max_descriptor_count` → 创建 pool（`max_sets = sets_count`）→ 创建 layout（`bindingCount = max_descriptor_count`）→ 对每个 set_reg 分配 descriptor set 并逐 binding 写入 `dm_->BufferAt(buffer_idx)`

4. 修改 `src/vk_compute.h`
    1. 删除 `DescriptorSetIndex` 枚举（已移至 `descriptor_sets.h`）
    2. 删除 `descriptor_set_layout_`、`descriptor_pool_`、`descriptor_sets_` 成员
    3. 新增成员 `DescriptorSets* ds_;`
    4. 构造函数增加 `DescriptorSets& ds` 参数
    5. 所有描述符集访问改为 `ds_->SetAt(...)`

5. 修改 `ComputeContext` 中 `pipeline_layout()` 的获取——`shared_ptr<PipelineLayout>` 从 `DescriptorSets` 的 `descriptor_set_layout()` 创建（在 `ComputeContext` 构造时初始化，存入 `pipeline_layout_`）
