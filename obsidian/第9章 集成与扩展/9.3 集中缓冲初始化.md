# 9.3 集中缓冲初始化

#### 目标
在[[9.2 计算调度归位]]的基础上，创建 `buffers::InitBuffers` 自由函数，将分散在 `ComputeContext::CreateBuffers`（流场 V0-V6 + IBM 四个缓冲）和 `BoundaryContext`（四边 BC 缓冲）中的缓冲创建逻辑全部收敛到一处。实现：
1. `buffers.h` 中声明 `void InitBuffers(DeviceManager& dm, const CaseData& case_data);`
2. `ComputeContext` 和 `BoundaryContext` 不再自行创建缓冲

#### 规则
1. 创建 `src/buffers.cpp`
    1. 实现 `InitBuffers`：从 `case_data` 获取 `total_cells()` 作为流场缓冲大小
    2. 创建 V0~V6（7 个流场缓冲）：`kBufV0` 到 `kBufV6`，usage 含 `StorageBuffer|TransferSrc|TransferDst`，mem_flags 为 `eDeviceLocal`，全零初始化
    3. 创建 IBM 四个缓冲：`kBufIbmPolygon`（`kPolygonBufferSize`）、`kBufIbmMarker`（`kMarkBufferSize`）、`kBufIbmForce`（`2*cell_count*sizeof(float)`）、`kBufIbmMask`（`2*cell_count*sizeof(float)`），全零初始化
    4. 创建 BC 四个缓冲（从 `BoundaryContext::UploadData` 的逻辑中迁移大小计算）：`h_cell_count = nx-2`，`v_cell_count = ny-2`，`h_buf_size = h_cell_count * kBufferUnitSize`，`v_buf_size = v_cell_count * kBufferUnitSize`

2. 修改 `src/buffers.h`
    1. 追加 `#include` 并前向声明 `class DeviceManager;` 和 `class CaseData;`
    2. 在 `namespace buffers` 中追加 `void InitBuffers(DeviceManager& dm, const CaseData& case_data);`

3. 修改 `src/vk_boundary.h`
    1. 将 `UploadBoundaryData` 重命名为 `UploadData`，参数增加 `const CaseData& case_data`（用于访问 `nx()`/`ny()` 计算 cell_count 和 buf_size）
    2. 删除 `h_cell_count_`、`v_cell_count_`、`h_buf_size_`、`v_buf_size_` 成员（大小在 `UploadData` 中临时计算）

4. 修改 `src/vk_boundary.cpp`
    1. `UploadData(const CaseData& case_data, DeviceManager& dm)`：根据 `case_data.nx()/ny()` 动态计算 `cell_count` 和 `buf_size` → 创建默认全零 `vector<uint8_t>` → 遍历 `segments_[d]` 覆盖自定义段 → `dm.InitBuffer(buffers::kBufBc0 + d, bytes)`

5. 修改 `src/window.cpp` 的 `Show`
    1. 在 `device_manager_` 创建之后、`ComputeContext` 构造之前调用 `buffers::InitBuffers(*device_manager_, *case_data_);`
