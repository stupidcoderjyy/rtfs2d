# 10.1 ImGui 初始化

#### 目标
在[[第9章 集成与扩展/章节总览|第9章]]的基础上，集成 Dear ImGui 库，创建 `ImGuiVulkanContext` 类完成 Vulkan/GLFW 后端初始化和帧生命周期管理，拆分 `GraphicsContext` 的 RenderPass 边界供外部控制，在自定义 GLFW 回调中手动转发事件给 ImGui。实现：
1. ImGui 上下文创建、GLFW 后端绑定（不注册回调）、独立描述符池
2. `BeginFrame()` / `EndFrame()` / `Shutdown()` 均为静态方法
3. `GraphicsContext` 拆为 `BeginRenderPass` / `RecordCommands` / `EndRenderPass`

#### 规则
1. 在 `thirdparty/CMakeLists.txt` 中构建 ImGui 静态库
    1. 定义 `IMGUI_TARGET = imgui`，源文件：`imgui.cpp`、`imgui_draw.cpp`、`imgui_widgets.cpp`、`imgui_tables.cpp`、`backends/imgui_impl_glfw.cpp`、`backends/imgui_impl_vulkan.cpp`
    2. `add_library(${IMGUI_TARGET} STATIC ${IMGUI_SOURCES})`
    3. `add_library(external::imgui ALIAS ${IMGUI_TARGET})`
    4. `target_include_directories(${IMGUI_TARGET} PUBLIC imgui)`
    5. `target_link_libraries(${IMGUI_TARGET} PRIVATE glfw Vulkan::Vulkan)`
    6. 末尾保留 `add_subdirectory(googletest)`

2. 修改顶层 `CMakeLists.txt`
    1. `add_subdirectory(thirdparty/googletest)` → `add_subdirectory(thirdparty)`

3. 修改 `src/CMakeLists.txt`
    1. 追加源文件 `imgui_vulkan_context.cpp`、`vis_config.cpp`、`imgui_control_panel.cpp` 到 `rtfs2d_core`
    2. `target_link_libraries` 追加 `external::imgui`

4. 修改 `src/vulkan/device_manager.h`
    1. 新增 `vk::raii::Instance& vk_instance() const { return *instance_; }`

5. 修改 `src/render/graphics_context.h`
    1. 原 `RecordCommands(cb, img_idx, gradient_type, vis_mode)` 拆为三个方法：
    2. `void BeginRenderPass(const vk::raii::CommandBuffer& cb, uint32_t img_idx) const;`——图像布局转换 + clear + `cb.beginRenderPass`
    3. `void EndRenderPass(const vk::raii::CommandBuffer& cb, uint32_t img_idx) const;`——`cb.endRenderPass` + 布局设为 `ePresentSrcKHR`
    4. `void RecordCommands(const vk::raii::CommandBuffer& cb, VisConfig& vis_config) const;`——视口/剪刀 + bind pipeline + bind descriptor set（从 `cc_->GetVisDescriptorSetIndex()` 获取）+ push constants（`gradientType, visMode, dyeColorLow, dyeColorMid, dyeColorHigh`）+ `cb.draw(3,1,0,0)`

6. 修改 `src/render/graphics_context.cpp`
    1. 将原 `RecordCommands` 方法体按上述拆分
    2. `RecordCommands` 中 push constant 数组构造为 `std::array<uint32_t,5>{gradient, mode, dyeColors[0], dyeColors[1], dyeColors[2]}`
    3. `CreateGraphicsPipeline` 中 `PushConstantRange` 大小设为 `5 * sizeof(uint32_t)`

7. 创建 `src/render/imgui_vulkan_context.h`
    1. 声明 `class ImGuiVulkanContext`，构造参数：`GLFWwindow* window`、`DeviceManager& dm`、`vk::RenderPass render_pass`、`uint32_t swapchain_image_count`
    2. 声明 `static void BeginFrame()`——`ImGui_ImplVulkan_NewFrame()` → `ImGui_ImplGlfw_NewFrame()` → `ImGui::NewFrame()`
    3. 声明 `static void EndFrame(const vk::raii::CommandBuffer& cb)`——`ImGui::Render()` → 获取 draw data → `ImGui_ImplVulkan_RenderDrawData`
    4. 声明 `static void Shutdown()`——`ImGui_ImplVulkan_Shutdown()` → `ImGui_ImplGlfw_Shutdown()` → `ImGui::DestroyContext()`
    5. 私有成员 `std::unique_ptr<vk::raii::DescriptorPool> imgui_descriptor_pool_;`

8. 创建 `src/render/imgui_vulkan_context.cpp`
    1. 构造函数步骤 1——创建上下文：`IMGUI_CHECKVERSION()` → `ImGui::CreateContext()` → `io.ConfigFlags |= NavEnableKeyboard` → `io.IniFilename = nullptr` → `StyleColorsDark()`
    2. 构造函数步骤 2——绑定 GLFW：`ImGui_ImplGlfw_InitForVulkan(window, false)`（不注册回调）
    3. 构造函数步骤 3——创建描述符池：`pool_count=16`，`DescriptorPoolSize` 含 `eSampler` 和 `eSampledImage` 各 16 个 → `maxSets = pool_count*2`，flags 含 `eFreeDescriptorSet`
    4. 构造函数步骤 4——填充 `ImGui_ImplVulkan_InitInfo`：`Instance = *dm.vk_instance()`、`PhysicalDevice`、`Device`、`QueueFamily`、`Queue`、`DescriptorPool`、`MinImageCount=2`、`ImageCount=swapchain_image_count`、`PipelineInfoMain.MSAASamples=VK_SAMPLE_COUNT_1_BIT`、`PipelineInfoMain.RenderPass=render_pass`
    5. 构造函数步骤 5——`ImGui_ImplVulkan_Init(&init_info)`
    6. 实现 `BeginFrame()`、`EndFrame()`、`Shutdown()` 静态方法

9. 修改 `src/render/window.cpp` 的 `Show` 方法
    1. 在 `graphics_ctx_` 构造之后创建 `imgui_ctx_`：`std::make_unique<ImGuiVulkanContext>(window_, *device_manager_, *swapchain_ctx_->render_pass(), swapchain_ctx_->swapchain_images().size());`
    2. `glfw_guard` 的析构 lambda 中 `ImGuiVulkanContext::Shutdown()` 在 `glfwTerminate()` 之前
