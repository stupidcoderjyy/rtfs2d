# 10.1 ImGui 初始化

#### 目标
在[[第9章 集成与扩展/章节总览|第9章]]的基础上，集成 Dear ImGui 库到项目中，创建 `ImGuiVulkanContext` 类完成 ImGui 的 Vulkan/GLFW 后端初始化和帧录制，将 `GraphicsContext` 的渲染通道边界拆分为 `BeginRenderPass`/`EndRenderPass` 供外部控制，最终在主循环中实现 BeginRenderPass → ImGui → 流场 → EndRenderPass 的渲染顺序。实现：
1. ImGui 上下文创建并与 GLFW/Vulkan 后端绑定
2. `GraphicsContext` 的 RenderPass 边界与绘制逻辑分离
3. `ImGuiVulkanContext::RecordCommands` 在一个调用中完成 NewFrame + Render + RenderDrawData

#### 规则
1. 在 `thirdparty/` 下创建 CMake 构建 `thirdparty/CMakeLists.txt`
    1. 定义 `IMGUI_TARGET = imgui`，源文件列表：`imgui/imgui.cpp`、`imgui/imgui_draw.cpp`、`imgui/imgui_widgets.cpp`、`imgui/imgui_tables.cpp`、`imgui/backends/imgui_impl_glfw.cpp`、`imgui/backends/imgui_impl_vulkan.cpp`
    2. 创建静态库 `add_library(${IMGUI_TARGET} STATIC ${IMGUI_SOURCES})`
    3. 创建别名 `add_library(external::imgui ALIAS ${IMGUI_TARGET})`
    4. `target_include_directories(${IMGUI_TARGET} PUBLIC imgui)`——公开 imgui 根目录（使 `#include <imgui.h>` 和 `#include <backends/imgui_impl_glfw.h>` 均可解析）
    5. `target_link_libraries(${IMGUI_TARGET} PRIVATE glfw Vulkan::Vulkan)`
    6. 末尾保留 `add_subdirectory(googletest)`

2. 修改顶层 `CMakeLists.txt`
    1. 将 `add_subdirectory(thirdparty/googletest)` 改为 `add_subdirectory(thirdparty)`——使 imgui 和 googletest 均由 `thirdparty/CMakeLists.txt` 统一管理

3. 修改 `src/CMakeLists.txt`
    1. 在 `rtfs2d_core` 的源文件列表中追加 `imgui_vulkan_context.cpp`
    2. 在 `target_link_libraries` 中追加 `external::imgui`

4. 修改 `src/device_manager.h`
    1. 新增 getter `vk::raii::Instance& vk_instance() const { return *instance_; }`——供 ImGui 初始化获取 `VkInstance` 原始句柄

5. 修改 `src/graphics_context.h`
    1. 将原 `RecordCommands(cb, img_idx, gradient_type, vis_mode)` 拆分为三个方法：
    2. `void BeginRenderPass(const vk::raii::CommandBuffer& cb, uint32_t img_idx) const;`——执行图像布局转换（`eNone→eColorAttachmentOptimal`）→ 清除颜色附件 → `cb.beginRenderPass(bi, eInline)`（原 `RecordCommands` 前半段）
    3. `void EndRenderPass(const vk::raii::CommandBuffer& cb, uint32_t img_idx) const;`——调用 `cb.endRenderPass()` → 将 `image_layouts_[img_idx]` 设为 `ePresentSrcKHR`（原 `RecordCommands` 末尾两行）
    4. `void RecordCommands(const vk::raii::CommandBuffer& cb, uint32_t gradient_type, uint32_t vis_mode) const;`——仅包含视口/剪刀设置、管线绑定、描述符集绑定、push constant 推送、`cb.draw(3, 1, 0, 0)`（原 `RecordCommands` 中间段），不再包含 render pass 的 begin/end

6. 修改 `src/graphics_context.cpp`
    1. 将原 `RecordCommands` 的方法体按上述拆分到 `BeginRenderPass`、`RecordCommands`、`EndRenderPass` 三个方法中
    2. `BeginRenderPass` 保留 barrier + clear value + beginRenderPass 逻辑
    3. `RecordCommands` 保留 viewport/scissor + bindPipeline + bindDescriptorSets + pushConstants + draw 逻辑
    4. `EndRenderPass` 保留 `endRenderPass()` + 布局更新

7. 创建 `src/imgui_vulkan_context.h`
    1. 声明 `class ImGuiVulkanContext`，构造参数：`GLFWwindow* window`、`DeviceManager& dm`、`vk::RenderPass render_pass`、`uint32_t swapchain_image_count`
    2. 声明 `void RecordCommands(const vk::raii::CommandBuffer& cb)`——在一帧中完成 ImGui 的全部帧工作（NewFrame → Render → RenderDrawData）
    3. 声明 `void Shutdown()`——逆序销毁 ImGui 资源
    4. 私有成员 `std::unique_ptr<vk::raii::DescriptorPool> imgui_descriptor_pool_;`

8. 创建 `src/imgui_vulkan_context.cpp`
    1. 构造函数步骤 1——创建 ImGui 上下文：`IMGUI_CHECKVERSION()` → `ImGui::CreateContext()` → 获取 `ImGuiIO& io = ImGui::GetIO();` → `io.ConfigFlags |= ImGuiConfigFlags_NavEnableKeyboard;` → `io.IniFilename = nullptr;` → `ImGui::StyleColorsDark();`
    2. 构造函数步骤 2——绑定 GLFW 后端：调用 `ImGui_ImplGlfw_InitForVulkan(window, true);`
    3. 构造函数步骤 3——创建 ImGui 专用描述符池：常量 `pool_count = 16`，创建 `std::array` 含两个 `DescriptorPoolSize`：`eSampler`（count=pool_count）和 `eSampledImage`（count=pool_count）→ `DescriptorPoolCreateInfo` 设置 `maxSets = pool_count*2`、`flags = eFreeDescriptorSet` → `make_unique<vk::raii::DescriptorPool>(...)`
    4. 构造函数步骤 4——填充 `ImGui_ImplVulkan_InitInfo`：`Instance = *dm.vk_instance()`、`PhysicalDevice = *dm.physical_device()`、`Device = *dm.device()`、`QueueFamily = dm.graphics_queue_family_index()`、`Queue = *dm.graphics_queue()`、`DescriptorPool = **imgui_descriptor_pool_`、`MinImageCount = 2`、`ImageCount = swapchain_image_count`、`PipelineInfoMain.MSAASamples = VK_SAMPLE_COUNT_1_BIT`、`PipelineInfoMain.RenderPass = render_pass`
    5. 构造函数步骤 5——调用 `ImGui_ImplVulkan_Init(&init_info);` 初始化（2025 年新版 API 不再需要手动创建字体纹理）
    6. 实现 `RecordCommands`：顺序调用 `ImGui_ImplVulkan_NewFrame();` → `ImGui_ImplGlfw_NewFrame();` → `ImGui::NewFrame();` → `ImGui::Render();` → 获取 `ImDrawData* draw_data = ImGui::GetDrawData();` → `if (draw_data != nullptr)` → `ImGui_ImplVulkan_RenderDrawData(draw_data, *cb);`
    7. 实现 `Shutdown`：逆序调用 `ImGui_ImplVulkan_Shutdown();` → `ImGui_ImplGlfw_Shutdown();` → `ImGui::DestroyContext();`

9. 修改 `src/window.h`
    1. 追加 `#include "imgui_vulkan_context.h"`
    2. 追加私有成员 `std::unique_ptr<ImGuiVulkanContext> imgui_ctx_;`

10. 修改 `src/window.cpp` 的 `Show` 方法
    1. 在 `graphics_ctx_` 构造之后追加：`imgui_ctx_ = std::make_unique<ImGuiVulkanContext>(window_, *device_manager_, *swapchain_ctx_->render_pass(), swapchain_ctx_->swapchain_images().size());`
    2. 在 `glfw_guard` 的析构 lambda 中添加 `imgui_ctx_->Shutdown();`（在 `glfwTerminate()` 之前，确保 Vulkan 设备仍存活）
    3. 主循环中，将原 `graphics_ctx_->RecordCommands(cb, img_idx, ...)` 的单一调用替换为三步：
        - `graphics_ctx_->BeginRenderPass(cb, img_idx);`——开始渲染通道
        - `imgui_ctx_->RecordCommands(cb);`——ImGui 绘制（此时已在 RenderPass 内）
        - `graphics_ctx_->RecordCommands(cb, gradient, mode);`——流场可视化绘制
        - `graphics_ctx_->EndRenderPass(cb, img_idx);`——结束渲染通道
