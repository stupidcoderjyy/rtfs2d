# 10.2 配置类与控制面板

#### 目标
在[[10.1 ImGui 初始化]]的基础上，创建 `VisConfig` 数据类集中管理所有可视化参数，使用 ImGui 构建控制面板，根据 VisMode 条件显示不同组件，并提供 Pause/Resume、Reset、Init Field 三个公共按钮。实现：
1. `VisConfig` 使用 `std::array<float,3>` 存储三物理量系数和区间，`std::array<uint32_t,3>` 存储 RGB 颜色
2. 控制面板顶部三个按钮 + 时间步长滑条 + VisMode 下拉框 + 条件渲染

#### 规则
1. 创建 `src/render/vis_config.h`
    1. 声明枚举 `VisField { kSpeed=0, kPressure=1, kVorticity=2 }`、`VisGradient { kGray=0, kJet=1, kCoolWarm=2 }`、`VisMode { kField=0, kDye=1 }`
    2. 声明 `struct VisConfig`——所有字段公开
    3. 字段 `VisMode vis_mode;`、`VisGradient vis_gradient;`、`VisField vis_field;`
    4. 字段 `std::array<float, 3> field_coeff;`——逐物理量的系数，默认 `{1.0, 100.0, 0.07}`
    5. 字段 `std::array<float, 3> max_field_coeff;`——各物理量滑条上限，默认 `{5.0, 500.0, 0.5}`
    6. 字段 `float dye_radius = 0.03f;`——墨迹半径
    7. 字段 `std::array<uint32_t, 3> dye_colors_;`——三层墨迹颜色 0xRRGGBB，默认 `{0x010101, 0x0DFFFF, 0x336699}`
    8. 字段 `float time_step = 0.016f;`——时间步长
    9. 字段 `bool paused = true;`——暂停状态
    10. 方法 `VisConfig()` 构造委托 `Reset()`
    11. 方法 `void Reset()`——恢复全部默认值
    12. 方法 `float& CurrentFieldCoeff()`——`return field_coeff[static_cast<int32_t>(vis_field)];`
    13. 方法 `float CurrentMaxFieldCoeff() const`——返回对应 `max_field_coeff`

2. 创建 `src/render/vis_config.cpp`
    1. `VisConfig()` 调用 `Reset()`
    2. `Reset()`：`vis_mode=kField`、`vis_field=kVorticity`、`vis_gradient=kJet`、`field_coeff` 三个默认值、`max_field_coeff` 三个默认值、`dye_radius=0.03`、`dye_colors_` 三个默认值、`time_step=0.016`、`paused=true`

3. 创建 `src/render/imgui_control_panel.h`
    1. 声明 `class ImGuiControlPanel`——构造接收 `VisConfig& config, ComputeContext& cc`
    2. `void Render() const;`
    3. 私有 `void RenderFieldControls() const;` 和 `void RenderDyeControls() const;`

4. 创建 `src/render/imgui_control_panel.cpp`
    1. `Render()` 完整结构：
        - `ImGui::Begin("Control Panel", nullptr, ImGuiWindowFlags_AlwaysAutoResize);`
        - 步骤 A——公共按钮行：`ImGui::Button(config_->paused ? "Resume" : "Pause")` 切换 `paused` → `ImGui::SameLine()` → `ImGui::Button("Reset")` 调用 `config_->Reset()` → `ImGui::SameLine()` → `ImGui::Button("Init Field")` 调用 `cc_->InitField()`
        - 步骤 B——时间步长滑条：`ImGui::SliderFloat("Time Step", &config_->time_step, 0.001f, 0.05f, "%.4f");`
        - 步骤 C——VisMode 下拉框：`"Field\0Dye\0\0"` → `ImGui::Combo("Mode", &idx, names)` → 更新 `vis_mode`
        - 步骤 D——`ImGui::Separator()` 后 `if (kField) RenderFieldControls(); else RenderDyeControls();`
        - `ImGui::End();`
    2. `RenderFieldControls()`：
        - VisGradient 下拉框：`"Grayscale\0Jet\0Cool/Warm\0\0"` → `ImGui::Combo("Gradient", &idx, names)` → 更新 `vis_gradient`
        - VisField 下拉框：`"Speed\0Pressure\0Vorticity\0\0"` → `ImGui::Combo("Field", &idx, names)` → 更新 `vis_field`
        - 系数滑条：`ImGui::SliderFloat("Coefficient", &config_->CurrentFieldCoeff(), 0.0f, config_->CurrentMaxFieldCoeff(), "%.4f");`
    3. `RenderDyeControls()`：
        - 半径滑条：`ImGui::SliderFloat("Ink Radius", &config_->dye_radius, 0.005f, 0.1f, "%.3f");`
        - 三个 `ColorEdit3`：`unpack(pack)` lambda 将 `uint32_t`→`float[3]`→`uint32_t`，标签 `"Ink Low"`、`"Ink Mid"`、`"Ink High"`，分别操作 `dye_colors_[0/1/2]`

5. 修改 `src/solver/compute_context.h`
    1. 删除旧的 `vis_field_`/`vis_gradient_`/`vis_mode_` 成员及其 getter/setter
    2. 新增 `VisConfig* vis_config_;` 成员
    3. 构造函数增加 `VisConfig& vis_config` 参数
