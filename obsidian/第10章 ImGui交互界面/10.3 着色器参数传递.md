# 10.3 着色器参数传递

#### 目标
在[[10.2 配置类与控制面板]]的基础上，修改着色器和 C++ 调度代码，将 `VisConfig` 中的系数、颜色、时间步长传递到 GPU。实现：
1. `compute_scalar.comp` push constant 扩展为 `{uint mode; float coeff;}`，替代硬编码乘数
2. `fullscreen.frag` push constant 扩展为 `{uint gradientType; uint visMode; uint dyeColorLow; uint dyeColorMid; uint dyeColorHigh;}`，`unpackColor` 解码 0xRRGGBB
3. 6 个着色器的 `const float DT` 改为 `layout(push_constant) uniform Params { float dt; } pc;`

#### 规则
1. 修改 `shaders/compute_scalar.comp`
    1. push constant 从 `{ uint mode; }` 改为 `layout(push_constant) uniform Params { uint mode; float coeff; } pc;`
    2. 速度模式：`scalar.data[idx] = speed * pc.coeff;`
    3. 压力模式：`scalar.data[idx] = p.data[idx] * pc.coeff;`
    4. 涡量模式：`scalar.data[idx] = abs(computeVorticity(idx,i,j)) * pc.coeff;`

2. 修改 `shaders/fullscreen.frag`
    1. push constant 从 `{ uint gradientType; uint visMode; }` 扩展为 `layout(push_constant) uniform VisParams { uint gradientType; uint visMode; uint dyeColorLow; uint dyeColorMid; uint dyeColorHigh; } vis;`
    2. 新增 `vec3 unpackColor(uint c)`：`return vec3(float((c>>16)&0xFFu)/255.0, float((c>>8)&0xFFu)/255.0, float(c&0xFFu)/255.0);`
    3. 染料渲染分支改为：`vec3 color_low = unpackColor(vis.dyeColorLow); vec3 color_mid = unpackColor(vis.dyeColorMid); vec3 color_high = unpackColor(vis.dyeColorHigh); vec3 dye_color = mix(color_low, mix(color_mid, color_high, dye_val), dye_val);`

3. 修改 6 个着色器将 `const float DT = 0.016f;` 改为 push constant
    1. `advection.comp`：删除 `const float DT` → 追加 `layout(push_constant) uniform Params { float dt; } pc;` → `DT * INV_DX/DY` → `pc.dt * INV_DX/DY`
    2. `dye_advection.comp`：同上
    3. `ibm_interpolate.comp`：`-vx / DT` → `-vx / pc.dt`
    4. `ibm_spread_markers.comp`：`w * fx * DT` → `w * fx * pc.dt`
    5. `poisson.comp`：`border_pressure` 中 `/ DT` → `/ pc.dt`；push constant 块从 `{float alpha; float beta;}` 扩展为 `{float alpha; float beta; float dt;}`
    6. `project.comp`：删除 `const float DT` → 追加 `layout(push_constant) uniform Params { float dt; } pc;` → `/ DT` → `/ pc.dt`

4. 修改 `src/solver/fluid_solvers.cpp` 的 push const size
    1. `task_advection_` 和 `task_dye_advection_`：追加 `.SetPushConstSize(sizeof(float))`
    2. `task_ibm_interpolate_` 和 `task_ibm_spread_`：确认已有 `.SetPushConstSize(sizeof(float))`
    3. `task_poisson_`：`.SetPushConstSize(3 * sizeof(float))`（alpha + beta + dt）
    4. `task_projection_`：追加 `.SetPushConstSize(sizeof(float))`
    5. `task_compute_scalar_`：`.SetPushConstSize(sizeof(uint32_t) + sizeof(float))`（mode + coeff）

5. 修改 `src/solver/compute_context.cpp` 的 `RecordCommands`
    1. `advection`：`.PushConstant<float>(vis_config_->time_step).End(cell_count_)`
    2. `dye_advection`：同上
    3. `ibm_interpolate` 和 `ibm_spread`：同上
    4. `poisson`：`.PushConstant<float>({alpha_p, beta_p, vis_config_->time_step}).End(cell_count_)`
    5. `projection`：`.PushConstant<float>(vis_config_->time_step).End(cell_count_)`
    6. `compute_scalar`：`.PushConstant<uint32_t>({...}).PushConstant<float>(vis_config_->CurrentFieldCoeff(), sizeof(uint32_t)).End(cell_count_)`
    7. `dye_source`：`.PushConstant<float>({dye_x_, dye_y_, vis_config_->dye_radius}).End(cell_count_)`

6. 修改 `src/render/graphics_context.cpp`
    1. `CreateGraphicsPipeline` 中 `PushConstantRange` 大小从 `2*sizeof(uint32_t)` 改为 `5*sizeof(uint32_t)`
    2. `RecordCommands` 中 push constant 数组 `{gradient, mode, dyeColors[0], dyeColors[1], dyeColors[2]}` 从 `vis_config` 读取
