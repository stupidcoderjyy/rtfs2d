# 5.7 流体步进编排

#### 目标
在[[5.6 压力投影]]的基础上，在 `ComputeContext` 中新增 `RecordFluidStepCommands` 方法串接完整流体步进，实现：
1. 半拉格朗日平流 u/v 各一次 → 扩散雅可比迭代 21 次（奇数次结束以确保 u/v 留在缓冲 0/1）→ 散度计算 → 压力雅可比求解 100 次 → 压力投影
2. 内存屏障由 `AddBufferMemoryWriteReadBarrier` 统一管理（不在 solver 内部）
3. `RecordAndSubmit` 改为调用 `RecordFluidStepCommands`

#### 规则
1. 在 `vk_compute.h` 中添加 solver 成员和辅助方法
    1. 添加 `#include` 引入 `advection_solver.h`、`jacobi_solver.h`、`divergence_solver.h`、`projection_solver.h`
    2. 添加四个 `std::unique_ptr` solver 成员和 `std::unique_ptr<vk::raii::PipelineLayout> pipeline_layout_`
    3. 声明私有方法 `void CreatePipelineLayout();`
    4. 声明私有方法 `void RecordFluidStepCommands(const vk::raii::CommandBuffer& cb) const;`
    5. 声明公有方法 `void AddBufferMemoryWriteReadBarrier(const vk::raii::CommandBuffer& cb, int buf) const;`——对指定 buffer 索引添加 `eShaderWrite → eShaderRead` 管线屏障

2. 实现 `CreatePipelineLayout`——用 `descriptor_set_layout_` 创建 `pipeline_layout_`

3. 实现 `RecordFluidStepCommands`——按序录制以下步骤
    1. 以 `eSimultaneousUse` 调用 `cb.begin`
    2. 平流 u——`advection_solver_->RecordCommands(cb, DescriptorSetAt(kSetAdvectionU));`，barrier 保护缓冲 2
    3. 平流 v——`advection_solver_->RecordCommands(cb, DescriptorSetAt(kSetAdvectionV));`，barrier 保护缓冲 0
    4. 扩散迭代 21 次——每次奇偶交替：偶次扩散 u（写缓冲 2、barrier 保护缓冲 1）、偶次扩散 v（写缓冲 1、barrier 保护缓冲 3）；奇次扩散 u（写缓冲 0、barrier 保护缓冲 2）、奇次扩散 v（写缓冲 3、barrier 保护缓冲 0）。奇数次结束确保 u_src 回到缓冲 0、v_src 回到缓冲 1
    5. 散度计算——`divergence_solver_->RecordCommands(cb, DescriptorSetAt(kSetDivergence));`，barrier 保护缓冲 1
    6. 压力求解 100 次——奇偶交替 ping-pong：偶次写缓冲 3、barrier 保护缓冲 3；奇次写缓冲 4、barrier 保护缓冲 4
    7. 压力投影——`projection_solver_->RecordCommands(cb, DescriptorSetAt(kSetProjection));`，barrier 保护缓冲 0 和 1
    8. `cb.end();`

4. 修改构造函数——在 `CreateDescriptorSets()` 之后依次调用 `CreatePipelineLayout()` 和四个 solver 的构造

5. 修改 `RecordAndSubmit`——分配一次性 command buffer 后调用 `RecordFluidStepCommands(cb)`、`queue.submit(si)`、`queue.waitIdle()`
