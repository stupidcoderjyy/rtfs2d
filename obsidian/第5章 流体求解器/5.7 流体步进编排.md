# 5.7 流体步进编排

#### 目标
在[[5.6 压力投影]]的基础上，在 `ComputeContext` 中新增 `FluidStep` 方法和 ping-pong 缓冲交换机制，实现：
1. `FluidStep` 按序调用半拉格朗日平流（u/v 各一次）→ 雅可比扩散迭代 → 散度计算 → 雅可比压力求解迭代 → 压力投影
2. `SwapVelocityBuffers` 交换 u_src↔u_dst、v_src↔v_dst 的缓冲指向并通过 `WriteBuffer` 更新描述符集
3. `RecordAndSubmit` 改为调用 `FluidStep`

#### 规则
1. 在 `vk_compute.h` 中添加四个求解器成员
    1. 添加 `std::unique_ptr<AdvectionSolver> advection_solver_;`，以及 `jacobi_solver_`、`divergence_solver_`、`projection_solver_`
    2. 声明私有方法 `void SwapVelocityBuffers();`——交换 src/dst 缓冲并更新描述符集
    3. 声明公有方法 `void FluidStep(const vk::raii::Queue& queue);`——完整执行一次流体步进

2. 实现 `SwapVelocityBuffers`
    1. 调用 `std::swap(velocity_buffers_[0], velocity_buffers_[1])` 交换 u_src↔u_dst，对应的 `velocity_memories_` 同步 swap
    2. 调用 `std::swap(velocity_buffers_[2], velocity_buffers_[3])` 交换 v_src↔v_dst
    3. 调用 `DescriptorSetBuilder::WriteBuffer` 重新将 binding 1 指向交换后的 `VelocityBuffer(eUDst)`、binding 2 指向 `VelocityBuffer(eUSrc)`、binding 3 指向 `VelocityBuffer(eVSrc)`——确保描述符集始终映射到正确的交换后缓冲

3. 实现 `FluidStep`——以下子步骤按序执行：
    1. 分配一次性 command buffer——参照 `RecordComputeCommands` 中前四行的分配模式：构造 `vk::CommandBufferAllocateInfo`，`setCommandPool(dm_->compute_command_pool())`、`setCommandBufferCount(1)`、`setLevel(ePrimary)`，调用 `dm_->device().allocateCommandBuffers(ai)` 取 `cbs[0]` 作为局部变量 `auto cb = std::move(cbs[0])`
    2. 平流 u 分量——调用 `DescriptorSetBuilder::WriteBuffer` 将 binding 0 指向 `eUSrc`、binding 1 指向 `eUDst`，然后调用 `advection_solver_->RecordCommands(cb)`，调用 `SwapVelocityBuffers` 将 u 分量的新值（在 `eUDst` 中）变成下一次读取的 `eUSrc`
    3. 平流 v 分量——调用 `WriteBuffer` 将 binding 0 指向 `eVSrc`、binding 1 指向 `eVDst`，调用 `advection_solver_->RecordCommands(cb)`，调用 `SwapVelocityBuffers` 交换 v 分量
    4. 扩散迭代——在 for 循环中执行若干次（如 4 次）：调用 `WriteBuffer` 将 binding 0 指向 `eUSrc`（当前场）、binding 1 指向 `eUSrc`（源项暂用自身）、binding 3 指向 `eUDst`（新场），调用 `jacobi_solver_->RecordCommands(cb, alpha, beta)`（alpha=`dt*viscosity/(dx*dx)`，beta=`4.0 + alpha`），调用 `SwapVelocityBuffers`；v 分量同理
    5. 散度计算——调用 `WriteBuffer` 将 binding 1 指向散度输出目标（可复用 `eUDst`），调用 `divergence_solver_->RecordCommands(cb)`
    6. 压力求解迭代——在 for 循环中执行若干次（如 20 次）：调用 `WriteBuffer` 将 binding 0 指向 `scalar_field_buffer_`（压力场当前值）、binding 1 指向散度场（`eUDst`）、binding 3 指向 `eUDst`（或复用 `scalar_field_buffer_` 的临时副本），调用 `jacobi_solver_->RecordCommands(cb, alpha, beta)`（alpha=`-(dx*dx)`，beta=`4.0`）
    7. 压力投影——调用 `WriteBuffer` 将 binding 0 指向压力场最终值，调用 `projection_solver_->RecordCommands(cb)`
    8. 提交与等待——构造 `vk::SubmitInfo si{};`，`si.setCommandBuffers(*cb);`，调用 `queue.submit(si);` 和 `queue.waitIdle();`

4. 修改构造函数——初始化四个求解器
    1. 在构造函数末尾（`RecordComputeCommands()` 之后）依次初始化：`advection_solver_ = std::make_unique<AdvectionSolver>(*dm_, *this);`，以及 `jacobi_solver_`、`divergence_solver_`、`projection_solver_`

5. 修改 `RecordAndSubmit`
    1. 将原有的 `vk::SubmitInfo` 构造和 submit 逻辑替换为一行 `FluidStep(queue);`
    2. 移除 `if (!verified_) { Verify(); ... }` 的验证逻辑
