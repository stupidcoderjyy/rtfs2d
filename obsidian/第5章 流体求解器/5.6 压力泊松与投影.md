# 5.6 压力泊松与投影

#### 目标
在[[5.5 散度计算]]的基础上，编写 `poisson.comp` 和 `project.comp` 两个着色器，实现：
1. `SolvePoisson(cb, ds, alpha, beta)`——以散度为源项，48 次雅可比迭代求解压力泊松方程
2. `SolveProjection(cb, ds)`——用压力梯度修正速度场，使其无散

#### 规则
1. 创建 `shaders/poisson.comp`
    1. `local_size_x = 128`，`layout(constant_id = 0/1)` 的 NX/NY
    2. binding 0=u、1=v、2=div（散度源项）、3=p_src（读当前压力）、4=p_dst（写新压力），binding 5-8 为 BC 缓冲
    3. 声明 `layout(push_constant) uniform Params { float alpha; float beta; } pc;`
    4. 实现 `border_pressure(pi, edge, ci, cj)`——NoSlipWall/SlipWall→返回 pi（Neumann），Velocity→返回 pi（Neumann），Pressure→返回 -pi（Dirichlet p=0）
    5. 实现 `getNeighborP(i, j)`——越界时 clamp 坐标后调用 `border_pressure`
    6. `main()` 中取四邻居压力 + 散度源项 b，计算 `p_dst = (left+right+bottom+top + pc.alpha*b) / pc.beta`
    7. 在 `shaders/CMakeLists.txt` 中追加 `poisson.comp`

2. 创建 `shaders/project.comp`
    1. `local_size_x = 128`，`layout(constant_id = 0/1)` 的 NX/NY
    2. binding 0=u（读写）、1=v（读写）、2=p（读压力），binding 5-8 为 BC 缓冲
    3. 复用 `border_pressure` 和 `getPressure`（同 poisson.comp）
    4. `main()` 中取四邻居压力，`inv_2dx = 0.5*NX`，`u -= (p_right-p_left)*inv_2dx`，`v -= (p_top-p_bottom)*inv_2dx`
    5. 在 `shaders/CMakeLists.txt` 中追加 `project.comp`

3. `FluidSolvers::CreateJacobiPipelines` 中为 poisson 创建独立 pipeline layout（同 diffusion）
4. `SolvePoisson` 传入 alpha=-(dx*dx)、beta=4.0
