# 5.6 压力投影

#### 目标
在[[5.5 散度计算]]与[[5.4 雅可比迭代]]的基础上，编写 `project.comp` 着色器并创建 `ProjectionSolver` 类，实现：
1. `ProjectionSolver` 复用 `ComputeContext::pipeline_layout()`（无 push constants），构造时通过 `DeviceManager::CreateComputePipelineFromFile` 创建管线
2. `project.comp` 从 binding 0 读取压力场、binding 2 和 binding 3 就地读写 u/v 速度
3. `RecordCommands` 录制 bind → dispatch → barrier 到传入的 command buffer

#### 规则
1. 创建 `shaders/project.comp`
    1. 声明 `#version 450`，`local_size_x = 128`
    2. 硬编码 `NX = 128u, NY = 128u`，`DX = 1.0f / float(NX)`
    3. 声明 binding 0 为压力缓冲（`PressureBuffer`，变量名 `p`）、binding 2 为 u 速度（`UBuffer`，变量名 `u`，同时作为读写缓冲）、binding 3 为 v 速度（`VBuffer`，变量名 `v`，同时作为读写缓冲），均使用 `std430` 布局
    4. 在 `main()` 中用一维 `gl_GlobalInvocationID.x` 反算二维坐标，边界越界直接返回
    5. 用辅助函数取左右邻居压力值、上下邻居压力值（越界返回 `0.0`），计算 `u.data[idx] -= (p_right - p_left) / (2.0 * DX)`，`v.data[idx] -= (p_top - p_bottom) / (2.0 * DX)`
    6. 在 `shaders/CMakeLists.txt` 的 `SHADER_SOURCES` 列表中追加 `project.comp`

2. 创建 `src/projection_solver.h`——与 `AdvectionSolver` 的声明模式完全一致
    1. 添加 `#ifndef RTFS2D_PROJECTION_SOLVER_H` / `#define` 守卫，包含 `<vulkan/vulkan_raii.hpp>`，前置声明 `class DeviceManager` 和 `class ComputeContext`
    2. 声明构造函数 `ProjectionSolver(DeviceManager& dm, ComputeContext& cc);`
    3. 声明公有方法 `void RecordCommands(const vk::raii::CommandBuffer& cb) const;`
    4. 私有成员：`DeviceManager* dm_`、`ComputeContext* cc_`、`std::unique_ptr<vk::raii::Pipeline> pipeline_`

3. 创建 `src/projection_solver.cpp`——复制 `AdvectionSolver::RecordCommands` 的完整代码，以下修改：
    1. 构造函数中调用 `dm_->CreateComputePipelineFromFile(cc.pipeline_layout(), "shaders/project.comp.spv")`
    2. `RecordCommands` 中 `cb.bindPipeline` 的管线对象改为 `**pipeline_`
    3. barrier 的 `setBuffer` 指向 u 速度缓冲：`cc_->VelocityBuffer(ComputeContext::eUSrc)`——project shader 同时对 u 和 v 就地写入，至少需要对其中一个施加屏障。后续 5.7 `FluidStep` 中 project 作为最后一个 step，其后的 submit + waitIdle 隐式保证了 v 的可见性，因此此处只需对 u 显式加 barrier
    4. 其余代码（begin、bindDescriptorSets、dispatch、barrier 构造、end）与 `AdvectionSolver::RecordCommands` 完全一致

4. 在 `src/CMakeLists.txt` 中追加 `projection_solver.h` 和 `projection_solver.cpp`
