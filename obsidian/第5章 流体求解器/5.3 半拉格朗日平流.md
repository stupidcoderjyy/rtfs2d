# 5.3 半拉格朗日平流

#### 目标
在[[5.2 FluidSolvers 类]]的基础上，编写 `advection.comp` 着色器，实现：
1. `FluidSolvers::SolveAdvection(cb, ds)` 通过 specialization constants 获得实际 NX/NY
2. `advection.comp` 读取 u/v 速度场，反向追踪后用双线性插值采样源场，写出平流结果

#### 规则
1. 创建 `shaders/advection.comp`
    1. `local_size_x = 128`，`layout(constant_id = 0) const uint NX` 和 `constant_id = 1` 的 NY，`DT = 0.016f`
    2. binding 0=u_src、1=v_src（读速度），binding 2=u_dst、3=v_dst（写结果），binding 5-8 为四边 BC 缓冲（本章暂用于越界保护）
    3. 实现 `border_velocity(vi, is_u, edge, local)`——查询 BC 缓冲的类型和速度值，按四种类型返回 ghost 值：NoSlipWall→0, SlipWall→法向0切向vi, Velocity→预设值, Pressure→vi
    4. 实现 `getU/getV` 辅助函数——正常坐标直接取 `u.data/v.data[idx]`，越界时 clamp 坐标后调用 `border_velocity`
    5. 实现 `sampleBilinear(x, y, is_u)`——用 floor/ceil 定四角、mix 三次完成双线性插值，越界坐标经 `border_velocity` 处理
    6. `main()` 中用 `idx = gl_GlobalInvocationID.x` 反算 `(i,j)`，读当前速度 u/v，计算反向追踪坐标 `bx = i+0.5 - u*DT/dx` 和 `by = j+0.5 - v*DT/dx`，减去 0.5 偏移后调用 `sampleBilinear`，分别写出 u_dst 和 v_dst
    7. 在 `shaders/CMakeLists.txt` 中追加 `advection.comp`
