# 5.3 半拉格朗日平流

#### 目标
在[[5.2 速度场GPU缓冲]]的基础上，编写 `advection.comp` 着色器并创建 `AdvectionSolver` 类，实现：
1. `AdvectionSolver` 持有独立的 compute pipeline，构造函数接受 `DeviceManager&`、`const vk::raii::PipelineLayout&` 和 `ComputeContext&`
2. `advection.comp` 从 binding 0 读取源标量场、binding 2 读取 u 速度、binding 3 读取 v 速度，向 binding 1 写出平流后的场
3. CPU 端通过 `RecordCommands` 方法将调度命令录制到传入的 command buffer 中

#### 规则
1. 创建 `shaders/advection.comp`——将平流逻辑编码为 compute shader
    1. 声明 `#version 450`，`local_size_x = 128`
    2. 声明 binding 0 为源缓冲（`SrcBuf`）、binding 1 为目标缓冲（`DstBuf`）、binding 2 为 u 速度缓冲、binding 3 为 v 速度缓冲，均使用 `std430` 布局
    3. 硬编码 `nx = 128u, ny = 128u`，时间步 `dt = 0.016`，网格间距 `dx = 1.0 / 128.0`
    4. 对每个单元计算反向追踪坐标 `bx = i + 0.5 - u * dt / dx, by = j + 0.5 - v * dt / dx`，clamp 到有效范围后执行双线性插值，结果写入 binding 1
    5. 在 `shaders/CMakeLists.txt` 中追加 `advection.comp` 的编译条目

2. 创建 `src/advection_solver.h`，声明 `AdvectionSolver` 类
    1. 添加 `#ifndef RTFS2D_ADVECTION_SOLVER_H` / `#define` 守卫，包含 `<vulkan/vulkan_raii.hpp>`，前置声明 `class DeviceManager` 和 `class ComputeContext`
    2. 声明构造函数 `AdvectionSolver(DeviceManager& dm, const vk::raii::PipelineLayout& pipeline_layout, ComputeContext& cc);`
    3. 声明公有方法 `void RecordCommands(const vk::raii::CommandBuffer& cb);`——录制 bind、dispatch 和 barrier
    4. 私有成员：`DeviceManager* dm_`、`ComputeContext* cc_`、`std::unique_ptr<vk::raii::Pipeline> pipeline_`、`const vk::raii::PipelineLayout* pipeline_layout_`

3. 创建 `src/advection_solver.cpp`
    1. 在构造函数中创建管线——调用 `dm_->CreateComputePipelineFromFile(*pipeline_layout_, "shaders/advection.comp.spv")`，将返回值置入 `pipeline_ = std::move(...)`
    2. 实现 `RecordCommands`——参照 `ComputeContext::RecordComputeCommands` 的录制模式，逐行复制对应 API 调用并替换关键参数：
        - 复制 `cb.bindPipeline(vk::PipelineBindPoint::eCompute, **compute_pipeline_);`，将 `**compute_pipeline_` 替换为 `**pipeline_`
        - 复制 `cb.bindDescriptorSets(vk::PipelineBindPoint::eCompute, **pipeline_layout_, 0, **descriptor_set_, nullptr);`，将 `**pipeline_layout_` 替换为 `*pipeline_layout_`（此处 `pipeline_layout_` 是指针而非 unique_ptr，解引用一层即可），将 `**descriptor_set_` 替换为 `cc_->descriptor_set()`（getter 返回引用，不加 `*`）
        - 复制 `int group_count = (compute_cell_count_ + 127) / 128;`，将 `compute_cell_count_` 替换为 `cc_->cell_count()`
        - 复制 `cb.dispatch(group_count, 1, 1);` 保持不变
        - 复制 `vk::BufferMemoryBarrier barrier{};` 到 `cb.pipelineBarrier(...)` 的整段 barrier 构造代码，执行以下替换：`setBuffer(**scalar_field_buffer_)` 替换为对目标缓冲的引用——当前平流结果写入 binding 1 即 `u_src`，通过 `cc_` 获取缓冲引用后传入；`setSize(compute_buf_size_)` 替换为 `cc_->buf_size()`；`setDstAccessMask(vk::AccessFlagBits::eHostRead)` 替换为 `setDstAccessMask(vk::AccessFlagBits::eShaderRead)`（后续 compute 管线可能读取此缓冲）；`cb.pipelineBarrier` 的 dst stage 从 `eHost` 替换为 `eComputeShader`

4. 在 `src/CMakeLists.txt` 中追加 `advection_solver.h` 和 `advection_solver.cpp`
