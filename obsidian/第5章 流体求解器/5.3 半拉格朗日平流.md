# 5.3 半拉格朗日平流

#### 目标
在[[5.2 速度场GPU缓冲]]的基础上，编写 `advection.comp` 着色器并创建 `AdvectionSolver` 类，实现：
1. `AdvectionSolver` 持有独立的 compute pipeline，构造函数接受 `DeviceManager&` 和 `ComputeContext&`
2. `advection.comp` 从 binding 0 读取源场、binding 2/3 读取速度矢量 (u,v)、向 binding 1 写出平流结果
3. `RecordCommands` 接受 `(cb, ds)` 录制 bind + dispatch

#### 规则
1. 创建 `shaders/advection.comp`
    1. 声明 `#version 450`，`local_size_x = 128`
    2. 硬编码 `NX = 128u, NY = 128u`，`DT = 0.016f`，`DX = 1.0f / float(NX)`
    3. 声明 binding 0 为源缓冲（变量名 `src`）、binding 1 为目标缓冲（变量名 `dst`）、binding 2 为 u 速度（变量名 `uSrc`）、binding 3 为 v 速度（变量名 `vSrc`），均使用 `std430` 布局
    4. 实现 `sampleBilinear(float x, float y)` 函数——用 `floor/ceil` 计算四个角点索引、clamp 到有效范围、从 `src` 读取后用 `mix` 三次完成双线性插值
    5. 在 `main()` 中用一维 `gl_GlobalInvocationID.x` 反算二维坐标、边界保护后从 `uSrc/vSrc` 读取速度、计算反向追踪坐标、减去 0.5 偏移后调用 `sampleBilinear`、通过 `dst.data[base]` 写出
    6. 在 `shaders/CMakeLists.txt` 的 `SHADER_SOURCES` 列表中追加 `advection.comp`

2. 创建 `src/advection_solver.h`
    1. 添加 `#ifndef RTFS2D_ADVECTION_SOLVER_H` / `#define` 守卫，包含 `<vulkan/vulkan_raii.hpp>`，前置声明 `class DeviceManager` 和 `class ComputeContext`
    2. 声明构造函数 `AdvectionSolver(DeviceManager& dm, ComputeContext& cc);`
    3. 声明公有方法 `void RecordCommands(const vk::raii::CommandBuffer& cb, const vk::raii::DescriptorSet& ds) const;`
    4. 私有成员：`DeviceManager* dm_`、`ComputeContext* cc_`、`std::unique_ptr<vk::raii::Pipeline> pipeline_`

3. 创建 `src/advection_solver.cpp`
    1. 构造函数中调用 `dm_->CreateComputePipelineFromFile(cc.pipeline_layout(), "shaders/advection.comp.spv")` 并将返回值 `std::move` 入 `pipeline_`
    2. 实现 `RecordCommands`——调用 `cb.bindPipeline(eCompute, **pipeline_)`，调用 `cb.bindDescriptorSets(eCompute, *cc_->pipeline_layout(), 0, *ds, nullptr)`，计算 workgroup 数量 `(cc_->cell_count() + 127) / 128` 后 `cb.dispatch(group_count, 1, 1)`
    3. 不在 solver 内部添加 barrier——屏障逻辑统一在 `RecordFluidStepCommands` 中管理

4. 在 `src/CMakeLists.txt` 中追加 `advection_solver.h` 和 `advection_solver.cpp`
