# 5.5 散度计算

#### 目标
在[[5.4 雅可比迭代]]的基础上，编写 `diverge.comp` 着色器并创建 `DivergenceSolver` 类，实现：
1. `DivergenceSolver` 复用 `ComputeContext::pipeline_layout()`（无 push constants），构造时通过 `DeviceManager::CreateComputePipelineFromFile` 创建管线
2. `diverge.comp` 从 binding 2 读取速度 u、binding 3 读取速度 v，向 binding 1 写出散度场
3. `RecordCommands` 录制 bind → dispatch → barrier 到传入的 command buffer

#### 规则
1. 创建 `shaders/diverge.comp`
    1. 声明 `#version 450`，`local_size_x = 128`
    2. 硬编码 `NX = 128u, NY = 128u`，`DX = 1.0f / float(NX)`
    3. 声明 binding 1 为散度输出缓冲（`DivBuffer`，变量名 `div`）、binding 2 为 u 速度（`UBuffer`，变量名 `u`）、binding 3 为 v 速度（`VBuffer`，变量名 `v`），均使用 `std430` 布局
    4. 在 `main()` 中用一维 `gl_GlobalInvocationID.x` 反算二维坐标，边界越界直接返回
    5. 用辅助函数取左右邻居 u 值、上下邻居 v 值（越界返回 `0.0`），计算 `div.data[idx] = (u_right - u_left) / (2.0 * DX) + (v_top - v_bottom) / (2.0 * DX)`
    6. 在 `shaders/CMakeLists.txt` 的 `SHADER_SOURCES` 列表中追加 `diverge.comp`

2. 创建 `src/divergence_solver.h`——与 `AdvectionSolver` 的声明模式完全一致
    1. 添加 `#ifndef RTFS2D_DIVERGENCE_SOLVER_H` / `#define` 守卫，包含 `<vulkan/vulkan_raii.hpp>`，前置声明 `class DeviceManager` 和 `class ComputeContext`
    2. 声明构造函数 `DivergenceSolver(DeviceManager& dm, ComputeContext& cc);`
    3. 声明公有方法 `void RecordCommands(const vk::raii::CommandBuffer& cb) const;`
    4. 私有成员：`DeviceManager* dm_`、`ComputeContext* cc_`、`std::unique_ptr<vk::raii::Pipeline> pipeline_`

3. 创建 `src/divergence_solver.cpp`——复制 `AdvectionSolver::RecordCommands` 的完整代码，以下修改：
    1. 构造函数中调用 `dm_->CreateComputePipelineFromFile(cc.pipeline_layout(), "shaders/diverge.comp.spv")`——复用 `cc_->pipeline_layout()`
    2. `RecordCommands` 中 `cb.bindPipeline` 的管线对象改为 `**pipeline_`
    3. barrier 的 `setBuffer` 指向散度输出对应的缓冲——散度写入 binding 1，当前描述符集中 binding 1 映射到 `eUDst`，因此用 `cc_->VelocityBuffer(ComputeContext::eUDst)` 或根据实际调用方约定选择缓冲
    4. 其余代码（begin、bindDescriptorSets、dispatch、barrier 构造、end）与 `AdvectionSolver::RecordCommands` 完全一致，无需修改

4. 在 `src/CMakeLists.txt` 中追加 `divergence_solver.h` 和 `divergence_solver.cpp`
