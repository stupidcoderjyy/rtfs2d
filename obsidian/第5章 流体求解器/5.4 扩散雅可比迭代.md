# 5.4 扩散雅可比迭代

#### 目标
在[[5.3 半拉格朗日平流]]的基础上，编写 `diffusion.comp` 着色器，实现：
1. `FluidSolvers::SolveDiffusion(cb, ds, alpha, beta)` 通过 push constants 传入扩散系数
2. 一次 dispatch 同时更新 u 和 v 两个分量的扩散结果

#### 规则
1. 创建 `shaders/diffusion.comp`
    1. `local_size_x = 128`，`layout(constant_id = 0) const uint NX`，`layout(constant_id = 1) const uint NY`
    2. binding 0=u_src、1=v_src（读当前值），binding 2=u_dst、3=v_dst（写新值），binding 5-8 为 BC 缓冲
    3. 声明 `layout(push_constant) uniform Params { float alpha; float beta; } pc;`
    4. 复用 `getU/getV` 和 `border_velocity`（同 advection.comp）
    5. `main()` 对 u 和 v 分量分别执行雅可比迭代：`u_dst = (u_left+u_right+u_bottom+u_top + pc.alpha*u_self) / pc.beta`，v 同理
    6. 在 `shaders/CMakeLists.txt` 中追加 `diffusion.comp`

2. `FluidSolvers` 的 `CreateJacobiPipelines` 中创建 diffusion 的独立 pipeline layout
    1. 构造 `vk::PushConstantRange` 设 stageFlags=eCompute、size=2*sizeof(float)
    2. `PipelineLayoutCreateInfo` 引用 `cc_->descriptor_set_layout()` 并设 push constant range
    3. 调用 `dm_->CreateComputePipelineFromFile`（不含 specialization constants，因为 diffusion 未在 `CreateSolverPipeline` 中创建）

3. `SolveDiffusion` 中通过 `cb.pushConstants<float>(*layout, eCompute, 0, {alpha, beta})` 传入参数
