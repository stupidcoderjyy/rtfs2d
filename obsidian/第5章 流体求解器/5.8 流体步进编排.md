# 5.8 流体步进编排

#### 目标
在[[5.7 涡量约束]]的基础上，在 `ComputeContext` 中实现 `RecordFluidStepCommands` 方法，串接完整六步流体步进，实现：
1. 半拉格朗日平流 → 扩散雅可比 11 次 → 涡量约束 → 散度计算 → 压力泊松 48 次 → 压力投影
2. 每步之间用 `AddBufferMemoryWriteReadBarrier` 保护写入目标
3. `RecordAndSubmit` 改为调用 `RecordFluidStepCommands`

#### 规则
1. 在 `vk_compute.h` 中添加成员
    1. `#include "fluid_solvers.h"`
    2. 添加 `std::unique_ptr<FluidSolvers> fluid_solvers_;` 成员
    3. 声明公有方法 `void AddBufferMemoryWriteReadBarrier(const vk::raii::CommandBuffer& cb, int buf) const;`——对指定缓冲索引添加 `eShaderWrite→eShaderRead` 屏障
    4. 声明私有方法 `void CreatePipelineLayout();` 和 `void RecordFluidStepCommands(const vk::raii::Queue& queue, const vk::raii::CommandBuffer& cb) const;`

2. 实现 `CreatePipelineLayout`
    1. `PipelineLayoutCreateInfo` 引用 `descriptor_set_layout_`，创建 `pipeline_layout_`

3. 实现 `RecordFluidStepCommands`
    1. `cb.begin({eSimultaneousUse})`
    2. advection：`SolveAdvection(cb, kSetAdvection)`，barrier 保护缓冲 2 和 3（写入目标）
    3. diffusion 11 次迭代——奇偶交替 ping-pong：偶次用 kSetDiffusionEven（写缓冲 0/1，barrier 保护），奇次用 kSetDiffusionOdd（写缓冲 2/3，barrier 保护）。11 次确保最终 u/v 留在缓冲 0/1
    4. vorticity：`SolveVorticity(cb, kSetVorticity, 0.5f)`，barrier 保护缓冲 0 和 1
    5. divergence：`SolveDivergence(cb, kSetDivergence)`，barrier 保护缓冲 2（散度写入目标）
    6. poisson 48 次迭代——奇偶 ping-pong：偶次用 kSetPressureEven（写缓冲 3，barrier 保护），奇次用 kSetPressureOdd（写缓冲 4，barrier 保护）
    7. projection：`SolveProjection(cb, kSetProjection)`，barrier 保护缓冲 0 和 1
    8. `cb.end()`

4. 修改 `RecordAndSubmit`
    1. 分配一次性 command buffer，调用 `RecordFluidStepCommands(queue, cb)`
    2. `queue.submit(si)`、`queue.waitIdle()`
