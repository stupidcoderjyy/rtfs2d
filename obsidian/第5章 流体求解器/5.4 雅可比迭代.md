# 5.4 雅可比迭代

#### 目标
在[[5.3 半拉格朗日平流]]的基础上，编写 `jacobi.comp` 着色器并创建 `JacobiSolver` 类，实现：
1. `JacobiSolver` 持有独立的 `pipeline_layout_`（含 push constant range），通过 push constants 传入 `alpha` 和 `beta`
2. `jacobi.comp` 从 binding 0 读取当前场、binding 1 读取源项、向 binding 3 写出新场
3. `RecordCommands` 接受 `(cb, ds, alpha, beta)` 录制 bind + pushConstants + dispatch

#### 规则
1. 创建 `shaders/jacobi.comp`
    1. 声明 `#version 450`，`local_size_x = 128`，硬编码 `NX = 128u, NY = 128u`
    2. 声明 binding 0 为当前场（变量名 `cur`）、binding 1 为源项场（变量名 `src`）、binding 3 为新场（变量名 `newF`），均使用 `std430` 布局
    3. 声明 push constants：`layout(push_constant) uniform Params { float alpha; float beta; } pc;`
    4. 实现 `getNeighbor(int i, int j)` 辅助函数——越界时返回 `cur.data[索引]`、正常时返回对应邻居值
    5. 在 `main()` 中用一维索引反算二维坐标、取四邻居、读源项 `b`、计算 `(left+right+bottom+top + pc.alpha*b)/pc.beta`、写入 `newF.data[idx]`
    6. 在 `shaders/CMakeLists.txt` 的 `SHADER_SOURCES` 列表中追加 `jacobi.comp`

2. 创建 `src/jacobi_solver.h`
    1. 声明构造函数 `JacobiSolver(DeviceManager& dm, ComputeContext& cc);`
    2. 声明 `void RecordCommands(const vk::raii::CommandBuffer& cb, const vk::raii::DescriptorSet& ds, float alpha, float beta) const;`
    3. 私有成员：`DeviceManager* dm_`、`ComputeContext* cc_`、`std::unique_ptr<vk::raii::PipelineLayout> pipeline_layout_`、`std::unique_ptr<vk::raii::Pipeline> pipeline_`

3. 创建 `src/jacobi_solver.cpp`
    1. 构造函数中创建含 push constant range 的独立 `pipeline_layout_`——构造 `vk::PushConstantRange pcr{};`，`setStageFlags(eCompute)`、`setOffset(0)`、`setSize(2*sizeof(float))`，然后 `vk::PipelineLayoutCreateInfo` 引用 `cc_->descriptor_set_layout()` 并设置 push constant range，调用 `dm_->device().createPipelineLayout(ci)` 后 `std::make_unique` 存入 `pipeline_layout_`
    2. 调用 `dm_->CreateComputePipelineFromFile(*pipeline_layout_, "shaders/jacobi.comp.spv")` 创建管线
    3. 实现 `RecordCommands`——`cb.bindPipeline` 绑 `**pipeline_`，`cb.bindDescriptorSets` 用 `**pipeline_layout_` 和参数 `ds`，`cb.pushConstants<float>(**pipeline_layout_, eCompute, 0, {alpha, beta})`，`cb.dispatch`

4. 在 `src/CMakeLists.txt` 中追加 `jacobi_solver.h` 和 `jacobi_solver.cpp`
