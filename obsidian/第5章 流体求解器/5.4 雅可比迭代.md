# 5.4 雅可比迭代

#### 目标
在[[5.3 半拉格朗日平流]]的基础上，编写 `jacobi.comp` 着色器并创建 `JacobiSolver` 类，实现：
1. `JacobiSolver` 持有独立的 pipeline layout（含 push constant range），通过 push constants 传入 `alpha` 和 `beta` 两个浮点参数
2. `jacobi.comp` 从 binding 0 读取当前场 `x`、binding 1 读取源项 `b`，向 binding 3 写出新场 `x_new`，公式为 `x_new = (邻居和 + alpha * b) / beta`
3. `RecordCommands` 接受 `(cb, alpha, beta)` 录制 bind → pushConstants → dispatch → barrier

#### 规则
1. 创建 `shaders/jacobi.comp`
    1. 声明 `#version 450`，`local_size_x = 128`
    2. 硬编码 `NX = 128u, NY = 128u`
    3. 声明 binding 0 为当前场（`XBuffer`，变量名 `x`）、binding 1 为源项场（`BBuffer`，变量名 `b`）、binding 3 为新场（`XNewBuffer`，变量名 `x_new`），均使用 `std430` 布局
    4. 声明 push constants：`layout(push_constant) uniform Params { float alpha; float beta; } pc;`
    5. 在 `main()` 中用一维 `gl_GlobalInvocationID.x` 反算二维坐标，边界越界直接返回
    6. 对每个单元取四邻居（`i-1, i+1, j-1, j+1`），越界时该邻居值视为 `0.0`
    7. 计算 `x_new.data[idx] = (left + right + bottom + top + pc.alpha * b.data[idx]) / pc.beta`
    8. 在 `shaders/CMakeLists.txt` 的 `SHADER_SOURCES` 列表中追加 `jacobi.comp`

2. 创建 `src/jacobi_solver.h`，声明 `JacobiSolver` 类
    1. 添加 `#ifndef RTFS2D_JACOBI_SOLVER_H` / `#define` 守卫，包含 `<vulkan/vulkan_raii.hpp>`，前置声明 `class DeviceManager` 和 `class ComputeContext`
    2. 声明构造函数 `JacobiSolver(DeviceManager& dm, ComputeContext& cc);`——与 `AdvectionSolver` 签名一致
    3. 声明公有方法 `void RecordCommands(const vk::raii::CommandBuffer& cb, float alpha, float beta) const;`
    4. 私有成员：`DeviceManager* dm_`、`ComputeContext* cc_`、`std::unique_ptr<vk::raii::PipelineLayout> pipeline_layout_`、`std::unique_ptr<vk::raii::Pipeline> pipeline_`

3. 创建 `src/jacobi_solver.cpp`——与 `advection_solver.cpp` 录制模式一致，以下修改点
    1. 在构造函数中创建独立的 pipeline layout——构造 `vk::PushConstantRange pcr{};`，设置 `setStageFlags(eCompute)`、`setOffset(0)`、`setSize(2 * sizeof(float))`，然后构造 `vk::PipelineLayoutCreateInfo`，设置 `setSetLayoutCount(1)` 引用 `cc_->descriptor_set_layout()` 和 `setPushConstantRanges(pcr)`，调用 `dm_->device().createPipelineLayout(ci)` 并将结果 `std::make_unique` 存入 `pipeline_layout_`。再调用 `dm_->CreateComputePipelineFromFile(*pipeline_layout_, "shaders/jacobi.comp.spv")` 创建管线
    2. `RecordCommands` 函数体复制 `AdvectionSolver::RecordCommands` 的完整代码——以下四处修改：
        - `cb.bindPipeline` 的管线对象改为 `**pipeline_`
        - `cb.bindDescriptorSets` 的 pipeline layout 改为 `**pipeline_layout_`
        - 在 `cb.dispatch` 之前插入 `cb.pushConstants<float>(**pipeline_layout_, vk::ShaderStageFlagBits::eCompute, 0, {alpha, beta});`——将 alpha/beta 以 `std::initializer_list<float>` 传入
        - barrier 的 `setBuffer` 指向 jacobi 写入的目标缓冲：`cc_->VelocityBuffer(ComputeContext::eUDst)`

4. 在 `src/CMakeLists.txt` 中追加 `jacobi_solver.h` 和 `jacobi_solver.cpp`
