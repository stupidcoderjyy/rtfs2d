# 5.7 涡量约束

#### 目标
在[[5.6 压力泊松与投影]]的基础上，编写 `vorticity.comp` 着色器，实现：
1. `FluidSolvers::SolveVorticity(cb, ds, epsilon)` 通过 push constants 传入强度系数
2. 计算旋度场，沿旋度梯度方向注入约束力以维持涡结构

#### 规则
1. 创建 `shaders/vorticity.comp`
    1. `local_size_x = 128`，`layout(constant_id = 0/1)` 的 NX/NY
    2. binding 0=u（读写）、1=v（读写），binding 5-8 为 BC 缓冲
    3. 声明 `layout(push_constant) uniform Params { float epsilon; } pc;`
    4. 复用 `getU/getV` 和 `border_velocity`（同 advection.comp）
    5. `main()` 中计算旋度 `omega = (v_right - v_left - u_up + u_down) * inv_2dx`
    6. 计算四个邻域的 `|omega|` 差分求梯度方向 `(grad_x, grad_y)`，归一化得 `(nx, ny)`
    7. 约束力 `fx = epsilon * dx * ny * omega`、`fy = -epsilon * dx * nx * omega`
    8. 施加幅值上限 `f_max = 2.0 / dx`，超限时等比缩放
    9. `u += fx`、`v += fy`
    10. 在 `shaders/CMakeLists.txt` 中追加 `vorticity.comp`

2. `FluidSolvers::CreateVorticitySolverPipeline` 创建独立 pipeline layout
    1. push constant range 大小 = sizeof(float)（只传 epsilon）
    2. pipeline 通过 specialization constants 传入 NX/NY
