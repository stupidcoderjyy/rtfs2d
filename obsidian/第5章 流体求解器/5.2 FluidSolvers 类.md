# 5.2 FluidSolvers 类

#### 目标
在[[5.1 描述符布局与GPU缓冲]]的基础上，创建统一的 `FluidSolvers` 类封装所有流体求解着色器的管线，实现：
1. 一个类管理六个 compute pipeline（advection、diffusion、divergence、poisson、projection、vorticity）
2. 扩散和泊松求解器持有独立的 `pipeline_layout_`（含 push constants），其余复用 `ComputeContext::pipeline_layout()`
3. 每个求解步骤暴露为 `SolveXxx(cb, ds, ...)` 方法，内部录制 bind + dispatch

#### 规则
1. 创建 `src/fluid_solvers.h`
    1. 前置声明 `class DeviceManager` 和 `class ComputeContext`，添加 `#include <vulkan/vulkan_raii.hpp>`
    2. 声明构造函数 `FluidSolvers(DeviceManager& dm, ComputeContext& cc);`
    3. 声明六个公有求解方法：`SolveAdvection(cb, ds)`、`SolveDiffusion(cb, ds, alpha, beta)`、`SolveDivergence(cb, ds)`、`SolvePoisson(cb, ds, alpha, beta)`、`SolveProjection(cb, ds)`、`SolveVorticity(cb, ds, epsilon)`
    4. 私有成员：`dm_`、`cc_`、六个 `std::unique_ptr<vk::raii::Pipeline>`、两个独立的 `std::unique_ptr<vk::raii::PipelineLayout>`（diffusion 和 poisson 各一个）、一个 vorticity 的独立 pipeline_layout

2. 创建 `src/fluid_solvers.cpp`，构造函数中依次初始化管线
    1. `CreateSolverPipeline(shader_path)` 私有辅助——用 `cc_->grid_params()` 的 nx/ny 构造 specialization map entry，调用 `dm_->CreateComputePipelineFromFile`
    2. advection、divergence、projection 通过 `CreateSolverPipeline` 创建，复用 `cc_->pipeline_layout()`
    3. `CreateJacobiPipelines()` 私有辅助——创建含 push constant range（2×float）的独立 pipeline layout，分别创建 diffusion 和 poisson 管线
    4. `CreateVorticitySolverPipeline()` 私有辅助——创建含 push constant range（1×float）的独立 pipeline layout，通过 specialization constants 传入 NX/NY 创建 vorticity 管线

3. 实现六个 `SolveXxx` 方法
    1. 各自绑定 pipeline：`cb.bindPipeline(eCompute, **pipeline_xxx_)`
    2. 绑定描述符集：`cb.bindDescriptorSets(eCompute, *layout, 0, *ds, nullptr)`
    3. diffusion/poisson/vorticity 通过 `cb.pushConstants<float>` 传入参数
    4. 统一计算 workgroup 数量 `(cell_count + 127) / 128` 后 dispatch

4. 在 `src/CMakeLists.txt` 中追加 `fluid_solvers.h` 和 `fluid_solvers.cpp`
