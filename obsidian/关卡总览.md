## 关卡总览

项目采用谜题学习法：把整个工程拆为若干章节，每章包含一系列谜题。每个谜题聚焦于掌握单个规则，格式统一为 **初始状态 → 目标状态 → 规则**。

---

## 项目目标

在二维矩形域上实现一个 GPU 加速的不可压缩 Navier-Stokes 流体求解器。求解器采用 Stam 稳定流体算法——半拉格朗日平流、雅可比迭代扩散、压力泊松投影的标准三步框架——全部在 Vulkan Compute Shader 中执行。支持 **无滑移壁面、滑移壁面、速度入口/出口、压力入口/出口** 四种边界条件，由 JSON 案例文件驱动，每边可设多段独立边界段。障碍物通过 **浸入边界法（Immersed Boundary Method）** 实现流固耦合：用户以物理坐标定义闭合多边形，自动生成拉格朗日标记点，逐帧插值速度场、计算反馈力并散布回网格。

可视化方面，投影步后通过后处理着色器将速度矢量合成为幅值标量场，支持 **速度幅值、压力、涡量强度** 三种物理量切换，片段着色器中提供 **灰度、Jet 彩虹、CoolWarm 冷暖** 三套渐变色映射，运行时实时切换。引入 **被动染料标量场**：染料跟随速度场半拉格朗日平流，按住鼠标左键在指针位置注入径向渐变墨迹，松开即停。障碍物区域内染料浓度强制清零，保证视觉上染料不穿透固体。

所有流场参数、边界条件、障碍几何均从 JSON 案例文件加载，支持物理网格尺寸（`mesh_density` 决定 `dx = dy`）和网格分辨率（`mesh_resolution` 决定 `nx x ny`），着色器通过 specialization constant 传入 `INV_DX/INV_DY` 适配任意物理域。管线创建使用 `ComputeShaderTask` 链式接口（`Begin → PushConstant → End`），描述符集通过注册表式 `DescriptorSets` 统一管理，计算和图形录制合并到同一 CommandBuffer 每帧单次提交。

最终通过 ImGui 控制面板实现运行时交互：Pause/Resume 暂停/继续模拟、Reset 恢复默认参数、Init Field 重新初始化流场；Field 模式下可切换物理量和渐变色并调节系数滑条；Dye 模式下可调节墨迹半径和三个 0xRRGGBB 颜色；两种模式共享时间步长滑条。程序通过 `rtfs2d case.json [--Debug]` 命令行启动，`--Debug` 启用 Vulkan 验证层。
