# 4.7 ComputeContext 结构体

#### 目标
在[[4.6 计算管线工厂]]的基础上，新建 `ComputeContext` 结构体，将 Window 中所有计算相关的缓冲、管线、描述符集和调度逻辑移入，实现：
1. `ComputeContext` 持有标量场缓冲、描述符集（layout/pool/set）、计算管线、command buffer 和网格参数，构造函数内完成全部初始化
2. Window 通过 `ComputeContext` 的公有接口调度 compute shader 和验证场数据
3. 编译通过，验证层无报错，正弦波纹验证通过

#### 规则
1. 创建 `src/vk_compute.h`，声明 `ComputeContext` 结构体
    1. 添加 `#ifndef RTFS2D_VK_COMPUTE_H` / `#define` 守卫，包含 `<vulkan/vulkan_raii.hpp>` 和 `"grid.h"`，前置声明 `class DeviceManager`
    2. 声明构造函数 `ComputeContext(DeviceManager& dm);`，参数为 `DeviceManager` 引用
    3. 声明公有 getter：`scalar_field_buffer()` 返回 `const vk::raii::Buffer&`、`descriptor_set_layout()` 返回 `const vk::raii::DescriptorSetLayout&`、`descriptor_set()` 返回 `const vk::raii::DescriptorSet&`
    4. 声明 `const GridParams& grid_params() const;` 和 `int cell_count() const;` 和 `vk::DeviceSize buf_size() const;`
    5. 声明公有方法 `void RecordAndSubmit(const vk::raii::Queue& queue);` 录制并提交一次 compute dispatch（内部调用 `RecordComputeCommands` 并 submit）
    6. 声明公有方法 `void Verify() const;` 回读标量场并验证正弦波纹数据（替代 `Window::VerifyFieldData`）
    7. 将 Window 中计算相关的全部成员变量移入私有区域：`scalar_field_buffer_`、`scalar_field_memory_`、`descriptor_set_layout_`、`pipeline_layout_`、`compute_pipeline_`、`descriptor_pool_`、`descriptor_set_`、`compute_command_buffer_`、`compute_verified_`、`grid_params_`、`compute_cell_count_`、`compute_buf_size_`，类型和默认值与原 `window.h` 完全一致
    8. 声明私有方法 `void CreateStorageBuffer()`、`void CreateComputePipeline()`、`void CreateDescriptorSets()`、`void RecordComputeCommands()`

2. 创建 `src/vk_compute.cpp`，将 `window.cpp` 中的计算相关函数移入并修改签名
    1. 实现构造函数：初始化列表赋值 `grid_params_`，函数体内依次调用 `CreateStorageBuffer()`、`CreateDescriptorSets()`、`CreateComputePipeline()`、`RecordComputeCommands()`
    2. 移动 `Window::CreateStorageBuffer` 的完整函数体，签名前加 `ComputeContext::`，函数内通过 `DeviceManager& dm_` 成员访问设备和上传函数
    3. 移动 `Window::CreateComputePipeline` 的完整函数体，签名前加 `ComputeContext::`，函数内创建 `pipeline_layout_` 后调用 `dm_.CreateComputePipelineFromFile`
    4. 移动 `Show()` 中创建描述符集的 `DescriptorSetBuilder` 代码段到 `CreateDescriptorSets`，签名前加 `ComputeContext::`
    5. 移动 `Window::RecordComputeCommands` 的完整函数体，签名前加 `ComputeContext::`
    6. 移动 `Window::VerifyFieldData` 的完整函数体，签名前加 `ComputeContext::`

3. 修改 `window.h`，删除移入 ComputeContext 的成员和函数
    1. 添加 `#include "vk_compute.h"`，新增加员 `std::unique_ptr<ComputeContext> compute_ctx_;`
    2. 删除 `scalar_field_buffer_`、`scalar_field_memory_`、`descriptor_set_layout_`、`pipeline_layout_`、`compute_pipeline_`、`descriptor_pool_`、`descriptor_set_`、`compute_command_buffer_`、`compute_verified_`、`grid_params_`、`compute_cell_count_`、`compute_buf_size_` 全部成员
    3. 删除 `CreateStorageBuffer`、`CreateComputePipeline`、`RecordComputeCommands`、`VerifyFieldData` 四个函数声明

4. 修改 `window.cpp`
    1. 删除所有移走的函数定义
    2. 在 `Show()` 中 `swapchain_ctx_` 构造之后插入 `compute_ctx_ = std::make_unique<ComputeContext>(*device_manager_);`
    3. 删除 `CreateStorageBuffer()` 到 `RecordComputeCommands()` 之间的全部调用
    4. 主循环中 compute 的 submit 和 verify 调用替换为 `compute_ctx_->RecordAndSubmit(device_manager_->graphics_queue());` 和 `compute_ctx_->Verify();`

5. 在 `src/CMakeLists.txt` 中追加 `vk_compute.h` 和 `vk_compute.cpp`
