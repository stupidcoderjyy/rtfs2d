# 4.2 缓冲上传辅助

#### 目标
在[[4.1 内存分配工具函数]]的基础上，在 `vk_memory.h` 中新增 `UploadBufferData` 函数并重构 `CreateStorageBuffer`，实现：
1. `UploadBufferData` 将 "创建 staging buffer → 映射并拷贝数据 → 录制 copyBuffer 命令 → 提交 → waitIdle" 五步合并为一次调用
2. `CreateStorageBuffer` 中的缓冲创建替换为对 `AllocateBuffer` 的调用、staging 上传替换为对 `UploadBufferData` 的调用
3. 编译通过，验证层无报错，正弦波纹显示正常

#### 规则
1. 在 `vk_memory.h` 中追加声明
    1. 在 `AllocateBuffer` 声明下方添加 `void UploadBufferData(const vk::raii::Device& device, vk::PhysicalDevice physical_device, const vk::raii::CommandPool& command_pool, const vk::raii::Queue& queue, const std::vector<float>& data, const vk::raii::Buffer& dst_buffer);`

2. 在 `vk_memory.cpp` 中实现 `UploadBufferData` —— 将 `CreateStagingBuffer` 和 `RecordStorageCommand` 的函数体合并为单个函数，执行以下替换：

    > 从 `CreateStagingBuffer` 复制代码段（`vk::BufferCreateInfo ci{};` 到 `staging_memory->unmapMemory();`）
    - `ci.setSize(compute_buf_size_)` → `ci.setSize(size)`，其中 `size = data.size() * sizeof(float)` 在函数开头声明
    - `ci.setUsage(vk::BufferUsageFlagBits::eTransferSrc)` 保持不变（staging 缓冲总是 `eTransferSrc`）
    - `device_->` → `device.`
    - `FindMemoryType(physical_device_, ...)` → `FindMemoryType(physical_device, ...)`
    - `compute_buf_size_`（在 `mapMemory` 和 `memcpy` 调用中）→ `size`
    - `staging_buffer` → 改为通过 `AllocateBuffer` 一行创建，不再手动拼接：`auto [staging_buf, staging_mem] = AllocateBuffer(device, physical_device, size, vk::BufferUsageFlagBits::eTransferSrc, vk::MemoryPropertyFlagBits::eHostVisible | vk::MemoryPropertyFlagBits::eHostCoherent);`
    - 删除 `CreateStagingBuffer` 中原有的 `vk::BufferCreateInfo` + `createBuffer` + `DeviceBufferMemoryRequirements` + `FindMemoryType` + `allocateMemory` + `bindMemory` 这六步（由 `AllocateBuffer` 替代）

    > 从 `RecordStorageCommand` 复制代码段（`vk::CommandBufferAllocateInfo ai{};` 到 `graphics_queue_->waitIdle();`）
    - `**command_pool_` → `*command_pool`
    - `device_->` → `device.`
    - `compute_buf_size_`（在 `copy_region.setSize` 中）→ `size`
    - `**staging_buffer` → `**staging_buf`
    - `**scalar_field_buffer_`（`copyBuffer` 的目标）→ `*dst_buffer`
    - `graphics_queue_->` → `queue.`
    - `vk::SubmitInfo si;` → `vk::SubmitInfo si{};`（统一初始化风格）

3. 删除 `Window` 中的冗余函数
    1. 在 `window.h` 中删除 `void CreateStagingBuffer(...)` 和 `void RecordStorageCommand(std::unique_ptr<vk::raii::Buffer>& staging_buffer) const;` 两个声明
    2. 在 `window.cpp` 中删除这两个函数的完整定义

4. 改写 `CreateStorageBuffer()` —— 复制现有函数体，执行以下替换：
    - `vk::BufferCreateInfo ci{};` 到 `scalar_field_buffer_->bindMemory(**scalar_field_memory_, 0);` → 替换为 `auto [buf, mem] = AllocateBuffer(*device_, physical_device_, compute_buf_size_, vk::BufferUsageFlagBits::eStorageBuffer | vk::BufferUsageFlagBits::eTransferSrc | vk::BufferUsageFlagBits::eTransferDst, vk::MemoryPropertyFlagBits::eDeviceLocal);` 然后 `scalar_field_buffer_ = std::move(buf); scalar_field_memory_ = std::move(mem);`
    - `std::unique_ptr<vk::raii::Buffer> staging_buffer;` 到 `RecordStorageCommand(staging_buffer);` → 替换为 `std::vector<float> host_data(compute_cell_count_, 0.0f);` 然后 `UploadBufferData(*device_, physical_device_, *command_pool_, *graphics_queue_, host_data, *scalar_field_buffer_);`
