# 4.5 描述符集构建器

#### 目标
在[[4.4 SwapchainContext 类]]的基础上，新增 `DescriptorSetBuilder` 类，将描述符集布局声明、池创建、集分配和缓冲写入合并为链式调用，实现：
1. `DescriptorSetBuilder` 一次性创建 layout + pool + set 三元组，并逐 binding 写入缓冲信息
2. Window 中的 `CreateDescriptorSetLayout`、`CreateDescriptorPool`、`CreateDescriptorSet` 三个函数被替换为对 Builder 的一次调用
3. 编译通过，正弦波纹显示正常

#### 规则
1. 创建 `src/vk_descriptor.h`，声明 `DescriptorSetBuilder` 类及其公有接口
    1. 添加 `#ifndef RTFS2D_VK_DESCRIPTOR_H` / `#define` 守卫，包含 `<vulkan/vulkan_raii.hpp>`，末尾 `#endif //RTFS2D_VK_DESCRIPTOR_H`
    2. 声明构造函数，参数为 `const vk::raii::Device&`，保存 `&device` 到私有成员指针 `device_`
    3. 声明类型别名 `BuildResult`，定义为包含 `unique_ptr<DescriptorSetLayout>`、`unique_ptr<DescriptorPool>`、`unique_ptr<DescriptorSet>` 三个元素的 `std::tuple`，避免后续重复书写冗长类型
    4. 声明 `AddStorageBufferBinding(uint32_t binding, vk::ShaderStageFlags stages)` 方法，返回 `DescriptorSetBuilder&` 以支持链式调用，内部向私有 `std::vector<vk::DescriptorSetLayoutBinding> bindings_` 追加一个 storage buffer 类型的 binding 描述
    5. 声明 `build() const` 方法，返回 `BuildResult`，用累积的全部 binding 一次性创建 DescriptorSetLayout、DescriptorPool 并从中分配一个 DescriptorSet
    6. 声明 `WriteBuffer` 方法，参数为已有的 `DescriptorSet`、目标 binding 编号和要绑定的 `Buffer`，向该 binding 写入 storage buffer 描述符信息

2. 创建 `src/vk_descriptor.cpp`，实现四个方法——复制 `window.cpp` 中现有三个对应函数的代码段，逐段做替换
    1. 文件顶部用 `using namespace rtfs2d;` 声明命名空间（与项目其他新建 .cpp 文件风格一致）
    2. 实现 `AddStorageBufferBinding`：复制 `Window::CreateDescriptorSetLayout` 中构造 `vk::DescriptorSetLayoutBinding lb{};` 到 `.setStageFlags(...)` 的代码段，将 `lb.setBinding(0)` 替换为 `lb.setBinding(binding)`、硬编码的 `eCompute | eFragment` 替换为参数 `stages`，末尾追加 `bindings_.push_back(lb);` 和 `return *this;`
    3. 实现 `build`：依次复制 `CreateDescriptorSetLayout` 的 `vk::DescriptorSetLayoutCreateInfo` 构造段及 `createDescriptorSetLayout` 调用、`CreateDescriptorPool` 的 pool 构造段及 `createDescriptorPool` 调用、`CreateDescriptorSet` 前半部分（set 分配段），将 `ci.setBindingCount(1)` 替换为 `ci.setBindingCount(bindings_.size())`、`.setPBindings(&lb)` 替换为 `.setPBindings(bindings_.data())`、`ps.setDescriptorCount(1)` 替换为 `ps.setDescriptorCount(bindings_.size())`、`ai.setDescriptorPool(**descriptor_pool_)` 替换为 `ai.setDescriptorPool(**pool)`、`.setPSetLayouts(&**descriptor_set_layout_)` 替换为 `.setPSetLayouts(&**layout)`，末尾以 `std::tuple` 返回三个 `std::move` 后的 unique_ptr
    4. 实现 `WriteBuffer`：复制 `CreateDescriptorSet` 后半部分（`vk::DescriptorBufferInfo` 构造到 `updateDescriptorSets` 调用），将 `bi.setBuffer(**scalar_field_buffer_)` 替换为 `bi.setBuffer(*buffer)`、`wds.setDstSet(**descriptor_set_)` 替换为 `wds.setDstSet(*set)`、`wds.setDstBinding(0)` 替换为 `wds.setDstBinding(binding)`

3. 修改 `window.cpp`，用 `DescriptorSetBuilder` 替代三个旧函数
    1. 在 `#include` 区域添加 `#include "vk_descriptor.h"`
    2. 删除 `Window::CreateDescriptorSetLayout`、`Window::CreateDescriptorPool`、`Window::CreateDescriptorSet` 三个函数的完整定义
    3. 在 `Show()` 中 `CreateStorageBuffer()` 之后，将原来的三个函数调用替换为：构造 `DescriptorSetBuilder` 对象并传入 `device_manager_->device()`，调用 `AddStorageBufferBinding` 注册 binding 0 为 compute+fragment 可见的 storage buffer，调用 `build()` 获取 layout/pool/set 三元组并以 `std::move` 分别赋值给 Window 的三个对应成员，调用 `WriteBuffer` 将 `scalar_field_buffer_` 写入 binding 0

4. 修改 `window.h`
    1. 删除 `CreateDescriptorSetLayout`、`CreateDescriptorPool`、`CreateDescriptorSet` 三个函数声明
    2. 不在 `window.h` 中添加 `#include "vk_descriptor.h"`——`DescriptorSetBuilder` 仅在 `Show()` 函数体内使用，由 `window.cpp` 的 include 覆盖

5. 在 `src/CMakeLists.txt` 的 `add_library` 源文件列表中追加 `vk_descriptor.h` 和 `vk_descriptor.cpp`
