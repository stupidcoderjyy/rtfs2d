# 4.6 计算管线工厂

#### 目标
在[[4.5 描述符集构建器]]的基础上，将 `LoadShader` 移入 `DeviceManager` 并新增 `CreateComputePipelineFromFile` 方法，消除 Window 中的 `ShaderModule` 成员变量，实现：
1. `DeviceManager::LoadShader(path)` 从 .spv 文件创建 ShaderModule，`DeviceManager::CreateComputePipelineFromFile(layout, path)` 一行完成从 .spv 到 `vk::raii::Pipeline` 的全流程
2. Window 中不再持有 `compute_shader_module_`、`vert_shader_module_`、`frag_shader_module_` 成员——管线创建后 ShaderModule 即可销毁
3. 编译通过，正弦波纹显示正常

#### 规则
1. 在 `vk_device.h` 中声明两个公有方法
    1. 声明 `std::unique_ptr<vk::raii::ShaderModule> LoadShader(const std::string& path) const;`——将 `Window::LoadShader` 的签名原样移入，访问修饰符改为 `public`
    2. 声明 `std::unique_ptr<vk::raii::Pipeline> CreateComputePipelineFromFile(const vk::raii::PipelineLayout& layout, const std::string& spv_path) const;`——作为 `DeviceManager` 的 const 成员函数，不再需要传入 `device` 参数

2. 在 `vk_device.cpp` 中实现两个方法——复制 `window.cpp` 中对应函数体并做替换
    1. 移动 `Window::LoadShader` 的完整函数体，签名前加 `DeviceManager::`，函数内 `device_manager_->device()` 替换为 `device_`（`DeviceManager` 直接持有 `device_` 成员）
    2. 实现 `CreateComputePipelineFromFile`：删除原有的内联 SPIR-V 加载代码（`std::ifstream` 到 `createShaderModule` 的整段），改为调用 `auto shader = LoadShader(spv_path);` 获取 ShaderModule，后续管线创建保持 `setModule(**shader)` 的原有写法

3. 修改 `window.h`
    1. 删除 `std::unique_ptr<vk::raii::ShaderModule> compute_shader_module_;`、`vert_shader_module_`、`frag_shader_module_` 三个成员
    2. 删除 `std::unique_ptr<vk::raii::ShaderModule> LoadShader(const std::string& path) const;` 声明
    3. 将 `void CreateComputePipeline();` 的函数体内联创建 `pipeline_layout_` 的逻辑与管线创建合并（`CreateComputePipeline` 改为同时创建 `pipeline_layout_` 和 `compute_pipeline_`）

4. 修改 `window.cpp`
    1. 删除 `Window::LoadShader` 的函数定义
    2. 在 `CreateComputePipeline` 中：创建 `pipeline_layout_` 后，调用 `device_manager_->CreateComputePipelineFromFile(*pipeline_layout_, "shaders/compute.comp.spv")` 替代原有的内联管线创建代码
    3. 在 `Show()` 中删除 `compute_shader_module_ = LoadShader(...)` 调用
    4. 在 `CreateGraphicsPipeline()` 中，将 `LoadShader(...)` 调用改为 `device_manager_->LoadShader(...)`
