# 4.6 计算管线工厂

#### 目标
在[[4.5 描述符集构建器]]的基础上，将 `LoadShader` + `CreateComputePipeline` 合并为一个自由函数 `CreateComputePipelineFromFile`，消除 Window 中的 `ShaderModule` 成员变量，实现：
1. `CreateComputePipelineFromFile(device, layout, "shaders/xxx.comp.spv")` 一行完成从 .spv 文件到 `vk::raii::Pipeline` 的全流程
2. Window 中不再持有 `compute_shader_module_`、`vert_shader_module_`、`frag_shader_module_` 成员——管线创建后 ShaderModule 即可销毁
3. 编译通过，正弦波纹显示正常

#### 规则
1. 在 `vk_device.h` 中声明自由函数
    1. `std::unique_ptr<vk::raii::Pipeline> CreateComputePipelineFromFile(const vk::raii::Device& device, const vk::raii::PipelineLayout& layout, const std::string& spv_path);`
    2. 需要 `#include <string>`（`vk_device.h` 中已有）

2. 在 `vk_device.cpp` 中实现
    1. 从 `spv_path` 以 `std::ios::binary` 打开 `std::ifstream`（与 `Window::LoadShader` 中的读取逻辑完全一致：seekg 到末尾获取大小、检查 4 字节对齐、读取到 `std::vector<uint32_t>`）
    2. 构造 `vk::ShaderModuleCreateInfo sm_ci{};`，设置 `setCodeSize` 和 `setPCode`，调用 `device.createShaderModule(sm_ci)` 获得局部 `vk::raii::ShaderModule sm`（函数返回时自动析构）
    3. 构造 `vk::PipelineShaderStageCreateInfo pss_ci{};`，设置 `setStage(vk::ShaderStageFlagBits::eCompute)`、`setModule(*sm)`、`setPName("main")`
    4. 构造 `vk::ComputePipelineCreateInfo cp_ci{};`，设置 `setStage(pss_ci)`、`setLayout(*layout)`
    5. 调用 `device.createComputePipeline(nullptr, cp_ci)` 并用 `std::make_unique<vk::raii::Pipeline>` 包装返回

3. 修改 `window.h`
    1. 删除 `std::unique_ptr<vk::raii::ShaderModule> compute_shader_module_;`、`vert_shader_module_`、`frag_shader_module_` 三个成员
    2. 删除 `std::unique_ptr<vk::raii::ShaderModule> LoadShader(const std::string& path) const;` 声明
    3. 删除 `void CreateComputePipeline();` 声明

4. 修改 `window.cpp`
    1. 删除 `Window::LoadShader` 和 `Window::CreateComputePipeline` 的定义
    2. 在 `Show()` 中将 `compute_shader_module_ = LoadShader(...); CreateComputePipeline();` 替换为 `compute_pipeline_ = CreateComputePipelineFromFile(device_manager_->device(), *pipeline_layout_, "shaders/compute.comp.spv");`
    3. 在 `CreateGraphicsPipeline()` 中，将 `vert_shader_module_ = LoadShader(...)` 和 `frag_shader_module_ = LoadShader(...)` 改为在函数内部创建局部的 `vk::raii::ShaderModule` 变量（用和 `LoadShader` 相同的读取逻辑内联实现，不保存为成员）
