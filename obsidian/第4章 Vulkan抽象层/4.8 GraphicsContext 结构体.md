# 4.8 GraphicsContext 结构体

#### 目标
在[[4.7 ComputeContext 结构体]]的基础上，新建 `GraphicsContext` 结构体，将 Window 中的图形管线和渲染命令录制逻辑移入，实现：
1. `GraphicsContext` 持有图形管线和管线布局，构造函数内通过 `DeviceManager::LoadShader` 加载着色器并创建管线
2. `RecordCommands` 移入 GraphicsContext，通过 SwapchainContext 和 ComputeContext 引用访问所需资源
3. 编译通过，窗口正常显示正弦波纹

#### 规则
1. 创建 `src/vk_graphics.h`，声明 `GraphicsContext` 结构体
    1. 添加 `#ifndef RTFS2D_VK_GRAPHICS_H` / `#define` 守卫，包含 `<vulkan/vulkan_raii.hpp>`，前置声明 `class DeviceManager`、`class SwapchainContext`、`class ComputeContext`
    2. 声明构造函数 `GraphicsContext(DeviceManager& dm, SwapchainContext& sc, ComputeContext& cc);`
    3. 声明公有方法 `void RecordCommands(const vk::raii::CommandBuffer& cb, uint32_t img_idx) const;`（替代 `Window::RecordCommands`）
    4. 私有成员：`DeviceManager* dm_`、`SwapchainContext* sc_`、`ComputeContext* cc_`、`graphics_pipeline_layout_`、`graphics_pipeline_`
    5. 声明私有方法 `void CreateGraphicsPipeline();`——不再需要 `LoadShader` 方法，因为 `DeviceManager` 已在[[4.6 计算管线工厂]]中提供了公有的 `LoadShader`

2. 创建 `src/vk_graphics.cpp`，将 `window.cpp` 中的图形函数移入并修改签名
    1. 实现构造函数：初始化列表赋值三个指针，函数体内调用 `CreateGraphicsPipeline()`
    2. 移动 `Window::CreateGraphicsPipeline` 的完整函数体，签名前加 `GraphicsContext::`——执行以下替换：`device_manager_->device()` → `dm_->device()`，`swapchain_ctx_->` → `sc_->`，`compute_ctx_->descriptor_set_layout()` → `cc_->descriptor_set_layout()`，`LoadShader("shaders/fullscreen.vert.spv")` → `dm_->LoadShader("shaders/fullscreen.vert.spv")`（着色器加载改由 `DeviceManager` 的公有方法完成）
    3. 移动 `Window::RecordCommands` 的完整函数体，签名前加 `GraphicsContext::`——执行以下替换：`swapchain_ctx_->` → `sc_->`，`compute_ctx_->descriptor_set()` → `cc_->descriptor_set()`
    4. 删除 `Window::LoadShader` 函数定义——已在 DeviceManager 中

3. 修改 `window.h`，删除移入 GraphicsContext 的成员和函数
    1. 添加 `#include "vk_graphics.h"`，新增加员 `std::unique_ptr<GraphicsContext> graphics_ctx_;`
    2. 删除 `graphics_pipeline_layout_`、`graphics_pipeline_` 两个成员
    3. 删除 `CreateGraphicsPipeline`、`RecordCommands` 两个函数声明——`LoadShader` 声明已在 4.6 中删除

4. 修改 `window.cpp`
    1. 删除 `Window::CreateGraphicsPipeline` 和 `Window::RecordCommands` 的函数定义
    2. 在 `Show()` 中 `compute_ctx_` 构造之后插入 `graphics_ctx_ = std::make_unique<GraphicsContext>(*device_manager_, *swapchain_ctx_, *compute_ctx_);`
    3. 删除 `CreateGraphicsPipeline()` 调用
    4. 主循环中 `RecordCommands(cb, img_idx)` 替换为 `graphics_ctx_->RecordCommands(cb, img_idx);`

5. 在 `src/CMakeLists.txt` 中追加 `vk_graphics.h` 和 `vk_graphics.cpp`
