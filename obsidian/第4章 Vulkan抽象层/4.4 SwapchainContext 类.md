# 4.4 SwapchainContext 类

#### 目标
在[[4.3 DeviceManager 类]]的基础上，新建 `SwapchainContext` 类，将交换链、图像视图、帧缓冲、渲染通道、同步对象和图形命令缓冲从 Window 中移出，实现：
1. `SwapchainContext` 绑定 `DeviceManager`，内部依次创建交换链、图像视图、渲染通道、帧缓冲、命令缓冲和同步对象
2. 窗口缩放时通过 `Recreate` 方法重建交换链
3. 编译通过，窗口正常显示、缩放重建正常

#### 规则
1. 创建 `src/vk_swapchain.h`，声明 `SwapchainContext` 的公有 getter 和私有成员
    1. 添加 `#ifndef RTFS2D_VK_SWAPCHAIN_H` / `#define` 守卫，仅包含 `<vulkan/vulkan_raii.hpp>`，前置声明 `class DeviceManager`
    2. 声明私有成员 `DeviceManager* device_manager_`，以及从 `window.h` 原样复制全部交换链成员变量：`swapchain_`、`swapchain_image_format_`、`swapchain_color_space_`、`swapchain_extent_`、`swapchain_images_`、`swapchain_image_views_`、`render_pass_`、`framebuffers_`、`command_buffers_`、`kMaxFramesInFlight`（值保持 2）、`image_available_semaphores_`、`render_finished_semaphores_`、`in_flight_fences_`、`image_layouts_`、`needs_recreate_`（默认值 `false`），类型和初始化方式与 `window.h` 中完全一致
    3. 声明私有方法 `CreateSwapChain(int width, int height, bool replace = false)`、`CreateImageViews`、`CreateRenderPass`、`CreateFrameBuffers`、`CreateCommandBuffers`、`CreateFrameBasedSyncObjects`、`CreateImageBasedSyncObjects`，签名照搬 `window.h` 原声明后将 `CreateSwapChain` 增加宽高参数
    4. 声明公有 getter（全部内联实现，返回对应成员引用）：`extent()`、`image_format()`、`swapchain_images()`、`render_pass()`、`framebuffers()`、`command_buffers()`、`in_flight_fence()`、`image_available_semaphore()`、`render_finished_semaphore()`、`image_layouts()`、`needs_recreate()`、`set_needs_recreate(bool)`
    5. 声明 `AcquireImage(const vk::raii::Semaphore& sem) const` 返回 `std::pair<vk::Result, uint32_t>`，内部调用 `swapchain_->acquireNextImage(UINT64_MAX, *sem)`
    6. 声明 `Present(const vk::raii::Queue& queue, uint32_t img_idx, const vk::raii::Semaphore& wait_sem)` 返回 `vk::Result`，内部构造 `vk::PresentInfoKHR`、调用 `queue.presentKHR`、检测到 `eErrorOutOfDateKHR` 或 `eSuboptimalKHR` 时设置 `needs_recreate_ = true`
    7. 声明 `Recreate(int width, int height)`，内部依次调用 `device_manager_->device().waitIdle()`、清空 `framebuffers_` / `swapchain_image_views_` / `render_finished_semaphores_`、`CreateSwapChain(true, width, height)`、`CreateImageViews`、`CreateFrameBuffers`、`CreateImageBasedSyncObjects`、`needs_recreate_ = false`

2. 创建 `src/vk_swapchain.cpp`，将构造函数的 7 步初始化链写入，并复制 `window.cpp` 中 7 个函数体
    1. 实现构造函数：初始化列表 `device_manager_(&dm)`，函数体内依次调用 `CreateSwapChain(width, height, false)`、`CreateImageViews()`、`CreateRenderPass()`、`CreateFrameBuffers()`、`CreateCommandBuffers()`、`CreateFrameBasedSyncObjects()`、`CreateImageBasedSyncObjects()`
    2. 复制 `Window::CreateSwapChain(bool replace)` 的完整函数体，签名改为 `SwapchainContext::CreateSwapChain(int width, int height, bool replace)`，函数体内 `width_` / `height_` 替换为参数 `width` / `height`
    3. 复制 `Window::CreateImageViews` 的完整函数体，签名前加 `SwapchainContext::`
    4. 复制 `Window::CreateRenderPass` 的完整函数体，签名前加 `SwapchainContext::`
    5. 复制 `Window::CreateFrameBuffers` 的完整函数体，签名前加 `SwapchainContext::`
    6. 复制 `Window::CreateCommandBuffers` 的完整函数体，签名前加 `SwapchainContext::`
    7. 复制 `Window::CreateFrameBasedSyncObjects` 和 `Window::CreateImageBasedSyncObjects` 的完整函数体，签名前加 `SwapchainContext::`

3. 修改 `window.h`
    1. 添加 `#include "vk_swapchain.h"`（放在 `"vk_device.h"` 之后），新增成员 `std::unique_ptr<SwapchainContext> swapchain_ctx_`
    2. 删除全部已移入 `SwapchainContext` 的成员变量（从 `swapchain_` 到 `frame_buffer_resized_`，以及 `kMaxFramesInFlight`）
    3. 删除全部已移走的函数声明（`CreateSwapChain` 到 `CreateImageBasedSyncObjects`，以及 `RecreateSwapChain`）
    4. 删除 `#include <functional>`（不再需要，`std::function` 未在头文件中使用）
    5. `RecordCommands` 声明后追加 `const`

4. 修改 `window.cpp`
    1. 删除全部已移走的函数定义（7 个 swapchain 方法 + `RecreateSwapChain`）
    2. 删除 `#include <set>`（不再需要，`std::set` 仅用于原 `CreateLogicalDevice`，已移入 DeviceManager）
    3. 在 `Show()` 中 `device_manager_` 构造之后、`glfwSetWindowUserPointer` 之前插入 `swapchain_ctx_ = std::make_unique<SwapchainContext>(*device_manager_, width_, height_);`
    4. 删除 `CreateSwapChain()` 到 `CreateImageBasedSyncObjects()` 的全部调用（SwapchainContext 构造已内部执行）
    5. `RecordCommands` 函数签名后追加 `const`

5. 修改 `RecordCommands()`，将直接成员访问替换为 `swapchain_ctx_->` getter
    1. `barrier.setImage(swapchain_images_[img_idx])` 替换为 `barrier.setImage(swapchain_ctx_->swapchain_images()[img_idx])`
    2. `.setOldLayout(image_layouts_[img_idx])` 替换为 `.setOldLayout(swapchain_ctx_->image_layouts()[img_idx])`
    3. `bi.setRenderPass(*render_pass_)` 替换为 `bi.setRenderPass(swapchain_ctx_->render_pass())`（返回引用，不加 `*`）
    4. `.setFramebuffer(*framebuffers_[img_idx])` 替换为 `.setFramebuffer(*swapchain_ctx_->framebuffers()[img_idx])`
    5. `swapchain_extent_.width` / `.height` 替换为 `swapchain_ctx_->extent().width` / `.height`
    6. `{0, 0}, swapchain_extent_` 替换为 `{0, 0}, swapchain_ctx_->extent()`
    7. `image_layouts_[img_idx] = ...` 替换为 `swapchain_ctx_->image_layouts()[img_idx] = ...`

6. 修改 `Show()` 主循环
    1. `frame_buffer_resized_` 全部替换为 `swapchain_ctx_->needs_recreate()` 或 `swapchain_ctx_->set_needs_recreate(true)`
    2. `RecreateSwapChain()` 替换为 `swapchain_ctx_->Recreate(width_, height_);`
    3. `command_buffers_[current_frame_]` 替换为 `swapchain_ctx_->command_buffers()[current_frame_]`
    4. `in_flight_fences_[current_frame_]` 替换为 `swapchain_ctx_->in_flight_fence(current_frame_)`
    5. `image_available_semaphores_[current_frame_]` 替换为 `swapchain_ctx_->image_available_semaphore(current_frame_)`
    6. `render_finished_semaphores_[img_idx]` 替换为 `swapchain_ctx_->render_finished_semaphore(img_idx)`
    7. 注意：getter 返回 `vk::raii::Fence&` / `vk::raii::Semaphore&` 引用，`**` 双重解引用全部改为 `*` 单层解引用
    8. `swapchain_->acquireNextImage(...)` 替换为 `swapchain_ctx_->AcquireImage(acquire_sem)`
    9. `present_queue_->presentKHR(pi)` 及外围的 `vk::PresentInfoKHR`、错误检测替换为 `swapchain_ctx_->Present(device_manager_->present_queue(), img_idx, render_sem)`
    10. `kMaxFramesInFlight` 替换为字面量 `2`

7. 修改 GLFW framebuffer size callback 和 `CreateGraphicsPipeline`
    1. `rtfs_win->frame_buffer_resized_ = true;` 替换为 `rtfs_win->swapchain_ctx_->set_needs_recreate(true);`
    2. `.setRenderPass(**render_pass_)` 替换为 `.setRenderPass(swapchain_ctx_->render_pass())`

8. 在 `src/CMakeLists.txt` 中追加 `vk_swapchain.h` 和 `vk_swapchain.cpp`
