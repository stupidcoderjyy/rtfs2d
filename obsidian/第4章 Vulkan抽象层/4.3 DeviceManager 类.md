# 4.3 DeviceManager 类

#### 目标
在[[4.2 缓冲上传辅助]]的基础上，新建 `DeviceManager` 类，将 Vulkan 实例、物理设备、逻辑设备、队列族索引、队列句柄、命令池和计算命令池从 Window 中移出，实现：
1. `DeviceManager` 构造函数接受 `GLFWwindow*` 和 `bool debug_enabled`，内部依次执行实例创建、窗口表面创建、物理设备选取、逻辑设备创建、命令池创建、计算命令池创建
2. Window 通过 `DeviceManager` 的公有 getter 访问这些资源
3. 编译通过，验证层无报错，正弦波纹显示正常

#### 规则
1. 创建 `src/vk_device.h`
    1. `#ifndef RTFS2D_VK_DEVICE_H` / `#define RTFS2D_VK_DEVICE_H`
    2. 包含 `#include <vulkan/vulkan_raii.hpp>`、`#include <memory>`、`#include <vector>`、`#include <string>`
    3. 前置声明 `struct GLFWwindow;`
    4. 声明 `namespace rtfs2d { class DeviceManager { ... }; }`，末尾 `#endif //RTFS2D_VK_DEVICE_H`
    5. 公有接口：
        - `DeviceManager(GLFWwindow* window, bool debug_enabled);`
        - `vk::raii::PhysicalDevice& physical_device();` 返回 `physical_device_`
        - `const vk::raii::Device& device() const;` 返回 `*device_`
        - `const vk::raii::Queue& graphics_queue() const;` 返回 `*graphics_queue_`
        - `const vk::raii::Queue& present_queue() const;` 返回 `*present_queue_`
        - `const vk::raii::CommandPool& command_pool() const;` 返回 `*command_pool_`
        - `const vk::raii::CommandPool& compute_command_pool() const;` 返回 `*compute_command_pool_`
        - `uint32_t graphics_queue_family_index() const;` 返回 `graphics_queue_family_index_`
        - `uint32_t present_queue_family_index() const;` 返回 `present_queue_family_index_`
    6. 私有成员：`std::unique_ptr<vk::raii::Instance> instance_`、`bool debug_enabled_`、`std::unique_ptr<vk::raii::DebugUtilsMessengerEXT> debug_messenger_`、`std::unique_ptr<vk::raii::SurfaceKHR> surface_`、`vk::raii::PhysicalDevice physical_device_ = VK_NULL_HANDLE`、`uint32_t graphics_queue_family_index_`、`uint32_t present_queue_family_index_`、`std::unique_ptr<vk::raii::Device> device_`、`std::unique_ptr<vk::raii::Queue> graphics_queue_`、`std::unique_ptr<vk::raii::Queue> present_queue_`、`std::unique_ptr<vk::raii::CommandPool> command_pool_`、`std::unique_ptr<vk::raii::CommandPool> compute_command_pool_`

2. 创建 `src/vk_device.cpp`
    1. 将 `DebugCallback` 自由函数移到本文件（保持与 `window.cpp` 中完全相同的实现）
    2. 将 `Window::GetEnabledExtensions`、`GetEnabledValidationLayers`、`GetApplicationInfo`、`GetDebugMessengerCreateInfo` 四个辅助函数移到本文件，改为 `DeviceManager` 的私有成员函数（保持实现不变，`GetApplicationInfo` 中 `title_.c_str()` 改为固定的 `"rtfs2d"`）
    3. 将 `Window::CreateVkInstance` 的代码移入 `DeviceManager` 构造函数——从 `auto enabled_extensions = GetEnabledExtensions()` 到 `debug_messenger_` 的创建
    4. 将 `Window::CreateWindowSurface` 的代码移入构造函数——`glfwCreateWindowSurface(**instance_, window, nullptr, &surface)` 后 `std::make_unique<vk::raii::SurfaceKHR>(*instance_, surface)`
    5. 将 `Window::CheckPhysicalDevice` 的代码移入构造函数——遍历物理设备，查找 graphics + present 队列族和支持 swapchain 扩展的设备，赋值 `physical_device_`、`graphics_queue_family_index_`、`present_queue_family_index_`
    6. 将 `Window::CreateLogicalDevice` 的代码移入构造函数——`std::set queue_families{...}`、`std::vector<vk::DeviceQueueCreateInfo>`、`vk::PhysicalDeviceFeatures df{}; df.setFragmentStoresAndAtomics(VK_TRUE);`、创建 device 和两个 queue
    7. 将 `Window::CreateCommandPoolAndBuffers` 中创建 `command_pool_` 的部分移入构造函数（只创建 command_pool，不分配 command_buffers——那属于 SwapchainContext）
    8. 将 `Window::CreateComputeCommandPool` 的代码移入构造函数——创建 `compute_command_pool_`

3. 在 `src/CMakeLists.txt` 中追加 `vk_device.h` 和 `vk_device.cpp`

4. 修改 `window.h`
    1. 添加 `#include "vk_device.h"`
    2. 新增成员 `std::unique_ptr<DeviceManager> device_manager_;`
    3. 删除所有移入 DeviceManager 的成员变量（从 `instance_` 到 `compute_command_pool_`，但不包括 `command_buffers_`）
    4. 删除所有移入 DeviceManager 的函数声明（`CreateVkInstance` 到 `CreateComputeCommandPool`，以及 `GetEnabledExtensions` 等辅助函数和 `DebugCallback`）

5. 修改 `window.cpp`
    1. 删除所有移走的函数定义
    2. 在 `Show()` 中 `window_ = glfwCreateWindow(...)` 之后插入 `device_manager_ = std::make_unique<DeviceManager>(window_, debug_enabled_);`
    3. 全局替换 `physical_device_` → `device_manager_->physical_device()`、`device_->` → `device_manager_->device().`、`graphics_queue_->` → `device_manager_->graphics_queue().`、`present_queue_->` → `device_manager_->present_queue().`
    4. `graphics_queue_family_index_` → `device_manager_->graphics_queue_family_index()`、`present_queue_family_index_` 同理
    5. `command_pool_` → `device_manager_->command_pool()`（注意 `**command_pool_` 需改为 `*device_manager_->command_pool()`）、`compute_command_pool_` → `device_manager_->compute_command_pool()`

6. 调整 `Show()` 初始化流程
    1. 删除 `CreateVkInstance()`、`CreateWindowSurface()`、`CheckPhysicalDevice()`、`CreateLogicalDevice()`、`CreateCommandPoolAndBuffers()`、`CreateComputeCommandPool()` 的全部调用（`device_manager_` 构造已内部执行）
