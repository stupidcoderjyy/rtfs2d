# 4.1 内存分配工具函数

#### 目标
将 `Window::FindMemoryType` 从 Window 类中提取为自由函数，并在同一文件中新增 `AllocateBuffer` 一站式缓冲创建函数，实现：
1. `vk_memory.h` / `vk_memory.cpp` 新增两个命名空间级函数和一个 `BufferAndMemory` 类型别名
2. `Window` 类通过调用自由函数替代原有成员函数的 `FindMemoryType` 调用
3. 编译通过，验证层无报错，正弦波纹显示正常

#### 规则
1. 创建 `src/vk_memory.h`
    1. 添加 `#ifndef RTFS2D_VK_MEMORY_H` / `#define RTFS2D_VK_MEMORY_H` 守卫和末尾 `#endif //RTFS2D_VK_MEMORY_H`
    2. 仅包含 `#include <vulkan/vulkan_raii.hpp>`，声明 `namespace rtfs2d { ... }`
    3. 声明 `uint32_t FindMemoryType(vk::PhysicalDevice physical_device, uint32_t typeFilter, vk::MemoryPropertyFlags properties);`（第一个参数从 `Window` 的隐式 `physical_device_` 改为显式 `physical_device`）
    4. 声明类型别名 `using BufferAndMemory = std::pair<std::unique_ptr<vk::raii::Buffer>, std::unique_ptr<vk::raii::DeviceMemory>>;`（后续函数返回此类型，替代冗长的 pair 写两遍）
    5. 声明 `BufferAndMemory AllocateBuffer(const vk::raii::Device& device, vk::PhysicalDevice physical_device, vk::DeviceSize size, vk::BufferUsageFlags usage, vk::MemoryPropertyFlags memory_flags);`

2. 创建 `src/vk_memory.cpp`
    1. 仅 `#include "vk_memory.h"`
    2. 实现 `FindMemoryType`：复制 `Window::FindMemoryType` 的整个函数体到 `rtfs2d` 命名空间内，将函数体内对 `physical_device_` 的引用替换为参数 `physical_device`，函数签名前加 `rtfs2d::`
    3. 实现 `AllocateBuffer`：复制 `CreateStorageBuffer` 中从 `vk::BufferCreateInfo ci{};` 到 `scalar_field_buffer_->bindMemory(**scalar_field_memory_, 0);` 的代码段，执行以下替换：`ci.setSize(compute_buf_size_)` → `ci.setSize(size)`、`ci.setUsage(eStorageBuffer | eTransferSrc | eTransferDst)` → `ci.setUsage(usage)`、所有 `device_->` → `device.`、`FindMemoryType(mr.memoryTypeBits, eDeviceLocal)` → `FindMemoryType(physical_device, mr.memoryTypeBits, memory_flags)`、`std::make_unique<vk::raii::Buffer>(...)` 赋值目标从 `scalar_field_buffer_` 改为局部变量 `auto buffer`、`std::make_unique<vk::raii::DeviceMemory>(...)` 赋值目标从 `scalar_field_memory_` 改为局部变量 `auto memory`、`bindMemory(**scalar_field_memory_, 0)` → `bindMemory(**memory, 0)`
    4. 删除 staging 相关代码（`std::unique_ptr<vk::raii::Buffer> staging_buffer;` 到 `RecordStorageCommand(staging_buffer);`）
    5. 函数末尾 `return {std::move(buffer), std::move(memory)};`，返回类型写为 `rtfs2d::BufferAndMemory`

3. 在 `src/CMakeLists.txt` 中注册新文件
    1. 在 `add_library` 的源文件列表中追加 `vk_memory.cpp` 和 `vk_memory.h`

4. 修改 `window.h`
    1. 删除 `uint32_t FindMemoryType(uint32_t typeFilter, vk::MemoryPropertyFlags properties) const;` 声明

5. 修改 `window.cpp`
    1. 在现有 `#include` 区域末尾添加 `#include "vk_memory.h"`
    2. 删除 `Window::FindMemoryType` 的整个函数定义
    3. 全局搜索 `FindMemoryType(`，每次出现时在前面追加 `physical_device_, ` 作为第一实参
