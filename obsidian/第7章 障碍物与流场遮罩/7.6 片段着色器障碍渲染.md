# 7.6 片段着色器障碍渲染

#### 目标
在[[7.5 求解器障碍感知]]基础上，修改 `fullscreen.frag` 实现障碍内部填充、边缘线框和流场可视化，实现：
1. 从 binding 12 读掩码缓冲
2. 障碍内部输出深色填充，边缘阈值内输出蓝色线框，其余正常渲染速度幅值灰度

#### 规则
1. 修改 `shaders/fullscreen.frag`
    1. 追加 `layout(std430, binding=12) buffer MaskBuf { float data[]; } mask;`
    2. `main()` 中 `mi = uint(fragUV.x*NX), mj = uint(fragUV.y*NY)`，clamp 后 `midx = mi + mj*NX`
    3. `inside = mask.data[midx*2]`，`edge = mask.data[midx*2+1]`
    4. 若 `inside > 0.5` → `vec4(0.05,0.05,0.08,1.0)`（深灰蓝填充）
    5. 否则若 `edge < 0.003` → `vec4(0.3,0.6,1.0,1.0)`（蓝色线框）
    6. 否则继续原速度幅值灰度输出
