# 7.1 ObstacleGeometry 数据结构

#### 目标
在[[第6章 边界与涡量/章节总览|第6章]]基础上，创建 `ObstacleGeometry` 数据结构，支持导入归一化坐标点集并自动生成 IBM 标记点，实现：
1. 存储闭合多边形，自动 AABB 包围盒计算
2. 在多边形边上等距采样生成 IBM 拉格朗日标记点
3. 提供结构体级别的序列化方法

#### 规则
1. 创建 `src/obstacle_geometry.h`
    1. 声明常量：`kMaxObstacles = 16`、`kMaxPolyVerts = 64`、`kMaxMarkers = 256`
    2. 声明内部结构 `PolyVert { float x,y; }` 和 `Obstacle { uint32_t vert_count; std::array<float,4> aabb; std::array<PolyVert,64> poly_verts; void ComputeAABB(); }`
    3. 声明 `PolygonSSBO { uint32_t count; std::array<Obstacle,16> obstacles; }` 和 `MarkerSSBO { uint32_t count; std::array<Marker,256> markers; }`，其中 `Marker { float x,y; std::array<float,4> _padding; }`——`_padding` 对应 fx/fy/vx/vy，在着色器中赋值
    4. `kPolygonBufferSize = sizeof(PolygonSSBO)`，`kMarkBufferSize = sizeof(MarkerSSBO)`
    5. 声明方法：`AddObstacle(points)`、`GenerateIBMMarkers(h)`、`Clear()`、`SerializePolygonSSBO()`、`SerializeMarkerSSBO()`
    6. 私有成员：`PolygonSSBO polygon_ssbo_{}` 和 `MarkerSSBO marker_ssbo_{}`

2. 创建 `src/obstacle_geometry.cpp`
    1. `AddObstacle`——检查上限、复制顶点到 `poly_verts`、首尾欧氏距离检测自动闭合、调用 `ComputeAABB()`、`++polygon_ssbo_.count`
    2. `Obstacle::ComputeAABB()`——遍历顶点求 min/max 存入 `aabb[0..3]`
    3. `GenerateIBMMarkers(h)`——`max_spacing = 0.15h`，遍历边，`n = max(1, floor(L/max_spacing))`，首边插起点、后续边跳过 s=0。容量超限 `goto end_generation`
    4. `SerializePolygonSSBO`——`AppendDataToBytesVec(buffer, polygon_ssbo_)` 整体序列化
    5. `SerializeMarkerSSBO`——`AppendDataToBytesVec(buffer, marker_ssbo_)` 整体序列化

3. 在 `src/CMakeLists.txt` 中注册
