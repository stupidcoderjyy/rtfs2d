# 7.6 采样式障碍渲染

#### 目标
在[[7.5 障碍掩码预计算]]的基础上，修改 `fullscreen.frag` 将障碍渲染从 per-pixel 射线投射改为读预计算掩码缓冲，实现：
1. 从 binding 12 读取 `[inside, edge_dist]` 对当前像素做双线性采样或最近邻采样
2. 根据阈值判断输出填充色、线框色或流场灰度

#### 规则
1. 修改 `shaders/fullscreen.frag`
    1. 删除原有的 `PolySSBO` 声明和 `pointInPolygon`/`distToSegment`/`minEdgeDist` 函数体（整个射线投射逻辑）
    2. 声明 binding 12 的 SSBO：`layout(std430, binding=12) buffer MaskBuf { float data[]; } mask;`
    3. `main()` 中在速度采样之前增加分支：用 `fragUV` 反算最近网格单元索引 `mi = uint(fragUV.x*NX), mj = uint(fragUV.y*NY)`，clamp 保护后 `midx = mi + mj*NX`
    4. `float inside = mask.data[midx*2]`，`float dist = mask.data[midx*2+1]`
    5. 若 `inside > 0.5` → 输出 `vec4(0.05,0.05,0.08,1.0)`
    6. 否则若 `dist < 0.003` → 输出 `vec4(0.3,0.6,1.0,1.0)`
    7. 否则继续原速度幅值灰度输出
    8. 注意：掩码在网格分辨率下计算（`NX×NY`），屏幕分辨率可能更高——最近邻采样在障碍边缘处有锯齿。可在后续优化关卡中用 GPU 双线性过滤替代
