# 7.4 浸入边界力计算

#### 目标
在[[7.3 障碍掩码预计算]]基础上，编写三个浸入边界着色器完成标记力计算、散布与施加，实现：
1. `ibm_interpolate.comp`——网格速度插值到标记点，计算边界力
2. `ibm_spread_markers.comp`——标记中心化 CAS 原子力散布
3. `ibm_apply_force.comp`——力施加到速度场并清零，障碍格强制置零

#### 规则
1. 创建 `shaders/ibm_interpolate.comp`
    1. binding 0=u、1=v、10=标记缓冲（`{ uint marker_count; float data[]; }`，每标记 6 float：x/y/fx/fy/vx/vy）
    2. 实现 `delta1D(r)`（Peskin 4 点核）和 `gridVelocity(ci,cj,is_u)`
    3. 实现 `interpVelocity(mp, is_u)`——`gx=mp.x*NX, gy=mp.y*NY`，4×4 支撑域 `Σ wx*wy*v_grid`
    4. `main()` 中以 `midx < marker_count` 遍历标记，读位置，插值 vx/vy，计算 `fx=-vx/DT, fy=-vy/DT`，写回 off+2..5

2. 创建 `shaders/ibm_spread_markers.comp`
    1. binding 10=标记缓冲（读 fx/fy）、11=力累加缓冲（`{ uint data[]; }`，读写）
    2. 实现 `delta1D(r)` 和 `atomicAddFloat(idx, val)`——CAS 循环直接操作 `force.data[idx]`
    3. `main()` 中以 `midx < marker_count` 遍历标记，读位置和力，`i0=floor(gx)-1, j0=floor(gy)-1`，4×4 支撑域原子加 `atomicAddFloat(gidx*2, w*fx*DT)` 和 `atomicAddFloat(gidx*2+1, w*fy*DT)`

3. 创建 `shaders/ibm_apply_force.comp`
    1. binding 0=u、1=v、11=力累加缓冲、12=掩码缓冲
    2. 实现 `isObstacle(ci,cj)`——`mask.data[(ci+cj*NX)*2u] > 0.5`
    3. `main()` 中若 `isObstacle(i,j)` 则 `u=v=0` + 清零累加缓冲并 return
    4. 否则 `u += fu, v += fv` + 清零累加缓冲

4. 在 `FluidSolvers` 中添加 `pipeline_ibm_interpolate_`、`pipeline_ibm_spread_`、`pipeline_ibm_apply_force_` 和对应 `Solve*` 方法

5. 在 `shaders/CMakeLists.txt` 中注册三个着色器
