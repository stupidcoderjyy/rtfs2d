# 7.3 标记中心化力散布

#### 目标
在[[7.2 全局缓冲管理]]的基础上，建立力累加缓冲并实现标记中心化的力散布方案，用 CAS 浮点原子替代网格中心化遍历，实现：
1. `force_accum` 缓冲（binding 11，`uint` 类型，大小 `2*NX*NY`，存 fu/fv 的位模式）
2. `ibm_spread_markers.comp`——每标记向 4×4 支撑域做 CAS 原子累加
3. `ibm_apply_force.comp`——每网格读累加缓冲 → 加到速度 → 清零

#### 规则
1. 在 `ComputeContext` 构造函数初始化列表中追加 `force_accum_buf_size_(2 * compute_cell_count_ * sizeof(float))`，缓冲创建已在 [[7.2 全局缓冲管理|7.2]] 的 `CreateBuffers` 中完成

2. 创建 `shaders/ibm_spread_markers.comp`
    1. `local_size_x = 128`，`constant_id 0/1` 的 NX/NY，`DT = 0.016f`
    2. binding 10 为标记缓冲（`{ uint marker_count; float data[]; }`，只读 fx/fy），binding 11 为力累加缓冲（`{ uint data[]; }`，读写）
    3. 实现 `delta1D(r)` 和 `atomicAddFloat(idx, val)` 函数——后者对 `force.data[idx]` 直接做 CAS 循环：`expected = force.data[idx]`，`desired = floatBitsToUint(uintBitsToFloat(expected)+val)`，`old = atomicCompSwap(force.data[idx], expected, desired)`，重试直到 `old == expected`
    4. `main()` 中 `midx = gl_GlobalInvocationID.x`，读标记位置 `(mx,my)` 和力 `(fx,fy)`
    5. 计算支撑域 `i0=floor(mx*NX)-1, j0=floor(my*NY)-1`，`di,dj = 0..3`，边界检查后计算 `w = delta1D(gx-ci)*delta1D(gy-cj)`
    6. `force_idx = ci + cj*NX`，`atomicAddFloat(force_idx*2, w*fx*DT)`，`atomicAddFloat(force_idx*2+1, w*fy*DT)`

3. 创建 `shaders/ibm_apply_force.comp`
    1. `local_size_x = 128`，`constant_id 0/1` 的 NX/NY
    2. binding 0=u（读写）、1=v（读写），binding 11=力累加缓冲（读写）
    3. `main()` 中 `idx = gl_GlobalInvocationID.x`，`fu = uintBitsToFloat(force.data[idx*2])`，`fv = uintBitsToFloat(force.data[idx*2+1])`
    4. `u.data[idx] += fu`，`v.data[idx] += fv`，`force.data[idx*2] = 0u`，`force.data[idx*2+1] = 0u`

4. 在 `shaders/CMakeLists.txt` 中追加 `ibm_spread_markers.comp` 和 `ibm_apply_force.comp`
