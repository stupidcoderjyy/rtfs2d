# 7.2 缓冲与描述符集扩展

#### 目标
在[[7.1 ObstacleGeometry 数据结构]]基础上，引入 `buffers.h` 命名常量、将缓冲创建集中到 `DeviceManager`，并将 `kBindingsSize` 扩展至 13，实现：
1. 所有缓冲通过 `dm_->BufferAt(kBufXxx)` 统一访问
2. 描述符集通过 `field_reg` + 声明式绑定完成注册

#### 规则
1. 创建 `src/buffers.h`
    1. `kBufV0..kBufV4`（velocity）、`kBufBc0..kBufBc3`（边界条件）、`kBufIbmPolygon=9`、`kBufIbmMarker=10`、`kBufIbmForce=11`、`kBufIbmMask=12`

2. 扩展 `vk_device.h` 中 `DeviceManager`
    1. `BufferInfo { vk::DeviceSize size; }` + `buffers_`、`memories_`、`buffer_infos_` 三个 vector
    2. `CreateBuffer(idx, size, usage, flags)`——含重复创建保护
    3. `BufferAt(idx)`、`BufferSize(idx)` getter
    4. `InitBuffer<T>(idx, data)` 模板及单值重载

3. 修改 `vk_compute.h`
    1. `kBindingsSize = 13`，删除分散的缓冲成员，保留 `force_accum_buf_size_`、`ibm_marker_count_{}`
    2. `CreateBuffers()` 替代原有多个创建方法

4. 实现 `CreateBuffers()`
    1. `kBufV0..V4`：`storage|transfer_src|transfer_dst`，`InitBuffer` 全零
    2. `kBufIbmPolygon`：大小 `ObstacleGeometry::kPolygonBufferSize`
    3. `kBufIbmMarker`：大小 `ObstacleGeometry::kMarkBufferSize`
    4. `kBufIbmForce`：大小 `2*cell_count*sizeof(float)`
    5. `kBufIbmMask`：大小 `2*cell_count*sizeof(float)`

5. 修改 `CreateDescriptorSets`
    1. binding 0-4 含 `eFragment`，5-8 `eCompute`，9-12 `eCompute|eFragment`
    2. `field_reg` 定义 13 个描述符集（原 8 个 + `kSetIbmApplyForce`、`kSetIbmInterpolate`、`kSetIbmSpreadMarkers`、`kSetIbmMask`、`kSetVisualization`），每个用 `buffers::kBufXxx` 声明绑定
