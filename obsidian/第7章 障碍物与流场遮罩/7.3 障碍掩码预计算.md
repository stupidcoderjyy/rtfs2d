# 7.3 障碍掩码预计算

#### 目标
在[[7.2 缓冲与描述符集扩展]]基础上，编写 `ibm_mask.comp` 预计算每个网格单元的障碍内外标志与边缘距离场，实现：
1. 从 binding 9 读多边形 SSBO，向 binding 12 写掩码缓冲
2. 每个网格单元通过 AABB 剔除 + 射线投射判断内外，通过全边遍历求最小边缘距离

#### 规则
1. 创建 `shaders/ibm_mask.comp`
    1. `local_size_x = 128`，`constant_id 0/1` 的 NX/NY
    2. binding 9 为 `PolySSBO`：`{ uint obstacle_count; PolyObstacle obstacles[16]; }`，其中 `PolyObstacle { uint vert_count; uint _pad; vec2 aabb_min; vec2 aabb_max; vec2 verts[64]; }`
    3. binding 12 为 `MaskBuf { float data[]; }`——data[idx*2]=inside, data[idx*2+1]=edge
    4. 实现 `pointInPolygon(p, obs_idx)`——标准射线投射
    5. 实现 `distToSegment(p, a, b)` 和 `minEdgeDist(p, margin)`
    6. `main()` 中对每个障碍先用 AABB 剔除（内外判断严格盒内，边缘距离用 2 格 margin），再调用射线投射和距离函数
    7. 写入 `data[idx*2] = inside ? 1.0 : 0.0`，`data[idx*2+1] = minEdgeDist(pos, margin)`

2. 在 `FluidSolvers` 中添加 `PrecomputeIBMMask`
    1. `pipeline_ibm_mask_` 成员 + `PrecomputeIBMMask(cb, ds)` 方法，以 `cell_count` 计算 dispatch 组数

3. 在 `UploadObstacles` 末尾调用
    1. 分配一次性 command buffer → `PrecomputeIBMMask(cb, kSetIbmMask)` → submit + waitIdle

4. 在 `shaders/CMakeLists.txt` 中注册 `ibm_mask.comp`
