# 7.5 求解器障碍感知

#### 目标
在[[7.4 浸入边界力计算]]基础上，在所有六个求解器着色器中引入 `isObstacle` 检测，将障碍格视为 NoSlipWall 边界，实现：
1. 速度着色器遇到障碍格邻居时返回零速度
2. 压力着色器遇到障碍格邻居时使用自身压力（Neumann dp/dn=0）
3. 障碍格自身跳过全部计算

#### 规则
1. 六个求解器着色器各追加 binding 12 声明和 `isObstacle` 函数
    1. `layout(std430, binding=12) buffer MaskBuf { float data[]; } mask;`
    2. `bool isObstacle(int ci, int cj)`——越界返回 false，否则 `mask.data[(ci+cj*NX)*2u] > 0.5`

2. 四个速度着色器（`advection.comp`、`diffusion.comp`、`diverge.comp`、`vorticity.comp`）
    1. `getU/getV`（或 `getNeighborU/getNeighborV`）内部邻居分支插入障碍返回 0.0
    2. `main()` 首行插入 `if (isObstacle(int(i), int(j))) return;`
    3. `advection.comp` 额外修改 `sampleBilinear`——四角点取样后各做 `isObstacle` 检测，障碍角点置零

3. 两个压力着色器（`poisson.comp`、`project.comp`）
    1. `main()` 首行插入障碍 skip
    2. `main()` 计算四邻居后，对每个邻居做 `if (isObstacle(...)) neighbor = pSrc.data[idx]`——将障碍邻居替换为中心格自身压力
