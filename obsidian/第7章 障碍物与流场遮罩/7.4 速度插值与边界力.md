# 7.4 速度插值与边界力

#### 目标
在[[7.3 标记中心化力散布]]的基础上，编写 `ibm_interpolate.comp` 并在 `FluidSolvers` 中注册，实现：
1. 将网格速度通过 delta 核插值到每个拉格朗日标记点
2. 用直接力公式 `F = -v_interp / dt` 计算边界力
3. 写回标记缓冲供散布步骤使用

#### 规则
1. 创建 `shaders/ibm_interpolate.comp`
    1. `local_size_x = 128`，`constant_id 0/1` 的 NX/NY，`DT = 0.016f`
    2. binding 0=u（只读）、1=v（只读）、10=标记缓冲（`{ uint marker_count; float data[]; }`，读写 fx/fy/vx/vy）
    3. 实现 `delta1D(r)` 函数
    4. 实现 `gridVelocity(ci, cj, is_u)`——clamp 到 `[0,NX-1]×[0,NY-1]` 后取 u 或 v 分量
    5. 实现 `interpVelocity(mp, is_u)`——计算 `gx=mp.x*NX, gy=mp.y*NY`，`i0=floor(gx)-1, j0=floor(gy)-1`，4×4 支撑域内累加 `wx*wy*v_grid`
    6. `main()` 中 `midx = gl_GlobalInvocationID.x`（以 marker_count 为上限），读 `(mx,my)`，分别插值 vx/vy，计算 `fx=-vx/DT, fy=-vy/DT`，写回 `off+2..5` 偏移

2. 在 `FluidSolvers` 中添加
    1. `fluid_solvers.h` 中新增 `pipeline_ibm_interpolate_`、`pipeline_ibm_spread_` 成员，声明 `SolveIBMInterpolate(cb, ds)` 和 `SolveIBMSpread(cb, ds)`
    2. `fluid_solvers.cpp` 构造函数中通过 `CreateSolverPipeline` 创建两个管线（`ibm_interpolate.comp.spv`、`ibm_spread_markers.comp.spv`），复用 `cc_->pipeline_layout()`
    3. `SolveIBMInterpolate` 中以 `cc_->ibm_marker_count()` 计算 workgroup 数 dispatch
    4. `SolveIBMSpread` 中以 `cc_->cell_count()` 计算 workgroup 数 dispatch（注意：`ibm_apply_force.comp` 为独立的第三个着色器，dispatch 组数也是 `cell_count`，但当前未在 FluidSolvers 中注册——见 [[7.6 流体步进 IBM 集成|7.6]]）

3. 在 `shaders/CMakeLists.txt` 中追加 `ibm_interpolate.comp`
