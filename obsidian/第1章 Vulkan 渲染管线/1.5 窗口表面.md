# 1.5 窗口表面

#### 目标
在 [[1.4 调试回调]] 基础上，为 GLFW 窗口创建 Vulkan 表面，实现：
1. 在 `vk::raii::Instance` 创建后、主循环开始前，成功创建 `vk::raii::SurfaceKHR`
2. 程序退出前自动销毁表面（由 RAII 保证，无需手动调用销毁函数）

#### 规则
- `glfwCreateWindowSurface` — GLFW 提供的跨平台窗口表面创建函数。接收 Vulkan 实例、GLFW 窗口和分配器回调（传 `nullptr`），返回原生 `VkSurfaceKHR` 句柄。此处不直接调用此函数，而是将其作为回调传给 vulkan_hpp

- `vk::raii::Context::getDispatcher()->vkCreateWindowSurfaceKHR` — vulkan_hpp 的 Context 持有平台相关的函数指针表。创建表面时需要用到这个 dispatcher，但 vulkan_hpp 提供了更简洁的封装

- `instance_->createWindowSurfaceKHR(...)` — 不直接存在。vulkan_hpp 对 GLFW 表面的创建方式是将 `VkSurfaceKHR` 原始句柄包装为 `vk::raii::SurfaceKHR`。具体做法：

  ```cpp
  // 1. 用 GLFW 创建原生 VkSurfaceKHR
  VkSurfaceKHR raw_surface;
  if (glfwCreateWindowSurface(
          static_cast<VkInstance>(**instance_),
          window_, nullptr, &raw_surface) != VK_SUCCESS) {
      throw std::runtime_error("Failed to create window surface");
  }

  // 2. 用 RAII 包装，接管生命周期
  surface_ = std::make_unique<vk::raii::SurfaceKHR>(
      *instance_, raw_surface);
  ```

- 成员变量 `std::unique_ptr<vk::raii::SurfaceKHR> surface_` — 存储表面的 RAII 句柄。`vk::raii::SurfaceKHR` 的析构函数会调用 `vkDestroySurfaceKHR`。由于 `surface_` 在 `instance_` 之前声明（或在同一作用域内后创建先销毁），销毁顺序由 C++ 成员声明顺序或析构顺序自动保证

- 表面在 `Show()` 中的创建时机 — 在 `VkCreateInstance()` 之后、`glfwCreateWindow()` 之后、主循环之前。此时 instance 和 window 都已就绪，可以安全创建表面
