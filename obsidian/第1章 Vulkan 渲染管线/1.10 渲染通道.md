# 1.10 渲染通道

**初始状态**：谜题 1.9 的图像视图程序。

**目标状态**：成功创建 `VkRenderPass`。程序退出前销毁。

**规则**：
- 一个 color attachment：`format = swapchain_image_format`，`samples = VK_SAMPLE_COUNT_1_BIT`
- `loadOp = VK_ATTACHMENT_LOAD_OP_CLEAR`，`storeOp = VK_ATTACHMENT_STORE_OP_STORE`
- `initialLayout = VK_IMAGE_LAYOUT_UNDEFINED`，`finalLayout = VK_IMAGE_LAYOUT_PRESENT_SRC_KHR`
- 一个 subpass：`pipelineBindPoint = VK_PIPELINE_BIND_POINT_GRAPHICS`，只引用 color attachment
- 不需要 depth attachment
- 不需要 subpass dependency
