# 1.9 图像视图

#### 目标
在 [[1.8 交换链]] 的基础上，为每个 swapchain image 创建对应的图像视图，实现：
1. 遍历 `swapchain_images_`，为每张图像创建 `vk::raii::ImageView`
2. 程序退出前由 RAII 自动销毁所有图像视图

#### 规则
- `vk::ImageViewCreateInfo` — 描述如何解释一张图像。需要设置的字段：
  - `setImage(image)` — 指定目标图像，来自 `swapchain_images_[i]`
  - `setViewType(vk::ImageViewType::e2D)` — 视图类型为二维
  - `setFormat(swapchain_image_format_)` — 像素格式与交换链一致
  - `setSubresourceRange(...)` — 指定访问范围：`aspectMask` 为 `vk::ImageAspectFlagBits::eColor`，`levelCount = 1`，`layerCount = 1`
  - `components` 使用默认值（不设置），即 RGBA 各通道不做 swizzle

- `device_->createImageView(create_info)` — 创建 `vk::raii::ImageView`，RAII 析构时自动调用 `vkDestroyImageView`

  ```cpp
  for (const auto& image : swapchain_images_) {
      vk::ImageViewCreateInfo ivci;
      ivci.setImage(image)
          .setViewType(vk::ImageViewType::e2D)
          .setFormat(swapchain_image_format_)
          .setSubresourceRange(vk::ImageSubresourceRange(
              vk::ImageAspectFlagBits::eColor, 0, 1, 0, 1));
      swapchain_image_views_.push_back(
          std::make_unique<vk::raii::ImageView>(device_->createImageView(ivci)));
  }
  ```

- 成员变量 — 新增 `std::vector<std::unique_ptr<vk::raii::ImageView>> swapchain_image_views_`
