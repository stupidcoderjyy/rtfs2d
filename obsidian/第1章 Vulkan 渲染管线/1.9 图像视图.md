# 1.9 图像视图

**初始状态**：谜题 1.8 的交换链程序。

**目标状态**：为每个 swapchain image 创建对应的 `VkImageView`，程序退出前全部销毁。

**规则**：
- 遍历 `swapchain_images_`，为每个 image 调用 `vkCreateImageView`
- `VkImageViewCreateInfo` 中 `viewType = VK_IMAGE_VIEW_TYPE_2D`
- `format` 使用交换链的 image format
- `subresourceRange.aspectMask = VK_IMAGE_ASPECT_COLOR_BIT`
- `subresourceRange.levelCount = 1`，`layerCount = 1`
