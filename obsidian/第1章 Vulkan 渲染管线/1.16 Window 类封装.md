# 1.16 Window 类封装

**初始状态**：谜题 1.15 的交换链重建程序。所有逻辑散落在 `main.cpp` 中。

**目标状态**：所有 Vulkan 初始化、渲染循环、清理逻辑封装在 `rtfs2d::Window` 类中。`main.cpp` 只包含：

```cpp
#include "Window.h"
int main() {
    rtfs2d::Window w(800, 600);
    w.Run();
    return 0;
}
```

**规则**：
- `Window` 构造函数接受 `width`、`height`，不接受其他参数
- `InitGlfw()` → `InitVulkan()` → `CreateVulkanSurface()` → `InitPhysicalDevice()` → `CreateLogicalDevice()` → `GetQueues()` → `CreateSwapChain()` → `CreateImageViews()` → `CreateRenderPass()` → `CreateFramebuffer()` → `CreateCommandPool()` → `InitCommandBuffers()` → `CreateSyncObjects()` 在构造时链式调用
- `Run()` = 谜题 1.14 的渲染循环 + 1.15 的重建逻辑
- 析构函数 = `Cleanup()`，按创建的逆序销毁所有 Vulkan 资源
- 成员变量命名采用 `snake_case_` 后缀（`width_`, `height_`, `device_` 等）
- Vulkan 句柄成员默认初始化为 `VK_NULL_HANDLE`，GLFW 指针默认初始化为 `nullptr`
- 每个 `Create*` / `Init*` 方法按需返回成功/失败（`int` 或 `void`），内部 assert 关键调用成功后继续
