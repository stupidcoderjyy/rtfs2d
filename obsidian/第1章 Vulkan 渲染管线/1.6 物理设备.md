# 1.6 物理设备

#### 目标
在 [[1.5 窗口表面]] 基础上，枚举物理设备并选定满足渲染需求的 GPU，实现：
1. 打印选定 GPU 的名称
2. 记录选定的 graphics queue family 索引和 present queue family 索引（二者可以为同一个）
3. 如果没有满足条件的设备，程序报错退出

#### 规则
- `instance_->enumeratePhysicalDevices()` — 枚举系统中所有支持 Vulkan 的物理设备，返回 `std::vector<vk::raii::PhysicalDevice>`

- 队列族（queue family） — GPU 将功能按"族"分组。每个族内可以分配若干队列。`vk::raii::PhysicalDevice::getQueueFamilyProperties()` 返回每个族的属性，其中 `queueFlags` 按位标记该族支持的操作类型（`vk::QueueFlagBits::eGraphics` 表示支持图形命令）。遍历所有族，找到第一个包含 `eGraphics` 的族，记录其索引

- `physical_device.getSurfaceSupportKHR(queue_family_index, *surface_)` — 检查指定队列族是否支持向窗口表面呈现图像。返回 `bool`：`true` 表示该族的队列可以用于 present。present 族可能与 graphics 族不同，记录索引时允许分开存储

  ```cpp
  for (const auto& device : instance_->enumeratePhysicalDevices()) {
      auto queue_families = device.getQueueFamilyProperties();
      std::optional<uint32_t> graphics_index;
      std::optional<uint32_t> present_index;

      for (uint32_t i = 0; i < queue_families.size(); ++i) {
          if (queue_families[i].queueFlags & vk::QueueFlagBits::eGraphics)
              graphics_index = i;
          if (device.getSurfaceSupportKHR(i, *surface_))
              present_index = i;
      }
      // 两个索引都找到后检查 swapchain 扩展...
  }
  ```

- swapchain 扩展检查 — 向窗口渲染图像需要设备支持 `VK_KHR_SWAPCHAIN_EXTENSION_NAME`。通过 `device.enumerateDeviceExtensionProperties()` 列出设备支持的扩展，遍历检查是否存在匹配的 `extensionName`

  ```cpp
  bool has_swapchain = false;
  for (const auto& ext : device.enumerateDeviceExtensionProperties()) {
      if (std::strcmp(ext.extensionName, VK_KHR_SWAPCHAIN_EXTENSION_NAME) == 0) {
          has_swapchain = true;
          break;
      }
  }
  ```

- 选定策略 — 三个条件（graphics 族存在、present 族存在、swapchain 扩展存在）全部满足后立即选定该设备，不继续遍历后续设备。打印 `properties.deviceName` 即 GPU 名称

- 成员变量 — 新增 `vk::raii::PhysicalDevice physical_device_` 存储选定的物理设备句柄，`uint32_t graphics_queue_family_` 和 `uint32_t present_queue_family_` 存储队列族索引
