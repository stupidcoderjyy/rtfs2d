# 1.8 交换链

#### 目标
在  [[1.7 逻辑设备与队列]] 的基础上，创建交换链以获取可渲染到窗口的图像，实现：
1. 选取合适的 surface 格式、呈现模式和交换链尺寸
2. 成功创建 `vk::raii::SwapchainKHR`，拿到 swapchain images 列表
3. 程序退出前由 RAII 自动销毁

#### 规则
- 核心接口 — `swapchain_ = std::make_unique<vk::raii::SwapchainKHR>(*device_, ci)`，其中 `ci` 是 `vk::SwapchainCreateInfoKHR`。构造成功即获得可用的交换链，析构时自动调用 `vkDestroySwapchainKHR`

- `ci.setSurface(*surface_)` — 指定交换链渲染的目标表面

- `ci.setImageExtent(...)` — 设置交换链中每张图像的像素尺寸。通过 `physical_device_.getSurfaceCapabilitiesKHR(*surface_)` 获取 `capabilities.currentExtent`。若 `currentExtent.width == UINT32_MAX`，则用构造参数 `width_` / `height_` clamp 到 `capabilities.minImageExtent` 和 `capabilities.maxImageExtent` 之间

- `ci.setImageFormat(...)` / `ci.setImageColorSpace(...)` — 设置像素格式和色彩空间。通过 `physical_device_.getSurfaceFormatsKHR(*surface_)` 查询支持的格式列表，优先选择 `vk::Format::eB8G8R8A8Srgb` + `vk::ColorSpaceKHR::eSrgbNonlinear`，若不存在则取列表第一个

- `ci.setPresentMode(...)` — 设置呈现模式，选择 `vk::PresentModeKHR::eFifo`（V-Sync）。通过 `physical_device_.getSurfacePresentModesKHR(*surface_)` 验证该模式在支持列表中

- `ci.setImageArrayLayers(1)` — 图像层数，普通 2D 应用设为 1

- `ci.setMinImageCount(...)` — 交换链最少图像数量，取 `capabilities.minImageCount + 1`。若 `capabilities.maxImageCount > 0` 且计算结果超过上限，则 clamp 到 `maxImageCount`

- `ci.setImageUsage(vk::ImageUsageFlagBits::eColorAttachment)` — 告知 Vulkan 交换链图像将作为颜色附件使用

- `ci.setPreTransform(capabilities.currentTransform)` — 指定图像变换（旋转等），直接使用 surface 的当前变换

- `ci.setCompositeAlpha(vk::CompositeAlphaFlagBitsKHR::eOpaque)` — 指定 alpha 合成方式，设为不透明

- `ci.setClipped(VK_TRUE)` — 允许 Vulkan 裁剪被遮挡的像素以提升性能

- `ci.setImageSharingMode(...)` — 若 `graphics_queue_family_index_ == present_queue_family_index_` 则设为 `vk::SharingMode::eExclusive`；否则设为 `vk::SharingMode::eConcurrent`，并通过 `setQueueFamilyIndices` 提供两个族索引

- 创建后获取图像 — `swapchain_images_ = swapchain_->getImages()`，返回 `std::vector<vk::Image>`

- 成员变量 — 新增 `std::unique_ptr<vk::raii::SwapchainKHR> swapchain_`、`std::vector<vk::Image> swapchain_images_`、`vk::Format swapchain_image_format_`、`vk::ColorSpaceKHR swapchain_color_space_`、`vk::Extent2D swapchain_extent_`
