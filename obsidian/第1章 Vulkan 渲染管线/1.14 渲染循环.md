# 1.14 渲染循环

**初始状态**：谜题 1.13 的同步对象程序。

**目标状态**：窗口每帧清屏为深蓝灰色 `(0.1, 0.15, 0.2)`。FPS 由 VSync 控制。

**规则**：
- 循环体：
  1. `vkWaitForFences(device, 1, &in_flight_fences[current_frame], VK_TRUE, UINT64_MAX)`
  2. `vkAcquireNextImageKHR` 获取 image index，signal `image_available_semaphore[current_frame]`
  3. `vkResetFences(device, 1, &in_flight_fences[current_frame])`
  4. 填充 `VkSubmitInfo`：wait stage = `VK_PIPELINE_STAGE_COLOR_ATTACHMENT_OUTPUT_BIT`；wait semaphore = `image_available`；signal semaphore = `render_finished`；command buffer = 对应 image index 的那个
  5. `vkQueueSubmit(graphics_queue, 1, &submit_info, in_flight_fences[current_frame])`
  6. 填充 `VkPresentInfoKHR`：wait semaphore = `render_finished`；swapchain = swapchain；imageIndex = 从 acquire 拿到的 index
  7. `vkQueuePresentKHR(present_queue, &present_info)`
  8. `current_frame = (current_frame + 1) % kMaxFramesInFlight`
- 窗口关闭时 `vkDeviceWaitIdle` 再清理
