# 1.14 渲染循环

#### 目标
在 [[1.13 同步对象]] 的基础上实现渲染循环，实现：
1. 窗口每帧清屏为随时间循环的颜色，FPS 由 V-Sync 控制
2. acquire → submit → present 的完整同步流程

#### 规则
1. 搭建循环骨架
    1. 循环条件为 `!glfwWindowShouldClose(window_)`，退出条件与关卡 1.2 一致
    2. 循环结束后调用 `device_->waitIdle()` 确保 GPU 完成所有工作
    3. 整体包裹在 `try-catch` 中，异常时 `device_->waitIdle()` 后重新抛出，保证 RAII 安全析构

2. 等待飞行帧完成
    1. 调用 `device_->waitForFences(**in_flight_fences_[current_frame_], VK_TRUE, UINT64_MAX)` 等待当前帧槽位的 fence 变为 signaled，确保 GPU 完成该帧工作后可复用资源
    2. 检查返回值是否为 `eSuccess`，否则抛出异常
    3. 调用 `device_->resetFences(**fence)` 重置为 unsignaled，供本次 submit 使用

3. 从交换链获取图像
    1. 调用 `swapchain_->acquireNextImage(UINT64_MAX, **acquire_sem)` 获取下一张可用图像的索引。返回 `std::pair<vk::Result, uint32_t>`
    2. `acquire_sem` 在 acquire 完成时被 signal
    3. 若 result 为 `eErrorOutOfDateKHR`，调用 `RecreateSwapChain()` 并 `continue` 跳过本帧

4. 录制并提交命令
    1. 调用 `RecordCommands(command_buffers_[current_frame_], img_idx)` 重新录制 command buffer
    2. 构造 `vk::SubmitInfo`：`setWaitSemaphores(**acquire_sem)` 使 GPU 等待 acquire 完成、`setWaitDstStageMask(vk::PipelineStageFlagBits::eColorAttachmentOutput)` 在颜色附件阶段之前等待、`setSignalSemaphores(**render_sem)`（`render_sem` 为 `render_finished_semaphores_[img_idx]`）在 submit 完成时 signal、`setCommandBuffers(*cb)` 提交录好的 command buffer
    3. 调用 `graphics_queue_->submit(si, **fence)` 提交

5. 呈现到窗口
    1. 构造 `vk::PresentInfoKHR`：`setWaitSemaphores(**render_sem)` 等待渲染完成、`setSwapchains(**swapchain_)`、`setImageIndices(img_idx)`
    2. 调用 `present_queue_->presentKHR(pi)` 呈现
    3. 若结果为 `eErrorOutOfDateKHR` 或 `eSuboptimalKHR`，将 `frame_buffer_resized_` 置为 `true`，下一帧重建

6. 推进帧索引
    1. 执行 `current_frame_ = (current_frame_ + 1) % kMaxFramesInFlight`
    2. 调用 `glfwPollEvents()` 处理窗口事件
