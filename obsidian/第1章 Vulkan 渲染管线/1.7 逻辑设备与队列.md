# 1.7 逻辑设备与队列

#### 目标
在 [[1.6 物理设备]] 的基础上，从选定的物理设备创建逻辑设备并获取队列句柄，实现：
1. 成功创建 `vk::raii::Device`，程序退出前由 RAII 自动销毁
2. 获取 graphics queue 和 present queue 的 `vk::raii::Queue` 句柄

#### 规则
- 去重队列族索引 — `graphics_queue_family_index_` 和 `present_queue_family_index_` 可能指向同一个族。用一个 `std::set<uint32_t>` 收集二者，避免在 `VkDeviceCreateInfo` 中重复声明同一个族
- `vk::DeviceQueueCreateInfo` — 为每个唯一的队列族填充一个该结构体。`queueCount = 1`（每个族只申请一个队列），`pQueuePriorities` 指向 `{1.0f}`。`queueFamilyIndex` 为该族的索引

  ```cpp
  std::set<uint32_t> unique_queue_families = {
      graphics_queue_family_index_, present_queue_family_index_
  };
  std::vector<vk::DeviceQueueCreateInfo> queue_create_infos;
  float priority = 1.0f;
  for (uint32_t qf : unique_queue_families) {
      queue_create_infos.push_back({});
      queue_create_infos.back()
          .setQueueFamilyIndex(qf)
          .setQueueCount(1)
          .setPQueuePriorities(&priority);
  }
  ```

- `vk::DeviceCreateInfo` — 逻辑设备创建参数。`queueCreateInfoCount` 和 `pQueueCreateInfos` 设置为上一步的结果。`enabledExtensionCount` / `ppEnabledExtensionNames` 包含 `VK_KHR_SWAPCHAIN_EXTENSION_NAME`。不启用任何 device feature（`pEnabledFeatures` 为 `nullptr`）
- `vk::raii::Device device(*physical_device_, create_info)` — 用物理设备和 create info 构造 RAII 逻辑设备。存储为 `std::unique_ptr<vk::raii::Device>`，析构时自动调用 `vkDestroyDevice`
- `device->getQueue(queue_family_index, 0)` — 获取队列句柄，返回 `vk::raii::Queue`。第二个参数为队列索引（每个族申请了 1 个队列，所以传 0）。分别用 `graphics_queue_family_index_` 和 `present_queue_family_index_` 获取 graphics 和 present 队列。存储为 `std::unique_ptr<vk::raii::Queue>`
- 成员变量 — 新增 `std::unique_ptr<vk::raii::Device> device_`、`std::unique_ptr<vk::raii::Queue> graphics_queue_`、`std::unique_ptr<vk::raii::Queue> present_queue_`
