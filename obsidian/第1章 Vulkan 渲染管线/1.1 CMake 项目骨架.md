# 1.1 CMake 项目骨架

#### 目标
从空目录开始，搭建 CMake 项目骨架，实现：
1. `cmake --build build` 成功编译出可执行文件
2. 运行后在控制台打印 `rtfs2d ready`

#### 规则
1. 创建顶层 CMake 构建文件
    1. 调用 `cmake_minimum_required(VERSION 4.0)` 指定最低 CMake 版本
    2. 调用 `project(rtfs2d LANGUAGES CXX)` 声明项目名称和语言
    3. 调用 `set(CMAKE_CXX_STANDARD 20)` 启用 C++20
    4. 调用 `find_package(Vulkan REQUIRED)` 和 `find_package(glfw3 REQUIRED)` 引入 Vulkan 和 GLFW 依赖
    5. 调用 `add_subdirectory(src)` 引入核心库子目录
    6. 调用 `add_executable(${PROJECT_NAME} main.cpp)` 创建可执行目标
    7. 调用 `target_link_libraries` 将可执行目标链接到 `rtfs2d::core`

2. 创建核心库的 CMake 构建文件
    1. 在 `src/CMakeLists.txt` 中调用 `add_library(rtfs2d_core STATIC core.cpp core.h)` 创建静态库
    2. 调用 `add_library(rtfs2d::core ALIAS rtfs2d_core)` 创建库别名供顶层引用
    3. 调用 `target_include_directories(rtfs2d_core PUBLIC ${CMAKE_CURRENT_SOURCE_DIR})` 使头文件对外可见

3. 创建核心库头文件
    1. 在 `src/core.h` 中声明 `namespace rtfs2d { void Ready(); }`

4. 创建核心库实现文件
    1. 在 `src/core.cpp` 中实现 `void rtfs2d::Ready() {}`

5. 创建程序入口文件
    1. 在 `main.cpp` 中 `#include "core.h"`，调用 `rtfs2d::Ready()`，然后向 `std::cout` 输出 `"rtfs2d ready"` 并换行
