# 1.4 调试回调

#### 目标
在 [[1.3 Vulkan 实例]] 的基础上注册调试回调，实现：
1. 验证层的 Warning / Error 消息以 `[Vulkan]` 前缀打印到控制台
2. 实例创建和销毁期间的回调也处于激活状态

#### 规则
1. 编写回调函数
    1. 声明 `VKAPI_ATTR VkBool32 VKAPI_CALL DebugCallback(severity, type, data, user_data)` 静态函数
    2. 函数体内根据 `severity` 分流：`eWarning` 调用 `spdlog::warn`，`eError` 调用 `spdlog::error`，均以 `"[Vulkan] {}"` 格式输出 `data->pMessage`
    3. 返回 `VK_FALSE` 表示不中断 Vulkan 调用

2. 构造调试回调配置
    1. 构造 `vk::DebugUtilsMessengerCreateInfoEXT` 对象
    2. 链式调用 `setMessageSeverity(eWarning | eError)`，只捕获 Warning 和 Error 级别
    3. 链式调用 `setMessageType(eGeneral | eValidation | ePerformance)`，覆盖所有消息类型
    4. 链式调用 `setPfnUserCallback(DebugCallback)` 指定回调函数

3. 将调试配置挂入 pNext 链
    1. 在 `CreateVkInstance()` 中调用 `vk::InstanceCreateInfo::setPNext(&debug_info)`，确保回调在 instance 创建和销毁阶段均激活

4. 创建 RAII 调试信使
    1. 调用 `instance_->createDebugUtilsMessengerEXT(debug_info)` 获取 `vk::raii::DebugUtilsMessengerEXT`
    2. 用 `std::make_unique` 存入 `std::unique_ptr<vk::raii::DebugUtilsMessengerEXT> debug_messenger_`。RAII 析构时自动调用 `vkDestroyDebugUtilsMessengerEXT`
