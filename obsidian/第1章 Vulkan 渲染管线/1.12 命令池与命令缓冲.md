# 1.12 命令池与命令缓冲

#### 目标
在谜题 1.11 的基础上，创建命令池和命令缓冲，为每个帧缓冲录制清屏指令，实现：
1. 成功创建 `vk::raii::CommandPool` 和 `std::vector<vk::raii::CommandBuffer>`
2. 每个 command buffer 录制一个清屏 render pass（清屏颜色为深蓝灰，无需任何 draw call）
3. 程序退出前由 RAII 自动销毁

#### 规则
- `vk::CommandPoolCreateInfo` — 命令池创建参数。`queueFamilyIndex = graphics_queue_family_index_`，将该池中的命令缓冲提交到 graphics 队列。`flags` 可设为 0（不使用重置/瞬态标志）
- `device_->createCommandPool(ci)` — 返回 `vk::raii::CommandPool`，存储为 `std::unique_ptr<vk::raii::CommandPool> command_pool_`
- `vk::CommandBufferAllocateInfo` — 命令缓冲分配参数。`commandPool = *command_pool_`，`commandBufferCount = swapchain_image_views_.size()`（与帧缓冲数量一致），`level = vk::CommandBufferLevel::ePrimary`。`device_->allocateCommandBuffers(ai)` 返回 `std::vector<vk::raii::CommandBuffer>`，存储为成员变量

- 录制清屏指令 — 为每个 command buffer 调用：
  1. `cb.begin({})` — 开始录制，flags 可设 0
  2. `vk::RenderPassBeginInfo` — 渲染通道开始信息。`renderPass = *render_pass_`，`framebuffer = *framebuffers_[i]`，`renderArea` 设置为 `{0, 0, swapchain_extent_.width, swapchain_extent_.height}`，`clearValueCount = 1`，`pClearValues` 指向 `vk::ClearValue{.color = vk::ClearColorValue{std::array{0.1f, 0.15f, 0.2f, 1.0f}}}`
  3. `cb.beginRenderPass(render_pass_begin_info, vk::SubpassContents::eInline)`
  4. `cb.endRenderPass()`
  5. `cb.end()`

- 成员变量 — 新增 `std::unique_ptr<vk::raii::CommandPool> command_pool_`、`std::vector<vk::raii::CommandBuffer> command_buffers_`
